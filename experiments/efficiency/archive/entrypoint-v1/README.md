# Archived entry-point measurements

These are the byte-preserved driver, protocol, and measurements used in commit `ff117e89310d815dfc327a7c2304b787fc1055d2`. They timed the original exp1 FT attribution entry point before final aggregation. They are retained for provenance and are not used by the current plot.

The current experiment measures the complete exp2 FT evaluation wrapper. Reproduction of this archive requires the original repository layout at the commit above; the archived driver is not intended to run from this subdirectory.
