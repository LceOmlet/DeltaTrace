## 前提

只以 token 价值作为 DT 与策略学习之间的对象。用户给定的理想化假设是：
**DT 的 token 反事实就是对应真实世界变量的精确反事实；模型估计的 token
价值完全准确，并等于对应真实世界变量的价值。**
推导采用这一前提，不重新质疑它，也不将其改成新增环境反事实模拟器或外部逐
token 打分器的要求。它用于检查精确极限下的组合；不声称现实估计已经没有误差。

下面的 \(Q/V\) 规定这些价值相对于既定奖励目标、token 前缀及旧策略参照的含义。
实际输出仍须与这个含义对齐；既不能把任意张量改名当作完成，也不能因估计有误差
就撤回已经成立的组合规则。

## 与 PPO 的逐项对应

| 项目 | 标准 PPO | 最终 DT 方案 |
| --- | --- | --- |
| 状态 | 每个 token 前缀 \(h_i\)，包含历史 \(O\) | 相同 |
| Action | 每个模型生成 token | 相同；reasoning、工具调用、final 都是独立 action |
| 工具观测 \(O\) | 状态，不是 action | 相同；不计算 ratio，不单独接收 credit |
| \(Q\) | \(Q^{\pi_{\rm old}}(h_i,a_i)\) | DT 提供该 token 的对应价值估计 |
| \(V\) | critic 学习 \(V^{\pi_{\rm old}}(h_i)\) | DT 计算策略边缘的 \(V^{\pi_{\rm old}}(h_i)\)，不建 value model |
| Advantage | \(A_i=Q^{\pi_{\rm old}}(h_i,a_i)-V^{\pi_{\rm old}}(h_i)\) | \(A_i^{DT}=Q_i^{DT}-V_i^{DT}\) |
| 工具调用 token 的价值 | 包含 \(A_t\rightarrow O_t\rightarrow\) 后续回报 | 完整包含同一链路 |
| 后续 token | 状态中包含工具返回 \(O_t\)，独立计算 advantage | 相同 |
| Token credit | 每个 token 一个 \(A_i\) | 每个 token 一个 \(A_i^{DT}\)，不广播、不平均 |
| Reward | 通过 \(Q/V\) 进入 advantage | 通过 DT 的 token 价值及既定 Q/V 关系进入 advantage |
| PPO ratio | \(\rho_i=\pi_\theta/\pi_{\rm old}\) | 完全相同 |
| PPO clipping | 原始 clipped objective | 完全相同 |
| Value loss | 通常训练 critic | 没有额外 value loss |
| 训练目标 | \(\min(\rho_i A_i,\operatorname{clip}(\rho_i)A_i)\) | 同一个目标，只替换 \(A_i\) 的来源 |

## 固定的 Q、V 和目标函数

令 \(G_i\) 为与 PPO 对照使用相同回报及折扣约定的环境 return-to-go，
\(\mathcal E\) 表示真实环境转移。DT 要计算的对象是：

\[
Q_i^{DT}
=\mathbb E_{\pi_{\rm old},\mathcal E}[G_i\mid h_i,a_i],
\qquad
V_i^{DT}
=\mathbb E_{a\sim\pi_{\rm old}(\cdot\mid h_i)}
   [Q^{DT}(h_i,a)],
\qquad
A_i^{DT}=Q_i^{DT}-V_i^{DT}.
\]

这里的策略边缘只定义 \(V\)；它不把同一调用 span 内的 token advantage 平均。
每个调用 token 仍使用自己的前缀 \(h_i\) 和 action \(a_i\)。

\[
\rho_i=\frac{\pi_\theta(a_i\mid h_i)}{\pi_{\rm old}(a_i\mid h_i)},
\qquad
\mathcal L=-\sum_{i\in\text{所有模型生成 token}}
\min\left[
\rho_i A_i^{DT},
\operatorname{clip}(\rho_i,1-\epsilon,1+\epsilon)A_i^{DT}
\right].
\]

在给定的 token 价值准确、并按上述旧策略参照正确组合时：

\[
Q_i^{DT}=Q^{\pi_{\rm old}}(h_i,a_i),\qquad
V_i^{DT}=V^{\pi_{\rm old}}(h_i),\qquad
A_i^{DT}=A_i^{\pi_{\rm old}}.
\]

因此，在同一策略、回报/折扣约定和 action mask 下，学习信号与精确
\(Q-V\) 的 token-level PPO 对应。工具返回 \(O\) 的影响包含在产生它的
调用 token 及后续 token 的 \(Q\) 中；\(O\) 自身不参与策略损失。

## 固定部分与近似部分

| 部分 | 固定的含义 | 实现和验证范围 |
| --- | --- | --- |
| Token 价值 | 理想条件下与对应真实变量价值相同 | 现实 DT 估计允许误差；单独衡量估计质量 |
| Q/V 组合 | 同一前缀、同一奖励目标、同一旧策略参照，相减得到 advantage | 组合正确性与上游张量接口分别检查，不以模型零误差作为验收前提 |
| 策略参照 | 旧策略的条件边缘 | 直接读取实际 token 生成前的事件概率；禁止额外抽取参考 token，不换成 EOS/null、跨状态组均值 |
| 工具与观测 | O 是状态；调用及后续 token 的价值保留其影响 | 使用真实工具事件和准确 token 身份，不凭最近位置推断归属 |
| Actor 更新 | 所有生成 token 的原始 PPO ratio、mask、clipping | 复用上游实现；不用近似估计为接口错位、漏 token 或广播开脱 |
| 资源 | 已有环境、48 GB 单卡、minibatch 4、32k 总长度上限 | 直接在该配置检查实际长度、显存、重复计算和编译，保留可复用结果 |

“模型近似”和“实现错误”分开处理。一个近似模块误差较大，只更新该模块的结论；
不据此否定已验证的 mask、Q/V 代数组合或上游损失。反过来，接口跑通不证明
估计已经准确，也不证明训练收益。

在同一前缀下，将真实 token 动作价值记为 \(q(a)\)，DT 估计记为
\(\widehat q(a)=q(a)+e(a)\)。按既定旧策略组合：

\[
\widehat A(a)=\widehat q(a)-\mathbb E_{\pi_{\rm old}}\widehat q,
\qquad
\widehat A(a)-A(a)=e(a)-\mathbb E_{\pi_{\rm old}}e.
\]

这是固定 Q/V 规则的代数性质，不增加一个估计模块：token 价值误差为零时，
组合误差也为零；实际 token 价值存在误差时，组合仍有明确含义。
若策略边缘的数值近似另有误差，应单独记录，不把它扩大成整个方案无效。

同一个 Q/V 组合也可以直接使用 DT 的反事实价值差。对固定前缀，若 DT 以同一个
参考值 \(B_i\) 给出各候选 token 的差 \(d_i(a)=q_i(a)-B_i\)，则：

\[
d_i(a_i)-\mathbb E_{a\sim\pi_{\rm old}}d_i(a)
=q_i(a_i)-\mathbb E_{a\sim\pi_{\rm old}}q_i(a)
=Q_i-V_i.
\]

参考值在相减中消去，不需要额外学习或求出它。这是已有 Q/V 规则的等价计算，
不是另一种算法。所有差值必须对应同一前缀、同一价值定义和同一个参考；不能把
跨前缀的值混在一起，也不能将某个参考 token 本身直接视为策略平均价值。
该恒等式说明如何使用精确 DT 反事实；当前具体输出与这些量的对应仍需据正式
接口核对，不能仅靠变量命名认定。数值近似只近似这些既定量，不改其含义。

## 奖励进入有限传播的代数接口

本节补充同一 Q/V 目标的奖励接入推导，不改变方法，也不新增奖励预测模型。
**以下已经证明的是奖励根节点的变换及其与 Q/V 的代数关系；不是宣称正式
runner 已经提供所有奖励结果的条件概率，或三项任务已经接通。**

对固定前缀、候选 token 和旧策略后续，令 y 表示一个奖励相关结果，R(y) 是
该结果的环境奖励。y 必须足以确定此处的奖励；不能把奖励取决于环境状态的
事件随意替换成一句答案文本。q(a)=sum_y R(y) p(y|h,a) 是原有价值定义的
展开，而不是新建一个概率预测器。过程奖励对各未来奖励事件分别作此展开，
按原有折扣约定相加。

正式 DT 的目标分数为固定目标文本的 log-prob。对于同一目标 y 的两个端点，
记 ell_1=log p_1、ell_0=log p_0。当 p_0,p_1>0 时，定义：

\[
L(p_1,p_0)=\begin{cases}
\dfrac{p_1-p_0}{\log p_1-\log p_0},&p_1\ne p_0,\\
p_0,&p_1=p_0.
\end{cases}
\]

于是 reward 为常数系数时，有严格恒等式：

\[
R(y)L(p_1,p_0)(\ell_1-\ell_0)=R(y)(p_1-p_0).
\]

因此，单一目标的正式 DT log-prob 归因向量可以乘以同一系数 R(y)L，得到
该奖励加权概率差的有限传播分解，不必对环境奖励求导。等端点使用连续极限；
真实概率为零的边界应使用概率差本身或明确的极限，不能计算 0 乘无穷。
这条恒等式不把整体端点守恒自动升级为每个 action 的 Q/V 证明。

以下参考 token b 只用于展开策略期望的代数证明，不是运行时采样步骤。
在用户给定的精确反事实假设下，对同一前缀的实际 token a 和参考 token b，
令 F_i 为 token i 之后的奖励事件集合，则所有奖励结果加权后：

\[
D_i(a,b)=\sum_{k\in\mathcal F_i}\gamma^{\Delta(i,k)}\sum_y
R_k(y)\left[p_{ik}^{a}(y)-p_{ik}^{b}(y)\right]
=Q(h_i,a)-Q(h_i,b).
\]

再以原计划的旧策略参照取平均：

\[
\mathbb E_{b\sim\pi_{\rm old}(\cdot|h_i)}D_i(a_i,b)
=Q(h_i,a_i)-V(h_i).
\]

这里没有另加 value model、O credit 路由、跨 token 平均或新策略损失。
奖励结果和策略参照的有限估计只能近似上式；仅有一条被选中的事实文本，不能
不加说明地当作已经算完所有奖励结果的期望。

已核对的 owner 接口：`qwen35_answer_finite.py` 中的 `FiniteAnswerOps` 产生
原始 logits 的有限 log-prob seed；`qwen35_dense_finite_runner.py` 返回
`target_logp0`、`target_logp1` 以及合并后的 signed attribution。单一联合文本
目标先对所选 token 的 log-prob 求和，再将联合概率按上述恒等式处理；不能把
整段概率替换为各 token 概率之和。多个不同权重的目标需要在 owner seed 合并前
施加各自权重；已合并的一个归因向量不能恢复任意各目标分解。复用原有有限传播，
不在 RL adapter 中复制另一套传播规则。

同一端点对的多个目标可以在线性的反向传播入口合并；不同前缀、参考或结果
端点的求值仍须计入实际开销，不能据此声称全轨迹必然只需一次 DT。

2026-09-21 的 CPU 代数检查验证了 10,000 组正负 reward 的概率差变换，最大
绝对残差 8.89e-16；另验证了过程奖励与终局奖励的有限结果求和等于 Q-V。
这些检查未调用真实 DT 模型或三个任务环境，不是训练验收。

## 逐 token、逐奖励事件的等价推导

本节将已有 Q/V 规则展开到过程奖励，不另建算法或奖励预测器。
**以下是精确假设下的推导与接入语义；实现与任务测试状态见 README。
本节不是实现或任务测试通过记录。**

对生成 token i，固定其生成前的前缀 h_i。实际 token 为 a_i；下式 b 仅为
旧策略期望的求和变量，不在实现中额外采样。两边后续按旧策略的条件续接定义，不能
把已经观察到的整条后缀固定下来，并将该条件文本分数冒充未来回报期望。

令 X_{ik} 是第 k 个未来奖励事件对 G_i 的贡献，已经包含既定折扣；事件未
发生时贡献为零。于是 G_i = sum_k X_{ik}。如果折扣所依据的时间也会随
续接改变，折扣必须放在 X_{ik} 内取期望，不能使用事实轨迹的时间替代它。
在用户给定的精确 token 反事实假设下，DT 对这个奖励目标的反事实差为：

\[
d^{DT}_{ik}(a_i,b)
=\mathbb E[X_{ik}\mid h_i,a_i]
 -\mathbb E[X_{ik}\mid h_i,b].
\]

这里明确了归因的两个条件端点；不是额外训练一个产生该差值的 critic。
原有 Q/V 的等价计算是：

\[
\begin{aligned}
A_i^{DT}
&=\mathbb E_{b\sim\pi_{\rm old}(\cdot\mid h_i)}
  \sum_k d^{DT}_{ik}(a_i,b)\\
&=\mathbb E[G_i\mid h_i,a_i]
 -\sum_b\pi_{\rm old}(b\mid h_i)\mathbb E[G_i\mid h_i,b]\\
&=Q^{\pi_{\rm old}}(h_i,a_i)-V^{\pi_{\rm old}}(h_i).
\end{aligned}
\]

奖励通过各个 X_{ik} 进入每个 token 的价值差；不能将整个 episode return
再乘一次，也不能除以全轨迹归因之和。求和轴是未来奖励事件，不是生成 token。
每个 token 有各自前缀，故同一工具调用内的 token 不共享同一个 advantage。
与精确 Q/V 对应的零均值条件是同前缀下 sum_a pi_old(a|h_i) A_i(a)=0；
不要求一条采样轨迹上的 sum_i A_i 等于该轨迹回报。

前节的结果概率展开和 log-prob 有限变换，是上述 d 的同一代数展开。
外部 reward 是数值系数，不要求它可导；但任意答案文本的概率不能直接替换
奖励事件的条件概率。成功事件若由多个后续结果组成，目标是该结果集合，而
不是某一句 success 文本。正式 owner 的一个联合输入端点分解也不能仅凭守恒
被当成这里各自前缀下的 token 反事实差。

工具边界采用同一个条件价值定义：对于调用之前或调用内部的 token，未来 O
是它的后代，其对后续奖励的影响包含在条件价值中；对于 O 之后生成的 token，
已经收到的 O 属于 h_i，在该次比较中保持不变。O 不是 policy action，不增加
ratio 或 actor loss，也不把 O 的自回归文本概率当成工具的真实转移概率。
这两类条件不能混淆；无需另造 O credit 再按位置搬回调用 token。

### Sokoban 当前奖励的精确展开

2026-09-21 已从 A6000 现有 gym_sokoban 的 `_calc_reward` 核对：每次
交互 -0.1，箱子进入/离开目标 +1/-1，完成 +10。固定 VERL worker 直接
传回这些奖励；当前 wrapper 的无效 action 返回 -0.1。此处 N 计入这些
产生奖励的有效期内交互，不使用 Gym 只计部分动作的内部计数代替它。

当前 gamma=1，过程已终止后的奖励不再累计。对一个尚未终止的 token 前缀，
记 B_i 为当前目标上的箱子数，B_T 为结束时该数，S 为未来完成指示量，N 为
剩余产生步惩罚的交互次数。箱子进出奖励逐项相消，因此：

\[
G_i=10S+(B_T-B_i)-0.1N.
\]

用 Delta_i X 表示上述同前缀、旧策略参照的条件期望差，则一般箱子数下：

\[
A_i^{DT}=10\Delta_i S+\Delta_i B_T-0.1\Delta_i N.
\]

当前一个箱子、成功即终止的设置有 B_T=S，因此：

\[
Q_i^{DT}=11\mathbb E[S\mid h_i,a_i]-B_i
          -0.1\mathbb E[N\mid h_i,a_i],
\qquad
A_i^{DT}=11\Delta_i S-0.1\Delta_i N.
\]

V_i 仍按同前缀旧策略对 Q_i 取边缘；B_i 在 Q-V 中自然消去。系数 11
包括进目标的 +1 与完成的 +10，不是新设计的奖励。N 对应的是每一步 -0.1
的条件价值，不能遗漏；若成功机会相同而某 token 降低期望剩余步数，它
仍有正 advantage。相反，若剩余步数确定且不受当前 token 影响，该项
差值为零。该化简不重复加入已经结算的过程奖励，不将步数惩罚乘到 O token。
若改变 gamma，使用原逐奖励事件公式，不沿用未折扣的望远镜化简。

这些 S/N/B_T 表达式是现有环境回报的代数分量，不是已实现的新模型输出。
其 DT 条件反事实差如何由正式接口算出仍须落实；不能添加一个成功/步数
预测头或让模型输出标签，就宣称完成了这一接口。

对 PPO 的对应结论是上述精确 Q-V。对于使用精确 V 的采样 TD 信号，
其给定 h_i,a_i 的条件期望也为 Q-V；这不声称任一条采样 GAE 数值逐项
等于精确 advantage。送入相同 PPO clipped objective 的 advantage 若
相同，则 actor 目标与梯度相同；该 advantage 在 actor 更新时停止梯度。

## 用户明确采用的终局／过程奖励采样接入

2026-09-21：用户给出 HCA 式 (6) 的重要性采样构造，并明确要求转成终局或
过程奖励的 token 优势后实现。本节落实该指令；目标仍是前文的 Q-V，不另换目标。

对 token i 和未来奖励事件 k，令 y_k 是足以确定该事件奖励的结果，
X_ik(y_k) 是其对 G_i 的贡献（含原有折扣）。DT 的所需输出契约是：

\[
d_{ik}(y_k)=\log P(y_k\mid h_i,a_i)
              -\log P(y_k\mid h_i,\pi_{\rm old}).
\]

两边均使用旧策略的条件续接；分母是同一前缀的策略边缘概率，不是 EOS/null
端点，也不是各候选 log-prob 的算术平均。实际 y_k 由选定 a_i 后的 rollout
采样。逐 token 的采样计算为：

\[
\widehat Q_i=\sum_k X_{ik}(y_k),\qquad
\widehat V_i=\sum_k X_{ik}(y_k)e^{-d_{ik}(y_k)},\qquad
\boxed{\widehat A_i=\sum_k X_{ik}(y_k)[1-e^{-d_{ik}(y_k)}]}.
\]

实现使用 `-expm1(-d)`，避免 d 接近零时的消减误差。不能把未采样的
`R*(p_action-p_policy)` 直接作为单条样本优势；不能再除以归因总和。
终局奖励是单事件特例；过程奖励逐事件组合。已经结算的过去奖励不回传到
之后生成的 token；同一调用内每个 token 保留独立 d。O/padding 的 actor mask
为零，不进行 observation routing。真实回报和事件时序由现有 rollout 提供。

Sokoban 的每步 -0.1、进/出目标 +1/-1、完成 +10 使用官方返回值，不在
适配层复制评分器。没有发生的未来事件为零奖励结果；其发生与否也是事件
定义的一部分，不能把“尚在执行”条件化掉而遗漏提前结束带来的步罚变化。
也可用包含全部奖励信息的终局结果表示同一个 return，但不能把它与逐事件
表示重复累加。当前选用逐事件表示，不新增成功/步数预测头。

在比值精确、奖励充分且满足覆盖条件时，逐项重要性采样给出
`E[Q_hat|h,a]=Q`、`E[V_hat|h,a]=V`、`E[A_hat|h,a]=Q-V`。
覆盖条件是参考结果分布绝对连续于选定动作后的结果分布；这对应
[HCA 定理 2、式 (6)](https://papers.neurips.cc/paper/9413-hindsight-credit-assignment.pdf)
的正支持假设。观察到的有限 d 不能证明整个分布的覆盖；不添加 epsilon
掩盖零支持，也不声称单条样本数值等于精确优势。PPO 保持上游 clipped
objective；无偏优势估计不自动意味着有限采样的 clipped objective 无偏。

正式 DT 的 joint-input signed attribution 仍是它自身的输出，不能直接重命名
为上述 d。原有 `PackedAnswerTargets` / `FiniteAnswerOps` / `attribute`
提供固定目标文本及两个联合输入端点的 log-prob 和输入分解；下节明确新增
事件目标与实际 token 生成前后端点读出。奖励组合的有限分布测试不能证明三个环境训练
或现实 DT 估计质量。

## 2026-09-22 用户批准的奖励事件目标读出

用户明确批准：将官方每步奖励的可能结果编码为文本目标，由当前同一个 Qwen
在给定 token 前缀、候选 token 和未来事件位置时打分；正式 DT 计算目标分数差，
已有代码完成旧策略边缘与奖励组合。不增加或训练 value model。此项批准覆盖
下面的事件分类读出，不覆盖 HCA 论文中的额外训练模型。

具体读出如下：

1. 每个任务声明官方每步奖励的有限值域，将每个不同奖励值编码为一个单 token
   标签。当前 WebShop/AppWorld 为 `{0,10}`；当前单箱 Sokoban 为
   `{-0.1,0,10.9}`。零包括未来步骤未发生；不能条件化为“该步一定发生”。
   这是事件编码，不复制环境评分器；真实 reward 仍由官方 worker 返回。
2. 对原始 rollout 的 token 前缀 `h_i` 以及 `h_i+a_i`，分别附加固定读出询问，
   指定任务、当前环境步、未来奖励步和 rollout 的最大步数，并解释标签值域。
   询问未来按同一个旧策略续接时该步的奖励类别。不提供事实未来 O、后续生成、
   实际奖励或终止时间。过去 O 已经位于原始前缀中，保留不变。
3. 同一原始 Qwen head 的标签 logits 经过标签集合上的 log-softmax，定义
   `p_hat_k(y|h_i,a)`。这是一项明确的条件事件概率估计，不把单句文本的原始
   概率自动等同于事件概率。现实预测质量需要实测；精确假设作用于这些条件概率。
   归一化的是事件类别分布，不是 token credit 或奖励。
4. **直接读取实际 token 生成前后两个前缀的事件概率。禁止额外抽取参考 token。**
   对同一未来奖励事件 k 和同一结果 y，正式 owner 的 `forward_prefix` /
   `read_outcomes` 分别读出
   `p_minus = p_hat_k(y|h_i)` 与 `p_plus = p_hat_k(y|h_i,a_i)`。
   两端使用同一个询问、奖励值域、事件位置和旧策略续接；生成前读出不能看到
   a_i，任一端都不能看到事实未来观测或后缀。未来工具结果的影响包含在事件
   概率内。两端长度自然相差一个实际 token，不插入 EOS/null 或占位参考。
5. 全概率公式给出
   `p_k(y|h_i) = sum_a pi_old(a|h_i) p_k(y|h_i,a)`，所以生成前的读出直接
   对应原定义的策略边缘，不需要枚举或采样候选。令
   `d_ik = log p_plus(y_k) - log p_minus(y_k)`，接入已固定的逐事件
   `Q_hat/V_hat/A_hat` 和原上游 PPO，不改公式、mask、reward 或 loss。
   零实际奖励项严格为零，可以省去其读出。

这不是把“前缀少一个 token”当成删除 token 的 null 反事实；生成前读出的含义
是当前 token 尚未选定、由同一旧策略继续时的事件分布。精确假设下它已经包含
对当前动作的边缘化；实际读出的估计误差与额外参考采样方差是不同的量，此路径
不再引入后者。完整类别加权的恒等式仍是

\[
Q_i=\sum_k\sum_y X_{ik}(y)p^+_{ik}(y),\qquad
V_i=\sum_k\sum_y X_{ik}(y)p^-_{ik}(y).
\]

生产接口继续使用用户已确定的实际事件采样组合；其条件期望等于这两个量，
适用上节已有的覆盖条件。不把单条采样优势宣称为精确期望值。

正式 owner 的根读出直接计算这两个条件端点的 log-prob。先前“同长度、单位置
替换”的 finite 对照只验证了先前探针，不能当作本次不同长度端点的验证。
本次不将联合输入归因重命名为 d，不新增有限传播实现或新的 value model。

同前缀缓存由 Hugging Face 原生 cache 保存。询问在缓存副本上执行，不写回
事实前缀；事实链只推进真实 action token。连续响应内 h_i+a_i=h_{i+1}，且未来
事件集合与询问不变，因此前一 token 的生成后读出复用为下一 token 的生成前
读出。N 个 token 每个事件只需 N+1 个边界读出，而不是逐 token 两次独立读取。
环境返回 O 后，下一行的生成前读出必须从含真实 O 的新前缀重新计算；不能跨
工具边界复用旧读出，不能把 O 导致的概率变化当作 policy action 的优势。
工具调用最后一个 token 的生成后读出仍在收到 O 之前，包含未来 O 的影响。

同一边界的多个未来事件共享询问的共同前缀缓存。采用原生模型前向与输出 head，
不实现第二套 transformer、cache 状态转移或 DT pullback；不启用变长编译。
当前 rollout 温度 1、top_p=1、不截断 top_k；事件读出所描述的续接策略与其一致。
读出询问本身不成为 action 或奖励事件。总上下文上限仍为 32768，前缀与询问
长度均计入并报告。

这一计算移除了参考 token 的采样方差和对应分支前向，但仍有各边界的事件查询
成本，不预先声称整轨迹等于一次 DT 或当前训练已通过。现实预测质量、原生缓存
一致性、三任务训练和时间/显存分别实测，不由代数证明代替。

## 每次推进的规则

1. 不再质疑用户给定的精确 token 反事实假设；不擅自增加“每次只能改一个部分”等
   工作约束。保留已经确定的结论，除非相关证据或用户指令确实要求修正。
2. 每个改动说明它改变了哪个计算、为何符合既定语义，以及准确性或成本上要改善什么。
   尚未证明的选择保持为待核对项，不因命名相近就固定成实现。
3. 不以穷举所有未来、真实模型零误差或重新训练一个完美环境模型作为开发门槛。
   实际奖励事件采样与数值近似保留原目标；禁止额外参考 token 采样。
4. 一个反例只否定它实际触及的计算。常数奖励反例排除了“把守恒份额直接当作
   advantage”，没有否定正确构造 Q、V 后相减的计划。
5. 除用户已明确采用的上述 HCA 采样恒等式和 2026-09-22 目标读出扩展外，不将 HCA 的其他组件、COCOA、
   奖励事件概率预测或其他讨论过的候选改写自动升级为本计划。
   不把用户对 Gibbs 采样逻辑的类比扩写成新的算法或强制工作顺序。
6. 遇到真实的接口冲突或无法继续的实际错误时，停止受影响部分并报告具体事实；
   “DT 是近似”本身不构成这样的错误。

旧归因归一化和观测位置映射已从本地 RL producer 移除；采样奖励组合与正式 DT
结果比值生产分开核验。该接口工作不能用来推翻用户给定的 token 价值假设，
也不能用假设将旧 joint-input attribution 直接认定为所需比值。

## 实现必须守住的范围

- 复用正式 DeltaTrace 和固定上游 RL/任务接口。rollout、环境、策略损失、
  optimizer 等已有能力由其原有实现负责，不复制或另写影子实现。
- 只替换 token advantage 的来源；不增加 value model、value loss、span credit、
  macro-action、独立 O credit 或独立奖励分账模块。
- 不将旧实现、历史通过记录或张量守恒检查当作上述 \(Q/V\) 构造及等价性的证明。
- 发现实现偏离本文件时，回到本文件修正；遇到实际卡点时停止相关实现并向用户报告，
  等待处理，不自行换用备选方法或改写本计划。
