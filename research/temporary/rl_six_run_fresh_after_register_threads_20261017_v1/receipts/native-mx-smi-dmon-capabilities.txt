
USAGE: 

   mx-smi dmon  [-hv] [--show-bdf] [--show-board-power] [--show-clock]
                [--show-index] [--show-memory] [--show-render]
                [--show-temperature] [--show-usage] [--total-memory] [-c
                <count>] [-i <deviceId>] [-l <ms>] [--die <dieId>]
                [--format <specifier>]


Where: 

   -i <deviceId>,  --index <deviceId>
     Target specific devices. The specified id may be the GPU's index in
     the natural enumeration, chip serial number, uuid, or PCI bus ID(as
     domain:bus:device.function in hex). Multiple devices can be combined
     as '0,1,5', '0-2' '0-4,6', 'GPU-2f8ab36b-882a-0248-494e-0da5d8ae9698,
     0000:03:00.0', 'all'

   --die <dieId>
     Target specific die index.

   -l <ms>,  --loop <ms>
     Display until Ctrl+C at specified millisecond interval, default(1000)

   -c <count>,  --count <count>
     Collect specified number of samples and exit, 0 represents forever.

   --format <specifier>
     Output format specifier:
        csv - format dmon output as a CSV
        noheader - remove header and device id

   --show-temperature
     Display temperature

   --show-board-power
     Display board power

   --show-usage
     Display VPUE,VPUD,GPU usage

   --show-memory
     Display memory usage

   --total-memory
     Display total memory

   --show-index
     Only valid when noheader is input, display GPU device id

   --show-render
     Display GPU render id

   --show-bdf
     Display GPU bdf id

   --show-clock
     Display brief clock frequency

   --,  --ignore_rest
     Ignores the rest of the labeled arguments following this flag.

   -v,  --version
     Displays version information and exits.

   -h,  --help
     Displays usage information and exits.

   MetaX GPU System Management Interface
