# 三项机制检查：开发研究，独立于正式原表实验

固定基线仍是 `clean-v1-20260909` / `clean-v1-eval1-20260909`。本目录是临时机制研究，所有整网输入来自作者 NI0–7/MH0–7 开发样本。没有生成新轨迹、构造新质量基准或修改 FT、模型、FA/FLA、作者指标。算子反例只验证数学性质，不能代替原数据集实验。

## 1. 归一化与重复变量：结构性反例成立

直接调用冻结的 `rmsnorm_secant_pullback` 和 `matmul_secant_pullback`。取 `x0=(3,4), x1=(0,10)`，`n=x/||x||`，共享变量出现在 `n.T@n` 的两条输入中。四种原/基线坐标组合的真实输出都是1；实际自动微分也返回零。当前有限规则的来源贡献却为 `(-0.108,+0.108)`。总和守恒，逐来源的常量函数零贡献性质失败。

实际 `epsilon=1e-6` 时，函数不再严格恒定，因此单列：真实单坐标删除效应约 `-8.26e-10, 5.25e-8`，原规则分配仍约 `(-0.108,+0.108)`。不是把 epsilon 的真实依赖误说成精确常量，也不是精度误差造成0.108。

两步 GDN 取共享归一化 key，`beta=(0.5,1)`、`v=(1,0)`、两步保留系数均为1、固定读取 `q=(0,1)`。第二步擦除第一步写入：`h1=0.5*n; h2=h1-n*(n.T@h1)`。在 epsilon=0 时四种坐标组合输出都为0，现有规则给出 `(+0.054,-0.054)`。该数值使用完整公开参数，不声称复现未给出参数的 ±0.03584。

进一步调用**原生公开 FLA**，被动记录真实 chunk 中间量，再调用冻结有限 FLA：旧归一化给出 `(+0.0543047,-0.0539141)`。这是实际后端检查；没有用显式递归替代原生前向。BF16 的输出及有限算子的舍入余项原样保留。

一个无可调权重的修正候选是令 `b=n0+n1`：

\[
S_*={2\over r_0+r_1}\left(I-{bb^T\over b^Tb}\right).
\]

因为 `b.T*Delta n=0`，且 `Delta x=(r0+r1)/2*Delta n+(r1-r0)/2*b`，它同时满足 `S_* Delta x=Delta n` 和 `S_*^T b=0`。epsilon 用固定附加坐标的解析形式处理；等端点退化为正确 Jacobian。实现只做向量运算和归约，O(d) 存储/计算，无新增注意力矩阵或 FLA 调用。

该候选把精确两步 GDN 反例归零；在原生 BF16 操作数下，残留为 `0.0002344,0.0001563`，不是宣称逐位/全算子精确。归一化端点关系、交换对称、等端点 Jacobian 的72组检查最大误差 `1.43e-14`。它只解决上述归一化恒等关系，**不能据此声称任意组合恒等关系或 NI 问题已解决**。Qwen3 同样使用原归一化规则；需要研究 GDN 的重复 key 结构是否使它在 Qwen3.5 更突出。

执行脚本：[常量范数](check_normalization_identity.py)、[原生两步 GDN](check_native_gdn_identity.py)、[几何候选](normalization_geometry.py)。第一次原生检查的捕获字段计数断言写成11而实际为10，失败保留；修正的是测试断言，原生框架未变。

## 2. content1/P1：条件性分配偏差成立，优劣仍需整网验证

`P1*Delta V + Delta P*V0` 把全部交互分给内容。当 `V0` 在有关位置相同，`Delta P*V0=0`，但原输入不同的 `V1` 上路由变化可以改变输出。其控制效应被分给内容，符合当前分配约定；这不是丢失了总效应。只有进一步追到来源，才能判断这种分配是否损害 token 排序。EOS 输入不意味着所有层/位置的实际 V0 都相同。

三种全24层统一对照已在 NI0、NI3、NI5、MH0 运行：仅输出 norm-gate 对称、仅整个有限 FLA 做端点平均、两者同时。FA、MLP、原生模型不改；不存在按层、样本或数字标签定制。FLA平均是两个完整有限 FLA 系数的平均，**不是逐个递归乘积的 Shapley 平分**，额外成本也未隐藏。

这些小样本显示一些改善，尚不是稳定根因修复。原生运行间约0.2%–1.76%的向量差和部分共同评分输入的数值变化均被记录，不能把旧控制/新候选的小差值都当成方法效应。来源：[原始结果](pilot_results.json)、[核验与逐例数据](pilot_summary.json)、[完整向量](pilot_vectors.json)。`matched16/` 仅是已准备、**未启动**的扩展，因归一化结构问题被提到更高优先级而保留待定。

## 3. RISE/MAS 分开视图：适配确需修正，但不是早段反转的原因

RISE只使用排序和模型响应，不依赖贡献密度；MAS使用密度且响应被截断/单调化。本次正式入口修订因此为 RISE 使用有符号排序，MAS 保留正值视图，原作者函数保持不变。明确区分两条曲线，不能把有符号RISE拼到正值曲线里伪装成一次原函数返回。

全部32个原开发样本的前20%删除 token 都为正分，裁零不改变这段排序。Qwen3的16例、Qwen3.5的8例在进入负分前已经被原RISE响应压到0，随后重排不可能改变该次曲线的RISE。另8例及NI5直接检查已用原函数重新评分，实际差异只可能来自尾部排序及记录到的运行间数值差异；3个NI例出现共同输入的评分变化，不能将跨运行差值作为纯裁零效果。MH的尾部排序影响有改善也有退步。

正式入口只在严格正分排序与原单调归零响应证明结果相同时复用原RISE返回值，保存证明；否则实际再调用原作者函数，完整记录成本。MAS不会使用有符号调用返回的MAS值。冻结标签及清洁方法文件不改。

修订入口已在Qwen3和Qwen3.5各NI0/MH0运行，共4例；复用证明和额外有符号原函数评分两个分支都执行通过。同次Qwen3.5 MH0的正值RISE为0.231993、有符号RISE为0.222203；MAS保持正值评分的0.355128。[入口验证](score_views_smoke_summary.json)。已有NI8曲线还给出更强界限：非正分尾部即使达到最好响应，也最多改善均值0.004844，占当前净差距28.6%，因此不能解释主要NI差距。[上界](rise_tail_bound.json)。

来源：[全部32例顺序检查](rise_signed_order_audit.json)、[原函数有符号评分](signed_rise_results.json)、[共同输入数值变化审计](signed_rise_summary.json)。

## 原删除反转的复核

NI5的两个固定44-token集合：DT估计 `142.699/81.190`（有符号），实际下降 `77/138`，确有反转。正值估计第二组是83.867，不能与81.190混写。NI3的前10%数字数是DT3、FT K1为8；这里“数字”指作者gold句内的数字token，不等同于独立证明的因果关键token。

使用实际输入token与对应模型tokenizer核对后，Qwen3.5 NI8的首批删除中，确实8/8例DT删除的gold句数字token少于FT K1；Qwen3则为6例更多、2例相同。这个跨模型差异存在，但它是排序现象，不能从中直接指定某个传播算子为原因。[完整计数](digit_counts.json)。

严格按0–20%梯形区间计算，该段占Qwen3.5 NI净RISE差距65.8%；76%的说法把20%处的节点按整份权重归入早段，不是同一个区间面积。Qwen3也出现局部集合反转而整体RISE优于FT，因此“有反转”不能单独定位GDN根因。详见[曲线审计](existing_curve_audit.json)。
