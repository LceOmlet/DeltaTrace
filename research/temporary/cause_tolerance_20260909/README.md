## 真实16例：顺序门假说尚不足以解释NI差距

[汇总与逐例核对](qwen35_real_gates/summary.json)、[384层原始统计](qwen35_real_gates/results.json)、[分支向量](qwen35_real_gates/vectors.npz)已完成。17次根前向包括1次原生初始化和16次DT；没有评分或生成。输入身份、全部层和向量哈希均核对。

诊断事件预先定义为：某个窗口在原输入下的标量保留率至少`exp(-1)`，EOS基线保留率却低至少10倍。它测条件是否出现，不测真实删除效果。

| 窗口 | NI：占原输入仍保留窗口的比例 | MH：同一比例 |
|---|---:|---:|
| 16 token | 2.18% | 2.57% |
| 64 token | 4.80% | 5.62% |
| 128 token | 7.08% | 7.12% |

因此，算子反例的相关条件会在真实任务出现，但在NI/MH中频率接近，部分尺度反而MH更多；不能直接把它升格为NI特有差距的主因。这不是对该机制的彻底排除——它可能落在不同的重要证据位置——但在追到真实删除集合前，没有依据做全网门修补。中间分支池的g绝对质量约占NI7.1%、MH6.4%；该池跨层重复计算，不能说遗忘门解释了最终输出的这些百分比。

另记录一项数值混杂：本次MH8的完整DT向量及原生根效应与旧恢复运行完全相同；NI8相对更早运行的向量L2相差1.50%–2.66%，原生根效应也已不同。尚未确定这种跨运行差异的来源，不把它当作observer导致的方法变化，也不把历史指标赋给新向量。后续质量候选必须同次比较，先分开原生端点差异与有限传播规则差异；不因这些微差改写官方框架。

## 第三轮：早期删除错配并非Qwen3.5独有

[实际曲线复核](ni_curve_structure.json)逐项验证原删除输入哈希和原RISE面积；[删除集合检查](early_deletion_sets.json)用同一份冻结DT向量分别求DT/FT实际所删集合的贡献，并读取原生实际下降，不运行新模型。前20%所删DT分数全部严格为正，所以这段排序不会被裁负修正。

| 原NI8，10%删除预算 | Qwen3 | Qwen3.5 |
|---|---:|---:|
| DT集合实际破坏小于FT的例数 | 6/8 | 6/8 |
| DT集合实际破坏大于FT的例数 | 2/8 | 2/8 |
| DT原RISE曲线10%内触底的例数 | 4/8 | 0/8 |
| FT原RISE曲线10%内触底的例数 | 4/8 | 0/8 |

这否定“只有Qwen3.5出现整段贡献与局部删除错配”的归纳，不能据此直接归罪GDN。Qwen3 NI1/NI2/NI5在10%删除时DT实际破坏均小于FT，但两条指标曲线都已为零，后续破坏强弱不再影响RISE。这是原指标的直接截断行为，不是更换指标的理由；原RISE仍原样报告。DT集合在固定分数上更高本来就是排序定义，所以该排名反转统计不能被当作某个有限规则的独立因果证明。

Qwen3.5 NI8的DT−FT RISE均值差为+0.0172828，其中前20%面积贡献+0.0111861（64.7%），后段+0.00609669（35.3%）。应使用这份有符号原8例的实际分解，不沿用其他样本/视图下的“76%”。仅假设最终标量在观测到的FP16/BF16网格上作最近舍入，Qwen3.5均值差的保守包络仍为[+0.00964,+0.02492]。**该包络只界定最后总分的舍入，不界定内部log-softmax、模型、FA/FLA或归因误差，也不是高精度评分实验。** 最后一次BF16舍入不足以单独解释当前胜负反转，不应据此改评分框架。

本轮没有足够证据支持新的简明、可泛化质量修法，未改分配规则。后续应分开核对共享的有限差—局部删除错配、RISE触底造成的观测差异和GDN可能额外引入的偏差；只有追到同一删除集合的真实计算路径，才值得再做统一规则修复。效率方向保留已发布的两模型同步优化；下一步若继续batch，应先剖析长输入重放/有限矩阵形状成本，不扫描数据集特定分组阈值。
