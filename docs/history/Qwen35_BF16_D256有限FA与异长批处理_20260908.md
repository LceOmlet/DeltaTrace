# Qwen3.5 BF16/D256 有限 FA 与异长批处理

现有 content_P1 有限 FA 核心已扩展到 Qwen3.5 的 BF16、D256、16个Q头/4个KV头及605/368异长 batch，并在原始 decoder3 操作数上执行。默认模型 FA 保持原样。当前只完成注意力核心；标准注意力的完整输入系数、decoder/MLP、答案目标和整网成本仍待接入。本轮没有新增质量结果。

## 实现边界

[内核](../../research/prototypes/vendor_fa_finite_p1_bf16_d256.cu)从已保存的 shared-mean-reuse 版本派生，继续复用 MetaX-MACA/mcXformer `aef88de756194e077460a1c8b8b341baa429259a` 的 FA traits、分块拷贝、MMA、转置乘法和行归约。厂商头文件未修改。三遍传播、logarithmic-mean softmax、对称 Q/K 规则和 content_P1 的 PV 规则均保留；没有调最终分数或改变方法来获得加速。

新内核使用 BF16 矩阵操作数/乘子，FP32累积和非线性归约，32×32块、2个厂商warp，每阶段32 KiB共享内存。长度仍作存储步长，每个样本另有有效长度；部分尾块正确遮蔽，完整 padding 块直接写零并跳过运算。K/V输入保留4头，输出K/V系数由调用者按4组在FP32求和。有效长度在CPU验证一次，设备缓冲复用，不在每次有限调用中同步读取长度。

生产核心只有线性长度的操作数、Q/K/V系数和两组行统计量，没有全局 T×T 或额外全局 Q/K平均张量。独立CPU数学复核也按32行分块，但它只作诊断，不进入归因、质量或计时路径。

有限框架版本仍为 FA2.5.3，实际默认模型包为 FA2.6.3+MetaX。二者不是同版源码，也不据此宣称任意未来FA版本无需适配。[运行时](../../research/runtime/vendor_fa_finite_bf16_d256.py)只调用独立命名的有限算子，不碰安装包私有ABI。默认模型通过原公开FA接口执行；LSE另用一次公开 `flash_attn_varlen_func(return_attn_probs=True)` 获得，调用成本完整计入。实际LSE为16×1946，按公开padding helper恢复；未返回的概率缓冲为 `None`，没有解码或使用。

## 真实来源与数值

使用上一阶段已保存的原始 root 第3层输入，只加载原始 decoder3 类的11个参数。加载沿用官方 `get_init_context` 和 `_materialize_copy`，全部实际参数BF16，原始checkpoint与加载后哈希分别记录。位置和mask来自原始纯文本/no-cache流程及官方RoPE/mask helper；部分旋转长度64。被动捕获代码不替换任何模型函数。

本例 decoder3 重放相对原 root 输出差为0，公开辅助FA输出与模型默认FA输出差也为0。这是该案例的观测结果，逐位一致不是新增验收要求。每个成功重放只观察到一次默认FA调用。全树2853个Python源码前后核验相同，原先已记录的三处FLA适配未新增修改。

## 成本与失败账本

有限核的唯一热调用为8.329 ms，新增峰值39.805 MB。公开辅助FA含LSE为0.998 ms；原生FA backward为1.960 ms。有限调用处理B2双端点，普通反向处理B4（基线cotangent为零但原生计算仍执行），且各方法只测一次热/诊断调用。这些数值不构成公平稳定的速度胜出结论；本次有限核心仍明显慢于原生FA，不能称为FA速度。

有限测量包含接口转换、输出分配和三次内核launch，排除了端点捕获、投影/非线性传播、GQA输出归并及最终归因。绝对峰值还包括诊断驻留张量和前一次输出，不能冒充整网峰值。没有与FT在该模型上重算完整成本。

失败和恢复均保留：

1. 首次编译45.67秒失败：厂商traits在主机编译阶段用half类型，与写死的BF16参数指针不匹配。采用原生FA同类的无类型参数存储、内核内类型解释后，第二次编译47.73秒成功，库439280 B。没有修改厂商头文件、设备精度或传播式。
2. 首次decoder重放后，FA最大长度是标量张量，JSON序列化失败；原始结果最后状态仍为running，但进程已终止且日志有未捕获异常。不能把该旧状态当作活任务。此次局部decoder重放0.565秒计入成本，未执行有限核。
3. 第二次重放已提前保存351670618 B的实际操作数。辅助公开FA返回概率缓冲None，旧检查错误调用numel后中断；此时仍未执行有限核。接受None/空张量后，从保存操作数恢复，无新decoder加载或重放。

累计：两次编译（一次成功），两次原始decoder参数加载/重放、两次公开辅助FA前向（含一次观测中断）、一次原生FA反向、三次有限调用/九个有限内核launch；完整模型加载/前向、新生成、质量查询及整网归因均为0。实际任务均已终止。源码、协议、结果、错误日志及离线复核进入仓库；原始激活/向量和编译库留在私有备份中，文件哈希公开记录。
