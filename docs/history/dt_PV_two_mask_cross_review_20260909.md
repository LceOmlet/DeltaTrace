# P0 第19层：双删除背景交叉审计

本次只有 CPU 代数，复用已完成四个作业的16次 DT、336次原评分；没有增加模型查询。C 表示原当前方法，P0 表示仅第19层改内容分配的候选。

结果表明：**在 C 和 P0 各自选择的删除背景中，8例的固定背景误差 AUC 都降低；但换成 P0 自身的删除排序后，NI0、MH1、NI3 的自身误差 AUC 比 C 自身更高。** 因而“固定 C 删除集合上的改善”不能代替完整方法评价。实际 RISE 有6例退步，MAS 有 NI0、MH1 两例退步；needle 在 NI0、NI3 各少恢复一个 gold token。

误差定义为

\[
E_{a,b,t}=\sum_{i\in A_{b,t}}s_a(i)-[G_b(\varnothing)-G_b(A_{b,t})],\quad a,b\in\{C,P0\}.
\]

每个背景 b 均使用它自身**真实保存**的原评分曲线。表中 MAE_AUC 是沿原21步均匀轴 t/20 对绝对误差作梯形积分，单位仍是 logprob；它不是原 MAS。主账本用实际评分的 FP32 prompt 分数在 CPU FP64 中求和，完整 FP64 向量另行复核，最大差小于9.1×10⁻⁷。同一作业内所有相同输入的两曲线原分数完全相同，没有把评分漂移混入背景差异。

固定 C 背景的19内点比较共148胜、0平、4负；固定 P0 背景为139胜、0平、13负。后一组确实暴露更多局部退步，不能用净 AUC 改善隐去它们。JSON 保留全部两方向21点、最大误差、退步步号、正负误差及实际输入哈希。

设 A(a,b) 为表中的 MAE_AUC，自身路径差可以严格写为

\[
A(P0,P0)-A(C,C)
=[A(P0,P0)-A(C,P0)]+[A(C,P0)-A(C,C)].
\]

NI0 是 −0.8780 的固定背景系数改善，加上 +1.6492 的背景变化，最终 +0.7712；MH1 是 −0.6345 加 +0.8399，最终 +0.2054。报告也保存反向分解：先固定 C 背景改变系数，再固定 P0 系数改变背景。两者是观测量恒等式，不是唯一的因果分摊。

因此现有证据支持“在两组已测固定状态上，候选的整体幅度预测更接近真实删除作用，但其排序选择的删除路径可以更差”。不支持“P0 在自己选的新状态上整体系数都变坏”，也不支持“幅度已普遍修好”。原 RISE 的退步直接表明候选自身删除次序在原目标上变差；MAS 还受归一化密度和作者后处理影响，不能全部归为排序。NI3 自身 MAE 增大但 MAS 改善，正说明两者不等价。

NI0 原10%预算为31个 token、可计 gold 为40个，恢复16→15。top-K 阈值两边均唯一，无 tie 排序歧义。退出位置为3、91、137、334；进入为83、295、297、319。退出 gold 91 的名次31→40、137 的名次28→34；进入 gold 83 的名次34→27，故净少一个。这里只核位置与实际分数，未 decode 文本。
