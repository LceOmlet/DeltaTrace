# 原生输出头选行配对与下一大头

2026-09-08。官方 `logits_to_keep` 路径已完成四次完整NI0归因及84次原评分，并设为当前dense DT驱动的默认选项；保留显式完整行选项。实际模型FA/FLA、完整词表和有限传播公式均不变。该改动避免不需要的输出头行，但本例没有显示明显的整网速度或全程峰值改善，停止输出头微调。

## 实测

同一模型常驻，原输入588token，固定响应248token。完整输出行A与选行B按A0→B0→B1→A1执行，每次独立运行真实双端点root、32层真实重放及有限传播；不复用归因激活。选行仅使用原模型参数，真实`lm_head`输入从[2,588,4096]变为[2,248,4096]，预测位置339–586，词表248320保持完整。

| 本例后两次热调用 | 完整行A1 | 官方选行B1 |
| --- | ---: | ---: |
| 完整归因，含同样观测 | 0.8397秒 | 0.8347秒 |
| 真实root，含CPU检查点 | 0.1674秒 | 0.1594秒 |
| 实际logits输出 | 584,048,640字节 | 246,333,440字节 |
| root峰值allocated | 19,480,533,504字节 | 19,146,887,680字节 |
| 全程峰值allocated | 20,118,682,112字节 | 20,118,688,256字节 |

输出减少337,715,200字节（约337.7MB），root峰值减少333.6MB。全程峰值没有下降，峰值发生在其他阶段；选行多出的约6KB不作问题。后两次完整归因只差约0.6%，单个固定顺序热调用对不能建立稳态加速结论。

A0第一次完整归因为7.8535秒，B0第一次选行为0.8428秒。不能把二者之比当作约9倍选行收益：首次root、finite边界和编译/缓存准备成本不同。候选和对照共用常驻模型及编译对象；reserved共享allocator高水位不能用来判断选行有没有减少瞬时分配。

四次实际完整归因向量、符号、目标logp及四条原始删除曲线均完全相同。这是本次观测，不将逐位相同变成今后的通用要求。四次needle均为37.5%，RISE为0.178474，MAS为0.349135。该轮原评分clean为−126.5，历史轮为−125.5，因此只用本轮配对检查质量保持，不用与旧MAS的微小差异宣称质量变化。

CPU小索引检查还覆盖两个样本具有重复预测位置的union/gather；它只验证索引，不是多样本真实模型或吞吐测试。当前dense驱动仍只接受无padding、等长端点，真正异长minibatch尚未完成。

## 当前更大的成本

在同一B1选行热调用的0.8347秒内，组件粗分为：

| 组件 | 时间 | 占完整归因 |
| --- | ---: | ---: |
| 32次原decoder重放，含被动捕获 | 0.3209秒 | 38.4% |
| root，含CPU检查点 | 0.1594秒 | 19.1% |
| GDN所在decoder的有限传播 | 0.1577秒 | 18.9% |
| FA所在decoder的有限传播 | 0.0696秒 | 8.3% |
| 其他、观测和调用间工作 | 0.1173秒 | 14.1% |

其余为种子/最终norm/辅助FA等。两类finite decoder计时都包含各自MLP、norm和mixer，不等于只计FLA或只计FA内核。重放计时包含真实模型和被动捕获，不能把38.4%全部扣掉后承诺相应加速。

工程下一步应审查32层重放、捕获与搬运的必要性及批处理摊销，保留实际模型算子和真实端点。若尝试在root中保留更多真实中间量以减少重放，必须同时记录CPU/GPU存储、长序列线性增长与完整峰值；没有在本轮实施该策略。这个短NI0只说明当前大头，不能宣称长输入FA空间耗尽。

## 质量下一步

四例MAS失配的结论保持不变。独立代码审查提出[真实条件误差分解](../dt_conditional_error_diagnostic_design_20260908.md)：用原评分已有的同后端B1 clean/删除/全EOS前向，与冻结DT系数按边界收缩，分别记录评分精度、logprob种子、投影、norm、decoder和输入映射的误差，并核对B2→B1端点迁移及MAS分母差。该诊断尚未执行，不能据此认定FLA或某一门控已经出错。

先定位误差再改方法。GDN输出门控从现有content1改成对称分配只是有条件的候选；不改FT、不按曲线缩放最终分数、不恢复已失败的MLP内容优先候选，也不默认增加端点或第二遍传播。

## 成本与来源

远端任务292732已终止，运行69.80秒：一次模型加载、一次原顺序eager B1诊断、四次完整DT归因、128次实际decoder重放、128次有限decoder、32次公开FA辅助LSE、84次原评分；零FT归因、零生成、零新增样本。累计向量存档、清理和CPU needle时间单列，存档不进入用于比较的完整归因计时。开发、传输和离线核验不是这69.80秒的一部分。

原指标函数、原评分器和FT源码哈希前后不变；固定raw输入formatter视图仍显式保留。原曲线由NumPy独立复算，误差低于1e-12。相关证据：[完整核验](../../evidence/dt_native_logit_rows_NI0_summary_20260908.json)、[原始输出](../../evidence/dt_native_logit_rows_NI0_20260908_v1/results.json)。研究目标尚未完成，选行兼容与一次小配对不是总体目标完成。
