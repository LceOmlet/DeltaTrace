# Qwen3.5 有限 FLA：三次收缩复用与阶段收口

本次只完成预先约定的一个局部候选，预算已关闭。保留为显式可选实现，默认关闭三次收缩复用；不追加收缩变体或精度扫描。接下来处理归一化、门控、卷积及整网目标传播，不能将本报告当成 Qwen3.5 整网归因已经完成。

## 改动与真实执行

[运行时](../../research/runtime/finite_fla_gpu.py)新增 `reuse_scalar_products` 开关，默认 `False`。通过内积转置关系，复用计算 dq/dk 已产生的 `Z @ H0.T`、`W @ H0.T`、`u0 @ D.T`，取代衰减系数中另外三次矩阵乘法。实数代数不改变 content_P1 的有限分配规则；BF16 舍入位置有变化，尤其 W 原为 FP32，复用分支经过 BF16 GEMM，不能宣称逐位等价。

使用已保存的真实首层双端点前缀 B2/T129/H32/K128、同一固定伴随；候选与逐字节保留的上次编译实现，在同一进程中比较。模型默认 FA、原生 FLA 伴随及 2,853 个模型/FLA 源文件在本任务前后保持一致。只使用官方 torch.compile/Inductor、厂商 BF16 GEMM 和已记录的有限衰减扫描扩展，没有新写模型或注意力实现。

本轮执行了新包装的 `True` 分支及归档旧实现。新包装的 `False` 分支保留原有收缩公式，未单独重跑，不能把归档旧实现的计时直接标成新包装默认分支的实测。

实际编译为两个完整图、无 graph break；生成源码和 kernel 记录已保存。两个生成图分别含15与18个 `extern_kernels.bmm_dtype` 调用，编译器外部调用总计数35还包含其他操作。诊断 kernel 数为42与45。编译器另外记录97次 GPU benchmark 函数调用，内部重复次数未计数；`max_autotune=False` 不代表没有任何默认调优。
