# GDN1 K 归一化错配：从实际根因到固定八例原指标

2026-09-09。当前 C 保留第0层对称 norm-gate、完整 FLA 端点平均与标准注意力 P1。新候选只改变 GDN1 的 K 有限归一化。FT e81b3be、真实模型、默认 FA/FLA、作者数据与原 scorer 均未修改。研究 Goal 仍未完成；这是一项有明确计算机制、但收益有限且有退步的修正，不是解决所有 MAS 差距。

## 1. 先把真实错配分开

复用 MH2 保存的真实原生 GDN1 状态和当前上游系数，按同一个原删除集合比较预测与真实规范化输出变化。原生 FLA 的定义是 n(x)=x/sqrt(sum(x²)+1e−6)。当前有限规则与该定义匹配，头复制与归并核验通过；没有为了诊断改官方框架。

设 rᵢ=sqrt(sum(xᵢ²)+ε)、x̄=(x₀+x₁)/2。当前规则为

\[
S_{01}=\tfrac12(r_0^{-1}+r_1^{-1})I-\frac{2\bar x\bar x^T}{r_0r_1(r_0+r_1)}.
\]

它严格满足相应解析归一化的端点关系。但实际部分删除后的 K 为 xA，原输入为 xC，其半径、方向都与 EOS/原输入这对端点不同。把实际条件的同型恒等式 SCA 与固定 S01 相减，得到两个可独立核对的机制项：逆半径缩放、径向反馈；原生数值边界另列。所有本表收缩都在同一 token/紧凑 key-head 坐标，符号为预测减实际，不混用前轮 FA 的 query 与 key 坐标。

| MH2 GDN1 K | step3 | step10 |
|---|---:|---:|
| 实际总错配 | +1.700541 | +3.965451 |
| 逆半径缩放错配 | +0.520894 | +1.531721 |
| 径向反馈错配 | +1.181422 | +2.449727 |

| 当前系数精度项 | 约−2.4×10⁻⁷ | 约−2.1×10⁻⁷ |

中段径向项绝对和7.0710、缩放项绝对和5.0592、总误差绝对和10.1205，正负数值均保存；不是仅看净值接近零。较大的几行中，固定规则给径向分支分配正作用，而实际条件下该正作用明显较小或变成负值。比如 token29/head11 的固定径向响应+0.123315，实际解析条件响应+0.025426；token67/head11 则为+0.041915与−0.005425。这些是内部 K 边界的位置，不是原输入证据的直接标签。

## 2. 有正确公式的候选也可能失败

首先实现了沿固定 EOS→原输入线段精确积分 L2 Jacobian 的解析规则。只需 rank-two 加单位阵的作用，O(D) 计算/内存，无数值积分步数和额外模型前向；32个预先均匀选定的实际端点行，用128点独立高阶积分核验数学公式。核验相对误差约7.9×10⁻¹⁶，端点关系也成立。

但真实早段/中段误差由1.70/3.97变成2.59/5.85，逐 token/head 绝对误差由6.39/10.12变成8.27/13.19，明确拒绝，不接入整网。积分核验只是公式检查，不是额外基准或原生 forward。实际部分 K 偏离端点连线的距离，按当前绝对误差加权约为原输入半径的40.7%/51.9%；把 EOS 连线上的响应算得更精确，并不保证这些其他方向更准确。

证据：[解析路径候选否定](../../evidence/dt_MH2_GDN1_K_path_scout_summary_20260909.json)。CPU 6.50332 秒；默认模型及归因源码不因该失败候选改变。

## 3. 本次进入完整测试的规则

新规则只在端点连线方向补足有限差关系，在垂直于该连线的方向采用原输入的局部响应。令 d=x₁−x₀、Δn=n₁−n₀，J₁为上述归一化定义在原输入处的解析 Jacobian：

\[
J_* = J_1+\frac{(\Delta n-J_1d)d^T}{d^Td}.
\]

d=0 时使用 J₁。J*d=Δn；对 dᵀv=0 的变化，J*v=J₁v。规则无需观测删除集合、gold 或评分；候选只收到正常双端点和上游系数，没有调连续权重或最终分数。这不是对称/半正定保证，也不自动保证实用性；原输入局部响应仍可能不适合大幅条件变化。J₁在此是有限归因算子的解析组成，没有声称执行了原生 backward。

选择此规则的证据边界：实际部分状态的平均相对半径距离，到原输入约0.182/0.196，到 EOS 约0.280/0.278；但更接近原输入的误差加权比例只有51.0%/47.4%，不是所有行都满足。相同构造思想此前在 FA softmax 和整体衰减上失败，不能据此宣称普遍优越。本次必须单独验证具体 K 边界。

## 5. 复杂度、真实调用与未完成范围

每次归因仍是8次有限FA/24阶段、25次有限FLA/50次原生adjoint阶段、8次公共LSE与32层原生重放。候选只在GDN1替换一次K有限归一化，O(BTHD)元素运算与归约；没有增加模型前向、矩阵乘法或积分端点，没有物化全局T²矩阵。规范化属于向量归约，继续用现有Torch算子；没有重写注意力、FA或模型。接口仅在两份DT归因源码增加显式可选回调，默认未配置时仍走原L2规则。

4个完整评测任务共16次DT、336次原B1评分、4次模型加载与4次原NI0 eager初始化；128次有限FA/384阶段、400次有限FLA/800次原生adjoint阶段、128次公共LSE、512次原生decoder重放。8次候选K回调均真实执行。原指标任务墙钟合计 287.630699 秒，3项CPU任务合计 20.185451 秒，七任务合计 307.816150 秒。FT/生成/新FA扩展编译次数均为零。八例各自候选与C的实际allocated峰值均相同；这不等于所有长度或batch都没有额外内存。

全程成本含加载、初始化、归因、原评分和存档；冷调用/形状和执行顺序影响很大，不能据此声称加速或明显减速。峰值及每次观测保存在汇总。本轮不是新的热性能或真实mini-batch验收；过去C的batch结论不能自动转给候选。当前工厂默认配置仍是C，可选候选尚未推广。

八例显示MoreHop四例中三例MAS退步，停止此候选的性能/batch扩测，不作为通用修复纳入默认。保留可选研究入口和实际测试过的冻结源码；默认工厂仍是C。下一步针对退步最大的MH3做最小真实状态定位：它在两套固定删除背景上的幅度也变差，须区分K局部规则本身失配，还是下传至输入时邻接项出现新的补偿。只有局部机制和完整跨例质量值得继续时，才进入热性能和真实batch门槛。

更大的FA19内容参照/条件softmax、GDN遗忘映射等已定位问题仍在；不继续追逐已失败的解析路径，也不由这个小改进宣称整个MAS错配修好。后续修法必须解释实际条件变化、来源分配及邻接项的补偿，不能仅靠端点守恒或拟合已有删除曲线。
