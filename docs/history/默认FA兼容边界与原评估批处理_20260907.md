# 默认 FA、适配边界与原评估批处理

当前主候选继续为 P1：原 NI 恢复77.52%，NI/MH RISE0.05742/0.05848，优于对应最强 FT 的0.06193/0.11013。用户接受相对对称约0.38个百分点的恢复下降。完整旧门槛、逐例退步和成本见 PV 完整16条报告；没有改写旧门槛或宣告独立胜出。

新的执行优先级是效率、真实默认 FA，以及无需跟随 FA 私有版本反复移植的双端点边界。当前模型始终使用原安装的 FA；当前归因捕获仍依赖私有 `_flash_attn_forward`/返回槽位，不能称为已经满足通用兼容要求。公开 FA 参数和文档化 LSE 返回是下一步候选接口；额外调用的成本尚未测试，不能预先承诺高效。两端点有限传播仍不是默认单端点 backward，接口解耦也不等于已完成线性存储的有限内核。

批量评估已经实现：按相同提示与响应长度分桶，直接调用原 FlashTrace 的 `compute_logprob_response_given_prompt`。原函数本身支持 [B,N]/[B,M]。没有重写评分器、模型、gold、删除顺序、生成轨迹或精度。每行独立使用原 FP16 求和，实际删除状态同时包含 P1 与对应最佳 RISE FT。

冻结检验使用原 NI0、NI2、MH0 的六条完整21点曲线；B=1/2/4 每样本各预热一次、实测两轮并轮换顺序。计时包含构造实际删除输入、批次打包、原模型调用和 CPU 返回。结果：

B4 每42条轨迹实际执行11次根前向，B2为21次，B1为42次；不能把11次批量调用当作11个样本。全部研究连预热为453次根前向、777条评估轨迹、16,308次物理 decoder 调用、27,972条 decoder 轨迹，0次反向、0次新归因。归因与评估成本分开。三个样本 N=601/1241/861；本结论不能扩展为任意长输入或任意批量的性能保证。

在当前验证范围，后续原曲线评估优先 B4，保留可配置批量及明确错误，不自动隐藏 OOM 后重试。新实验应对所有比较方法使用相同批量协议并记录数值变化。多样本成对归因仍待实现：当前原归因 B2 只是一个样本的两个端点。真正多样本需处理各自长度、目标、有效 token/mask 和输出，不能用重复同一输入的吞吐测试冒充已经完成。

厂商源码的来源检查也已结束：MetaX 官方 mcXformer 提交 aef88de756194e077460a1c8b8b341baa429259a 含 FA2.5.3 的真实反向框架，78个文件按 Git 原始字节保存。首次 .cpp 暂存导致普通 C++ 模式构建失败；改回原 .cu 后未修改算子源码即可编译，约291.39秒，生成对象3,069,080字节。此处0次模型/归因/GPU核执行，没有安装对象文件或替换当前 FA2.6.3。编译通过不证明运行数值、效率或与安装二进制同源；其作为历史来源证据保留，已不作为默认运行时路线。
