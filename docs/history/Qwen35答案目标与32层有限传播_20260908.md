# Qwen3.5 答案目标与32层有限传播

DeltaTrace已完成一次真实Qwen3.5-9B的32层有限传播，包含24层GDN/真实FLA、8层标准注意力/默认FA、MLP、门控/归一化/残差及最终答案log-prob。使用作者NI0/MH1的固定轨迹和605/368异长B2有限批处理；本次不是质量评测，也没有同模型FT胜出结论。

## 目标和执行路径

作者重映射答案闭区间为NI0[209,246]、MH1[119,139]，共38/21个真实目标token。输入保留完整原固定轨迹，EOS基线只替换作者可归因用户位置。输出头用完整248320词表和独立lm_head权重；59个真实目标行及其两个端点合并为一次原始Linear调用，没有补造padding标签。

旧8B P1种子覆盖完整固定回答，本次9B显式限定作者答案sink；这是目标范围变化，不是PV/FLA有限规则变化。新结果不能合并进旧P1质量数字。FT解释的是同一答案段的表示贡献，DeltaTrace目标是该段token的条件log-prob；二者不因此变成同一个内部标量。原RISE/MAS仍由作者单独评测函数计算。

原始root输入已在先前任务保存，本次不再整网前向。复用原始layer0/3完整捕获，其余30层调用原始decoder并被动保存实际端点；每层有限传播后释放激活和该层设备权重。模型默认FA、实际FLA、厂商源码保持不变。所有31→0输入系数留档，没有生成新答案。

## 实际资源与限制

任务95.63秒，首次尝试成功并已确认进程终止。34次局部模块权重加载共26.39秒；30次原始decoder重放及GPU捕获共16.56秒，其中首个GDN冷重放16.16秒；8个有限FA decoder调用合计0.823秒，24个有限GDN decoder合计2.771秒，含首次编译/加载。头/最终RMS及其原生梯度诊断共5.472秒，七次公开辅助FA共2.589毫秒。

记录的计时段合计52.08秒，其余约43.55秒含导入、核验、诊断、系数/操作数落盘等未单独细分工作；没有把它从任务成本中抹掉。95.63秒在finally创建压缩review bundle之前停止计时，因此还不包括最终打包和SFTP下载。先前root前向及保存捕获的成本也不能当作免费生产缓存。

每阶段测量的最大设备峰值约2.592GB，发生在头/最终RMS原生梯度诊断；它来自逐层加载/释放权重的工程路径，不能与全模型驻留的一次反向显存直接相除。有限GDN每层新增峰值约776MB，有限FA decoder约172MB。无全局序列平方阶张量，不代表所有临时张量已最优。

官方编译观察为六个图、五个图缓存命中、一个新图，graph_break为空；观察到26次benchmark_gpu调用。主线程观察不精确覆盖调优内部重复/工作进程调用。原缓存35份及新增14份生成Python源码已按哈希保存。冷调用、权重IO和捕获诊断使本次不能用于宣称FA速度、稳定吞吐或相对FT加速；也不能据此宣布FA优化空间耗尽。

## 当前主对照与下一步

按用户最新要求，主对照固定为**同一实际Qwen3.5权重上的FT变体**。共享模型名称核验为Qwen3.5-9B；搜索还找到Qwen3-8B，未在已查目录找到Qwen3.5-8B。模型名称不能混用，更不能用不同模型的结果认定DeltaTrace胜出。

已找到并核对作者官方FT混合架构代码，固定到[e81b3be](https://github.com/wbopan/flashtrace/blob/e81b3be50a48dcfc652fbf1b530069b552736e66/flashtrace/qwen35.py)，共享副本与GitHub原文件逐字节一致。应以它为基线来源，同时审查结构适配问题，不能将有缺陷的基线当作容易击败的对手。

已确认源码问题：FT的通用RMS线性化用raw weight，而本模型普通RMS使用1+weight；混合输入三元组还未纳入标准注意力输出sigmoid门、GDN输出RMS/SiLU门。原变体要求B1/eager，GDN单位值探测产生每头T×T混合矩阵。单位值探测调用原生核本身不是影子实现，但其成本、维度变化、精度及原生FLA路径都需要明示；不能把小模型核心重构测试或自造smoke数据当作官方基准通过。详见[源码审查](../../evidence/qwen35_FT_variant_audit_20260908.json)。

下一步先固定同模型FT适配边界，保留原版身份和必要修复的明确差异，再用保存的真实FA/FLA操作数做小预算检查。默认模型FA/FLA、精度、轨迹、答案段和可归因位置保持一致；所有辅助探测、前反向、重放和缓存成本都计入。随后才做两方法的原指标小样本对照与完整路径剖析。质量对照同时保留FT0—3跳，不能用逐样本最优oracle或不同hop拼成不可部署基线。

完整层间传播已执行；通用生产API、同模型FT质量/公平完整成本和独立确认仍未完成。研究Goal保持active。详见[完整独立摘要](../../evidence/qwen35_whole_finite_summary_20260908.json)。
