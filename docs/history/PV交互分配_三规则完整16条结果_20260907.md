# PV 交互分配：完整原 16 条对照结果

已将三种离散规则改入同一整网有限差传播函数，并完成固定原 NIAH q2 0—7、MorehopQA 0—7 共 16 条开发样本的全部对照。按冻结的附加筛选“相对对称规则三个主要质量均值均不退步”，两种顺序规则都未通过；P1 的原因是 NI 恢复率小幅下降。这不等于它没有 RISE/MAS 收益，也不等于未通过对 FT 的原联合质量门槛。

每种规则、每个样本一次预热后实测三次，顺序轮换，FT both1 紧接每轮三规则测量。完整计时包含每次实际输入准备、真实批量双端点前向、36 次原生批量层重算、有限规则传播、CPU 分数返回；模型加载、研究日志序列化与额外 profiler 不属于一次正常归因 API 的计时。它们属于研究作业墙钟和研究成本，未伪装成免费计算。共享编译的首调用只作记录，不当作三种规则独立冷启动公平比较。少量百分比提速仍受计时波动影响。

六份真实 profiler（NI0、NI2 各三规则）核实每次 72 个原生 FA 前向核、253 次有原生 FP16 GEMM 执行证据的归因投影；同一样本三规则的实际总 GEMM 核调用数相同。对称规则有 144 次已链接到实际编译核的 midpoint 调用，两个顺序规则为 72 次；减少的是每层 PV 的两次平均，QK 平均保留。没有修改 FA 内核、原生反向或真实模型输出，没有混合端点模型查询。

初次核验在 NI2 两个顺序规则的第75次投影处失败：该 GEMM 的 profiler External id 缺失。原追踪仍保留唯一的 runtime launch correlation，并能连接到同线程 aten::mm 内的实际 GPU FP16 GEMM。核验器补充这条严格链路后全部253次覆盖通过；没有放宽调用数量、接受仅名称注释、补造追踪或重跑替换原实验。

源码只改变 PV 两个乘子：对称为 M·Vmean^T 与 Pmean^T·M；内容用 P1 为 M·V0^T 与 P1^T·M；内容用 P0 为 M·V1^T 与 P0^T·M。独立 AST 核对和不交换矩阵顺序的精确多项式检查均通过。全部其他有限规则、模型和 FA 代码/二进制哈希保持。当前 P 来自实际原生 Q/K/LSE 的显式 FP32 归因计算，不是 FA 返回的原生概率矩阵，相关近似误差与真实 PV 输出误差逐端点保留。

三个规则仍显式计算 N×N 归因张量。这次修改保持原强方法复杂度，不增加 PV 矩阵乘法，也不因此获得 FA 的线性注意力存储性质。此处的时间和显存通过范围仅限实际 16 条长度；长输入要求仍未解决。
