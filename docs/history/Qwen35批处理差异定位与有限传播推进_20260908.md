# Qwen3.5 批处理差异定位与有限传播推进

本轮两次原生前向、一次同 Q/K/V 的官方 FA 对比和一次官方 CPU 参考已完成并核验。批处理差异在标准注意力之前就已出现，不能只归因于 FA 的 dense/varlen 路径。保留默认 BF16 和实际 FA/FLA；不为旧 1% 筛查线改写后端、增加精度或继续铺开诊断。下一步进入 FLA 有限传播接入，而不是把原生数值差异当成无限前置任务。

## 核验结果

固定使用作者原缓存 NI0；B2 另带 MH1，输入长度为 605/368，右侧 padding。两个真实前向都执行全部 32 层，各有 24 次 FLA chunk、24 次 causal-conv 和 8 次默认 FA；未经过 Torch 模型回退或替换 forward。B1 使用 dense FA，B2 使用 varlen FA。

| 比较 | 相对 L2 差异 | 解释范围 |
| --- | ---: | --- |
| NI0 的 B1/B2 完整目标 log-prob | 2.4489% | 248 个目标位置；最大绝对差 0.233608，平均绝对差 0.010171。旧相对 1% 筛查仍失败，绝对 0.25 筛查通过。 |
| 同一实际 Q/K/V，dense FA 与额外一次原生 varlen FA | 0.08587% | 首个标准注意力层、605 tokens；最大绝对差 0.015625。仅算子对比，未替换模型中间输出。 |
| 首层原生 FLA 与官方 Transformers CPU 递推参考 | 0.35080% | 前 129 个真实 tokens，跨越 64/128 两个 chunk 边界；最大绝对差 0.015625。局部检查不覆盖其他层或 backward。 |
| 首层 FLA，B1/B2 前 129 tokens | 0 | 实际 Q/K/V、g、beta 及输出均相同；不外推全部 605 tokens。 |

FA 重放保持 Q/K/V 数值和 BF16，但上传时使用连续布局；原步长记录在证据中。因此这一对比衡量实际原生调用路径及布局组合的差异，不能孤立归因于某个 kernel。额外调用有真实 GPU FA kernel trace。

每个全层输出均比较 NI0 的 605 个有效位置。embedding 和首个 input norm 相同；首层 QKV 投影已有约 0.000144% 差异。前三个线性注意力层的输出差异依次约 0.0154%、0.1307%、0.3627%，均发生在第一个标准注意力层之前。到最后一层约 2.469%，最终 norm 约 2.833%。误差并非每层单调增长，也尚未用整网干预量化每个算子的因果份额。

这支持的判断是：原生批量形状相关的数值差异会在整网传播，FA 路径不同只是候选因素之一。它不能证明 FLA 或 GEMM 完全无误，也不能把 0.351% 的首层参考误差当作整网质量保证。原生两次前向的全部三个目标向量与上一轮相同，诊断 hook 未改变这部分输出。

## 来源、资源与保全

2853 个 Transformers/FLA 源文件前后核验一致，仅保留已记录的设备名称映射与 FLA state kernel 单处流水线调度修改。权重分片大小/mtime 前后一致，并沿用此前完整官方哈希核验；本轮没有再次读取 20 GB 权重重算哈希。实际选中的 state 调度为 BV=32、4 warps、1 stage。

预算严格为：1 次模型加载、2 次完整前向、1 次额外 FA、1 次官方 CPU 参考；0 次归因、0 条质量曲线、0 次生成。前向中的 CPU 数据保存与诊断 hook 属于诊断成本，不能作为稳态速度或归因显存。完整 NPZ 和 profile 随远端 ZIP 下载并校验 CRC；逐文件哈希核对，目标向量、FLA 前缀、FA 对比与保存的模块前缀在本地重新计算。

全层 605-token 比较由审查过的诊断代码计算，仓库保留这些统计与来源记录；独立重算的模块原始数组限所保存的 129-token 前缀，不能声称所有全层数组均已独立重算。完整诊断数组保存在本地和远端恢复包，公共仓库发布源码、协议、原始 JSON、数组哈希与派生统计，不发布模型输入文本或大体积激活数组。

## 下一决策

本轮诊断预算关闭，旧筛查失败保留；不再以追逐该 1% 数值线为由默认增加模型调用。继续使用实际模型每个 batch 的端点作为有限传播参照，原生与归因的差异分开核验，随后由原指标判断数值影响。

有限 FLA 接入先复用官方 chunk 状态重建和反向状态传播，再扩展混合端点的局部收缩。源码显示 native `chunk_gated_delta_rule_bwd_dhu` 不依赖内容 v 或基线状态的数值，其 endpoint1 状态伴随传播可复用；它返回的 dv 是 WY 块变量的伴随，不能直接当作单 token 更新的伴随。此边界已补入[有限传播契约](../qwen35_finite_extension_contract.md)，防止“复用 backward”时悄悄换掉有限规则。

Qwen3.5 的完整归因、gold/token 重映射、相同模型 FT 对照、质量与完整成本仍未完成。当前并不宣称战胜 FT、可靠条件删除符号或新模型完整支持。
