# Qwen3.5 同模型 FT 原生内容分解核验

主对照仍是与DeltaTrace使用同一实际Qwen3.5权重的FT变体，当前共享checkpoint为Qwen3.5-9B。本次完成两个真实层的内容分配适配：FA第3层、GDN第0层，各使用作者NI0/MH1保存的605/368异长B2操作数。没有调用新整网前向、重放decoder、生成答案或查询质量指标。完整32层FT及0—3跳尚未执行，不能报告DeltaTrace胜出。

## 实现身份：原生模型、明确适配、独立参考

| 部分 | 实际执行 | 身份和限制 |
| --- | --- | --- |
| 目标模型 | 先前保存的原始Qwen3.5原生FA/FLA真实端点；本次仅加载五个实际BF16参数张量 | 没有构造替代模型前向；未使用的原始模块保持meta且不执行。参数字节与先前真实decoder加载收据一致。 |
| FA内容伴随 | 公开flash_attn_varlen_func前向及其FlashAttnVarlenFuncBackward | 辅助调用将GQA的4个KV头明确展开到16个query头，保留逐头O投影信息；不替换模型原来的GQA调用，额外计算计费。 |
| GDN内容伴随 | 公开chunk_gated_delta_rule及其ChunkGatedDeltaRuleFunctionBackward | 固定真实q/k/g/beta，只消费value梯度；已归一化的捕获q/k不再次归一化。原生反向计算的其他梯度仍计入成本。 |

运行记录捕获了上表三个实际原生反向节点，并显示被计算但未消费的梯度。2853份模型/FLA源码在前后检查一致，模型源码和已安装FA接口单独校验。当前FLA环境仍包含先前记录的设备映射、单处流水线调度调整及上游两行WY修复；不是声称整个安装环境从未修改。此次没有新增原生算子源码修改，详见[原生FLA修复来源](Qwen35原生FLA反向与上游两行修复_20260908.md)。

DeltaTrace双端点有限传播本来就是明确标识的自定义归因规则及可追溯扩展，不能称为默认FA标准梯度。本次实现的是FT对照准备，未替换DeltaTrace方法。源码中没有把CPU参考、重写的注意力或替代模型当作原生执行。

## 内容分解为何成立

真实端点固定路由后，FA/GDN的core输出对value线性。对FT答案sink权重w及实际输出冻结增益d，原生value伴随计算r=J_Vᵀ(wd)，来源贡献为C_jh=W^O_h(v_jh⊙r_jh)。FA的d为实际sigmoid输出门；GDN为实际输出RMS缩放乘SiLU门。GDN的等效混合可以有符号，不是softmax概率。

本次FT答案位置为NI0绝对闭区间[566,603]、MH1[346,366]，分别38/21个表示位置。它与DeltaTrace解释同一作者答案段，但FT使用表示贡献，DeltaTrace使用条件log-prob，不能把两者内部标量说成相同。

GDN继续将post-conv内容分配到真实卷积前value来源。使用线性conv与固定sigmoid增益是端点内容分解，不将真实非线性导数混入后冒称代数相同。有限精度下与原始融合SiLU的差异完整保留，没有给最终token分数作残差补偿。

GDN原生卷积来源梯度相对独立CPU转置计算差0.16479%；线性conv乘固定sigmoid相对原始融合SiLU value差0.04726%；卷积前/后的总内容差0.03569%。固定head0/末head和来源位置7/59/200/300的O投影也独立核验：相对相同BF16输入的FP64乘积差0.15853%/0.16396%。全部实际padding贡献为0，token与残差分数合计约1。

这些检查包含每个head的重构，未仅依赖投影后相互抵消的总误差。记录足以关闭本次局部接入预算，继续整网FT，不因非逐位一致追加精度扫描；也不因此保证任意长度、其他层、排序、质量或删除符号正确。

原版结构遗漏也在真实输入上被量化：直接使用作者raw-weight RMS线性化相对实际普通RMS输出差81.29%；未门控core相对实际门控输出差967.79%/187.03%。后两项比较的是被遗漏的结构边界，不是完整原版FT的误差或质量下降幅度。不能以此虚构原版needle/RISE/MAS分数，更不能故意仅与结构错误的对手比较。原版源码身份继续保留，修正版单独命名。

## 实际成本与失败记录

第一次启动因协议漏带源码守卫字段，在导入Torch前停止；零参数加载、零GPU算子。v1的源码、协议、异常和终止收据均保留。v2只补齐协议字段，study和runtime哈希不变，没有重跑已完成的GPU实验。

v2任务55.84秒（最终ZIP之前）；有名计时段13.65秒，其余42.18秒含导入、哈希、CPU/GPU数据准备、诊断和NPZ保存，未从任务成本抹去。FLA辅助前向8.296秒、原生反向4.593秒，包含本次首次调用的编译/默认调优。FA辅助前向1.034毫秒、原生反向82.55毫秒；两类FT投影/聚合535.24/12.81毫秒，包含FP64诊断且首调用状态不同，不能据此宣布FA变慢或GDN更快。

加载五个局部参数张量约0.125秒；另有两次固定CPU审查用投影，已分别计时。记录阶段峰值745.33MB，包含局部参数和诊断缓冲；不是全模型驻留内存，也不能与DeltaTrace整网峰值直接相比。生产中不存在全局T×T矩阵或单位值探测，来源张量为B×T×H×D，投影按32个来源位置流式处理。辅助前向、被丢弃梯度、参考检查、以前的root保存成本及最终ZIP/SFTP都不可当作免费。

独立CPU审查18.93秒，两份向量及review包已下载、CRC/哈希核对；两个远端进程均确认终止。结果可恢复，不需依赖仍在运行的任务。
