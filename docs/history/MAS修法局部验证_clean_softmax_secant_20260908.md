# MAS修法局部验证：保留原输入响应的softmax有限传播

已实现并实测唯一的softmax候选。它以原输入softmax Jacobian响应为起点，在零行和与完整端点有限差约束下，作唯一的欧氏最小范数修正。数学依据及局限见[前一定位](MAS根因与修法_softmax条件斜率_20260908.md)。只修改有限传播的路由权重，原QK中点与P1内容分配、模型前向、默认FA/FLA、FT均保持。

中段下降1.814562，早段下降0.309240；原P1的dv系数逐位相同。它减少了已定位的条件路由过估，但没有消除该问题，尚无新MAS、RISE或needle结论。这里是实际保留操作数上的一次候选调用，没有用局部差额冒充完整输入修复。

FP32行约束最大残差6.33×10⁻⁶；16个单key退化行的目标残差均为0。最大修正系数0.002713，最小正方差0.068370。归一前后目标差总和5.53×10⁻⁶，数值变化如实保留。候选端点正项124.5804、负项−115.5992，明显存在抵消；这些数不是对符号可靠性的证明，也不能与不同粒度的旧统计直接比较。

更关键的反证风险是：当前完整输入早段误差为−2.321790。局部正误差减小可能使全网早段低估加重，必须继续整网传播，再调用原评测。后续采用同一softmax算子统一全部8个注意力层，以避免从已看过的MH1误差挑选层；这是一项待检验的一般化假设，其他层及变化后的上游可能推翻第19层局部收益。

实现直接复用已追溯FA框架的3个phase及原GEMM次数，没有新注意力前向或全序列概率矩阵。新增行归约，当前15行FP32状态（含诊断）在本例为336,960字节，比旧2行多292,032字节；不能据矩阵乘法次数不变推断耗时相同。一次编译49.188秒、局部任务8.344秒，1次候选有限算子、0次新增FA/模型/DT/评分/FT。私有激活仅留远端，Git保存源码、协议及可复核的收缩证据，不声称Git保存了激活。
