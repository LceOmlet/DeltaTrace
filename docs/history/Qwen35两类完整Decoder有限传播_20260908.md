# Qwen3.5 两类完整 Decoder 有限传播

已接通原始第3层标准注意力decoder与第0层GDN decoder的完整有限传播，使用原作者NI0/MH1固定轨迹、605/368右侧padding、原生B4端点及有限B2批处理。只用已有root层输入重放两个原始decoder，没有新增整网前向、生成或质量查询。整网答案归因尚未完成。

## 实现与来源

[新增运行时](../../research/runtime/qwen35_decoder_finite.py)保留既有content_P1有限FA、content1 GDN递推、对称SwiGLU/RMS规则。接入原始sigmoid输出门、Q/K的1+weight RMSNorm、64维部分RoPE、GQA归并、投影和两条decoder残差。Q与gate在每个head内部交错，GDN门控RMS直接使用weight，与普通RMS的1+weight区别保留。

使用原始类和官方BF16加载策略，两层分别11/14个参数。被动module hooks保存真实MLP/SiLU及残差边界；已有观察器捕获真实FA/FLA操作数，没有替换模型函数或backward。四个复合有限边界交给官方torch.compile，保留厂商BF16 GEMM；没有逐项另造融合内核，没有eager失败回退。FA框架版本与默认安装包版本的差异继续见前一阶段记录，不主张通用ABI兼容。

原生autograd节点实际执行记录包含FlashAttnVarlenFuncBackward、ChunkGatedDeltaRuleFunctionBackward和CausalConv1dFnBackward。安装包2853个源码前后相同；FA公开接口哈希未变。35个编译器生成源码保存并核对哈希，来源记录不替代数学验证。

## 完整向量复核

局部上游为实际原输入decoder输出，padding置零。它是工程诊断目标，不是答案log-prob。每层只执行一次冷实际有限传播、一次热正常传播、一次等端点传播；CPU NumPy/FP64独立重算全部输入系数的梯度差和有限效应。

| 原始decoder | 等端点系数相对原生梯度L2差 | 实际双端点有限效应向量残差 | NI0 / MH1 各自相对残差 |
| --- | ---: | ---: | ---: |
| 第3层标准注意力 | 0.5768% | 0.06306% | −0.05845% / −0.07310% |
| 第0层GDN | 0.4984% | 1.65939% | −1.5170% / −1.9061% |

两层实际、等端点、原生梯度的padding系数均为0，冷/热有限向量一致。所有重放内部的乘积、残差及输入边界核对差为0。第3层重放与保存root输出差为0；第0层相对L2差0.02466%，仍保留原生默认精度。

GDN的1.66%有限效应残差不能被0.50%的等端点梯度差替代；两者回答不同问题。也不能与上一阶段不同上游的0.641%直接归因比较。全部有符号贡献保留，不把残差强行分给token，不据此认定整网稳定或条件删除方向正确。
