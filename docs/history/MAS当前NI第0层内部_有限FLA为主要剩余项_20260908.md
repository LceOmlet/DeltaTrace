FLA 中段正项 +44.73601、负项 −23.08976，净 +21.64625。deleted 坐标 +15.33955、kept +8.12232、other prompt −1.67757、response −0.13805。这些是内部坐标上的收缩，不是单独输入词的因果信用。早段 FLA 为负并抵消其他项，故不能把局部 FLA 误差下降直接等同于完整 MAS 改善。

本次仍未证明某一个门控分支负责全部误差。beta 分支预测本身、中间量总守恒，都不能冒充条件错配的根因。下一步使用实际保存的 native chunk 状态拆读取、写入和遗忘的乘积错配；缺失的原生伴随只允许极小补捕获，不重新做模型前向。完整端点交换平均可作为一个有机制依据的候选，但必须与当前 norm-gate 修复组合后验证完整传播和原指标，不能沿用旧上游下的局部收益。
