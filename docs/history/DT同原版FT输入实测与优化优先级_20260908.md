# DT 同原版 FT 输入实测与优化优先级

按用户最新决定，将当前 DT 暂作胜出的工作版本继续优化，FT 固定为作者 e81b3be50a48dcfc652fbf1b530069b552736e66 的完整实现。本决定是研发工作基线，不把尚未测量的 RISE/MAS、跨样本质量或稳态速度写成实测胜出。以前自定义 FT 内容分配和控制器不恢复对照资格。

## 本轮实际结果

相同 Qwen3.5-9B 权重、作者 NI0 固定文本/生成轨迹、588-token 输入、310 个可归因位置，原 needle 在 top31 中恢复 40 个 eligible gold token 的比例：

| 方法 | needle | 完整归因时间 | 峰值 allocated / reserved |
| --- | ---: | ---: | ---: |
| DT content_P1 | 15/40 = 37.5% | 22.890 s | 20.119 / 21.081 GB |
| 完整原版 FT，0 跳 | 4/40 = 10% | — | — |
| 完整原版 FT，1/2/3 跳 | 各 6/40 = 15% | 一次完整三跳调用 30.731 s | 21.601 / 21.794 GB |

GB 为十进制。FT 各跳由作者一次完整三跳调用保存的原始向量得到，没有分别测量每个跳数的完整时间。DT 是单样本的双端点 B2、FA+FLA；FT 保留原版 B1、eager+FLA。输入相同不代表后端相同。这是历史开发样本上的比较，不是独立确认。

DT 目标仍为全词表上 248 个固定响应 token（含 EOS）的 log-probability 之和。仅将原 eligible 输入位置替换为 EOS。未改目标、原 PV content_P1、有限 FLA 或十个既有传播模块；只新增真实 dense FA 的被动观察，因为无 padding 时模型选择公开 dense FA 接口。FT 的方法目标仍保留作者定义。

32 个实际 decoder 重放输出与原 root 保存值在此次运行的记录差为零；8 次公开 FA 辅助返回值亦与实际注意力输出一致。NumPy 从保存的实际双端点输入和有限系数重新构造 588 维分数，误差小于 1e-9；所有非 eligible 位置为零，32 层有限效应账本闭合。端点总效应 165.195633，归因和 165.412048，未分配效应 -0.216416，即 -0.1310%。这不证明逐 token 删除方向正确，也不需要为这一级残差改官方框架。

DT 有 120 个负、190 个正 eligible 分数，原 needle 内部沿用正值截断。原始有符号向量完整保留。RISE/MAS 尚未执行；不得据此填入优劣。

同一常驻原模型的 clean eager B1 / FA B2 诊断中，逐目标 logp 相对 L2 差 1.7915%，最大绝对差 0.17708；整段和分别 -126.160005 / -126.235332。该差异包含 batch 形状影响，未分离为单独的 FA 误差；不能宣称后端完全一致。

| DT 已计入完整归因的部分 | 秒 |

| 全词表有限 seed | 2.2660 |
| 最终 norm 有限传播 | 0.8555 |
| 32 层原 decoder 重放 | 0.3496 |
| 8 次公开 FA 辅助 LSE | 0.00188 |

| 其他归因内诊断、拷贝、归档等 | 1.4541 |

有限 decoder 中首次标准注意力层 4.9477 s、首次线性注意力层 8.4981 s，其余 30 层合计约 0.212 s。再加首次 seed/norm，四次首调用合计 16.5673 s，占完整归因约 72.4%。代码使用官方 Torch 编译器，这些调用包含冷编译/调优及实际执行；尚未单独测出可消除的纯编译时间，不能直接减掉 16.57 s 当作热性能。

模型加载 18.2916 s、另一次 eager 诊断 13.4078 s 均单列；含启动、最终分数/系数导出等的任务时间 71.5291 s，结束后的 ZIP 打包不在该计时内。原归因输入与 packed logits 的诊断存档合计约 584 MB。所有工作收费范围在原 protocol/results 中保留。没有重启任务或新增 FT/删除/生成调用。

## 按优先级执行的 DT 改进

详细计划及停止条件见 [DT 优化优先级](../dt_optimization_priorities_20260908.md)。

1. 第一个质量候选只修改 SwiGLU 的交互分配：当前 MLP 仍用对称平均，测试由原输入门控取值分配内容变化；矩阵乘法次数不增加。
2. 工程上先调用原模型已有 `logits_to_keep`，仅算目标所需的 248 个预测位置，避免当前 588 行全量输出头；保留全部 248320 词表。
3. 复用常驻模型与编译对象/缓存，分离日常归因和大张量导出；单独测量冷与热成本。
4. 完成真正多样本、异长长度分桶 batch。当前一次归因的 EOS/输入 B2 不能冒充两个测试样本。
5. 若原删除曲线证明存在前段失真，再考虑有明确预算的条件有限传播；不默认增加端点或积分步数，不按 MAS 曲线调最终分数。

新增质量候选均与当前冻结 DT 比较，再列固定原版 FT 对照。使用作者既有原样本及原 needle/RISE/MAS；RISE/MAS 越低越好，完整保存曲线、signed density 和退步样本。暂定胜出不改变历史门槛，也不冒称研究目标已经完成。
