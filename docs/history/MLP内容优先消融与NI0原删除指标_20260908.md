# MLP 内容优先消融与 NI0 原删除指标

结论：不升级 MLP content1，保留当前 DT 的对称 MLP 默认规则。该候选在唯一已测原 NI0 上 needle、RISE、MAS 均退步，没有继续扩跑它的依据。当前 DT 仍按用户决定作为暂定胜出工作版本，完整原版 FT e81b3be 保持固定。接下来执行优先级2：复用原模型 `logits_to_keep`，减少不需要的输出头行计算。

## 结果与比较身份

模型和归因输入为同一 Qwen3.5-9B、588-token 原 NI0 固定轨迹、310 个 eligible 位置。FT0–3使用上一轮完整未修改官方 FT 保存的向量；没有重新计算或修改 FT。新 MLP 候选唯一变化为 Δ[u·SiLU(g)]=SiLU(g1)Δu+u0ΔSiLU(g)，PV、FLA、其他 DT 有限规则与目标不变。

候选相对同次控制组少恢复2个gold token，RISE增加0.015315，MAS增加0.021384。原 top31 中丢失 gold 位置79、89、137，新增91。不是把理论恒等式成立当作质量成立：MLP 两支都来自已有隐藏状态，原输入门控可能同时突出无关特征。该例不支持此前“基线门控稀释→内容优先会更好”的假设；不能据此推断所有任务都必然退步，也没有按层/权重扫描。

当前冻结 DT 相对这例最好的 FT2，RISE降低0.010511，MAS增加0.052599。这里只确认单例表现；Morehop和独立数据尚未测。两次对称控制的top31集合一致，但其分数向量相对原保存值差0.2663%，1个接近零的eligible分数改变符号，原曲线的RISE/MAS亦有小幅变化，均保留。

## 原指标如何执行，哪里做了输入适配

直接执行作者 `flashtrace.improved.faithfulness_test_skip_tokens(k=20)`，调用原 `LLMAttributionEvaluator.compute_logprob_response_given_prompt` 进行真实模型评分。七条曲线全部使用相同 BF16、默认 FA/真实 FLA、B1、完整词表与原 EOS 删除。未截断或重标定有符号分数，未改排序、密度、响应单调化、alignment penalty、AUC或MAS归一化。

存在明确的外部输入适配：[FixedInputMetricView](../../research/runtime/fixed_input_metric_view.py) 仅固定已被解释的原始 prompt 文本。作者当前评分器的默认 Context/chat 包装会把这里的输入换成605token，而当前 FT/DT 都解释588token；直接照用其默认包装会改变上下文。因此本次在评分器外部固定输入，原指标函数和原模型评分方法不变。这属于同输入上的原指标评估，不能冒称完整原 `run_exp` 包装流程或论文原表复现。

147次真实模型输入均由被动hook逐次核验：只允许310个eligible位置改为EOS，响应和其他位置不变；全部七条曲线的clean/全EOS输入哈希一致，实际评分端点也完全相同，分别为-125.5/-292.0。原评分器采用其实际默认log-softmax/求和精度，没有偷偷替换为DT归因种子的FP32数值。完整原始曲线、排序、每步删除位置、输入哈希和评分调用均保存；离线NumPy独立复算所有RISE/MAS，差异小于1e-12。

## MAS 为什么落后

原密度为 ρ_k=1−累计已删除归因/归因总和。DT保留负归因，先删除正项后，累计正项可能超过净归因总和，使ρ变为负数。原归一化模型响应r被截断并单调化到[0,1]，因此当ρ<0时，|r−ρ|中至少含有−ρ这一项。

| 对齐项 | FT2 | 冻结DT | MLP候选 |
| --- | ---: | ---: | ---: |
| density最小值 | 约0 | -0.137212 | -0.131650 |
| density回升步数 | 0 | 8 | 7 |
| 总对齐罚项AUC | 0.108180 | 0.172289 | 0.171076 |
| density越出[0,1]的AUC | 0 | 0.077918 | 0.071983 |

冻结DT约45.2%的对齐罚项来自density越出允许响应范围；这部分大于DT相对FT2增加的对齐罚项0.064109。把density投影回[0,1]仅用于离线代数分解，其余罚项约0.094371；没有用投影分数重新评测或替换原MAS。由于MAS之后还有裁剪和归一化，不能直接把0.077918从最终MAS减掉。

这表明MAS的幅度/密度约定对有符号分配产生了额外罚项，解释了needle/RISE更好而MAS更差的部分原因；不是据此宣告MAS无效，也不是获得修改原门槛的理由。MLP候选降低了负密度面积，但删除RISE更差、MAS亦更差，故不应通过裁负或幅度调参追指标。

## 数值、成本和保留的失败

首轮已完成32次实际decoder重放和两套各32次有限传播，得到相同的37.5%/32.5% needle。驱动以统一1e-6分数阈值断言失败，且保存向量在断言之后，导致完整向量未落盘。该任务保留为失败，未追溯改判。之后另冻结一次采集修复：先保存每个完整向量，再报告默认精度差异；候选及所有方法公式不变。

恢复任务完成完整向量与32层账本，独立复核两套账本闭合。对称/候选总有限差残差分别-0.0856%/-0.1583%。局部检查使用真实捕获坐标：相同端点时与原Torch SiLU乘积autograd相对差约5.8e-8；局部有限产品恒等式误差低于1e-9。它们只支持实现检查，不替代原指标。

两次消融复用已认证的实际root/目标logits，逐层运行原模型并观察输出；没有伪造端点或旧605-token缓存。共同root来源的原生成成本继续留在前轮记录。两套传播共享层重放，且固定先控制组后候选；首次编译、调优等计入实际调用，不把候选0.343s和控制组3.268s直接解释为加速。完整配对传播为22.55s，并非一次普通归因。

本轮三次远端任务累计约179.70秒（55.37秒失败采集、60.81秒恢复、63.53秒指标评分；不含结束后打包、本地分析和传输）。实际总量：3次完整模型加载、64次原decoder重放、128次有限decoder、16次FA辅助LSE、4次CPU needle、147次真实B1评分前向；0次FT归因重跑、0条新生成、0个新增benchmark样本。三任务均已终止。原指标本轮串行B1；没有宣称已实现多样本batch吞吐。

## 下一决策

停止MLP content1扩跑，不推广为默认。优先级2的官方输出头行选择有明确的不必要计算依据，先做同输入、同目标的质量保持和完整成本配对；FT继续冻结。RISE/MAS本例已补齐，后续不因缺指标反复重跑本例或修原框架，必要时再用已有少量Morehop开发样本验证当前DT的稳定性。
