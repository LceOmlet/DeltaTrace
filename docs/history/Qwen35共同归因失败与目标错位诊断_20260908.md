# Qwen3.5：两种归因适配未通过质量验收

当前应归纳为：**FT 和 DeltaTrace 在首个 NI0 上都没有恢复好证据，当前适配未通过质量验收。**之前只强调“DeltaTrace 没有胜过 FT”，把两者共同失效降成了相对胜负问题。真实 FA/FLA 调用、分解恒等式及小残差属于实现证据，不能替代解释能力验收。

本轮没有新增模型前向、反向、归因或删除评测。暂停尚未启动的 97 次 B2 RISE/MAS 前向，直接分析已冻结的同例分数、原生端点概率和官方文本。CPU tokenizer 首次导入因遗漏既有 MACA_PATH 环境变量失败，补齐后完成；没有改后端或精度。

## 实际失败落在哪里

同一个作者 NI0，旧新 tokenizer 的可归因 token 都是 310 个，可评估 gold 都是 40 个，按原指标选前 31 个。新 tokenizer 的位置已重映射；不能沿用旧位置。以下不是跨模型的受控消融，旧结果只用于定位迁移中发生的变化。

| 已冻结版本 | 恢复的证据 token | 前31个中位于末尾问句的数量 |
| --- | ---: | ---: |
| 旧 Qwen3-8B P1，整段轨迹目标 | 17/40，42.5% | 9 |
| 当前 Qwen3.5-9B P1，末尾答案目标 | 1/40，2.5% | 18 |
| 当前同模型修正原生 FT0 | 2/40，5.0% | 28 |
| 当前同模型修正原生 FT1 | 3/40，7.5% | 27 |

当前分数大量落在问句/答案前缀中的 `provided`、`mentioned`、`are` 等词，而非正文中首次提供数字的两句证据。这说明交付物没有完成证据恢复任务；不能以 FT 同样低分降低 DT 的验收要求。这里的结论限于已测 NI0，其他样本尚未证明全部失效。

## DT 已查明的重要目标变化

迁移同时改变了模型结构和 DT 目标范围。旧 P1 对整段固定生成轨迹的 log-prob 求有限贡献；新 P1 只对末尾答案段求有限贡献。记输入为 x、固定 thinking 为 c、末尾答案为 a：

\[
S_{\rm cond}(x;c,a)=\sum_{t\in a}\log p(a_t\mid x,c,a_{<t}).
\]

这解释的是“已经给出整段 thinking 以后，输入还怎样影响答案措辞”。如果 thinking 已重复写出正确数字，这个量就可能几乎不再依赖输入中的原始数字证据。有限恒等式即使成立，也只能分配这个条件目标的变化，不能保证找回先前取得数字的来源。

保存的真实原生端点已经显示这一问题。只把原可归因用户 token 换成 EOS，保留 thinking 与回答：

| 同一 NI0 内的目标部分 | 原输入相对 EOS 基线的 log-prob 变化，nats |
| --- | ---: |
| thinking 首次写出两串正确数字的 token | 36.26298 |
| 末尾答案再次写出这两串数字的 token | 0.01428 |
| 末尾答案全部38个 token | 12.83989 |
| 整段轨迹 | 179.42102 |

末尾数字仅占答案总变化的约 **0.11%**。`provided` 和 `mentioned` 两个 token 的变化分别约 5.0135 和 2.6252 nats。整段轨迹变化的 92.80% 位于 thinking；同批 MH1 也有 93.25% 位于 thinking。后一个观察只说明目标效应分布相似，不是 MH1 的归因质量结论。

这些量来自原有 FP32 log-softmax 诊断记录，**不是新运行的原 RISE/MAS，也不是逐词删除效应**。它们确证目标变化及效应构成；“固定 thinking 中的答案副本遮蔽了原输入依赖”是有这些证据支持的机制解释。还没有用仅改变目标范围的归因对照测出它能解释多少恢复率损失。

## FT 的共同失败仍须单独解释

FT 归因于答案位置的表示贡献，并通过原 hop 规则追踪 thinking；它不优化上述 log-prob 标量。因此不能把 DT 的标量诊断直接当成 FT 失败的证明。

保存的 FT0 层分数表明，末尾问句集中不仅出现在 GDN，也出现在标准 FA 层。早期部分层仍有证据分数，整网聚合却偏向末尾问句。这使“全是 FLA 算子错误”缺乏支持；下一步应关注来源追溯与聚合是否保留了证据，而不是继续修约2×10⁻⁶的舍入。逐层分布仅作定位，不能根据 gold 挑层、拼出一个新 FT 或调权后宣称恢复成功。

## 下一步应回答的单一问题

首先核查：**把迁移前已固定的整段轨迹 P1 目标恢复后，同一9B、同一端点、同一有限传播规则能否恢复原证据定位能力？**这比先执行十条完整删除曲线更能区分“目标迁移造成的退化”和“有限传播/新架构仍有问题”。

下一控制限于一次真实 B2 全轨迹 P1 归因和一次原 NI0 CPU needle 评估；复用已保存的真实端点，不新增生成、样本、精度扫描或 FT 重跑。必须在执行前冻结具体调用预算，并保留当前答案版本结果。该控制本轮尚未执行。

全轨迹分数是 \(\sum_{t\in(c,a,EOS)}\log p(y_t\mid x,y_{<t})\)，与旧 P1 和作者原 RISE/MAS 的整段响应评分范围一致；它仍是固定轨迹评分，不能冒称重新生成或对生成决策做了因果微分。这个诊断也不能悄悄替换官方答案证据任务：最终要解释答案如何取得证据，包括 thinking 中介。若恢复全轨迹目标仍失败，应进一步定位新结构传播；若明显恢复，则先纠正目标迁移的定义与对照，再讨论最终方法。
