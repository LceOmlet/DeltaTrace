# 公开 FA 捕获：P1 数值与真实成本

原 NI0、NI2、MH0 的冻结检验已经完成。公开接口路径与同作业旧路径、此前完整16条实验中的对应 P1 带符号向量完全相同；预热、三次正式调用及 NI0 额外 profile 都核对过。目标分数、未分配残差和原生层边界保持一致。这里只确认三个原样本的实现等价，没有新增质量优势或独立数据结论。

|原样本|旧私有捕获秒数|公开捕获秒数|耗时比|额外峰值字节|
|---|---:|---:|---:|---:|
|niah_mq_q2 0|0.599064|0.608046|1.014994|378880|
|niah_mq_q2 2|1.204961|1.217630|1.010514|0|
|morehopqa 0|0.846753|0.856607|1.011638|330240|

计时包含每次实际输入准备、一个 B2 根前向、36次 B2 原 decoder 重算、归因传播、分数返回，以及公开方案新增的36次 B2 FA 调用。三样本耗时增加约1.05%—1.50%，峰值最多多378,880字节；通过预先冻结的逐样本15%耗时/72.5MiB显存额外开销检查。这个保守采用检查是研究者事前选择，不是用户指定的科学质量门槛。旧 FT 相对成本结果不拿跨作业数字重新计算。

新路径被动观察公开 `flash_attn_func` 的实际 Q/K/V 和输出；每层额外调用同一个未修改的公开函数，参数保持原值，仅请求文档化 LSE。辅助输出逐层与真实模型 FA 输出严格核对，始终不替换模型输出；测试矩阵没有参与任何概率重建。当前安装返回的测试字段实际为 None。LSE 用于已有明确标注的归因概率近似，不把重建 P 冒充 FA 原生返回矩阵。

NI0 profile 确认旧路径72个、新路径108个真实 `flash_fwd_kernel`。新路径没有复制 FA、patch 模型或替换原生 backward，也没有调用一个自写算子再称其为 FA。原有限传播源码哈希未变。

首次作业在过严的返回值类型检查失败：它只接受空 Tensor，而安装版本用 None 表示未返回测试矩阵。修复只接受这两种无矩阵表示，并记录实际类型、修正异常路径调用计数。第一次失败作业原始记录和预算修正保留，不能抹成零成本。成功作业26次根前向、936次额外层重算、468次辅助 FA、0次反向和0次评估。连失败作业合计28次根前向/56条端点轨迹、973次额外层重算/1946条端点层轨迹、469次辅助 FA，27次完成归因、1次失败尝试，共2450个 FA 前向调用。没有重跑原删除曲线：完整带符号向量和输入身份相同，原分数/曲线仅作为已有证据引用。

采用范围：后续开发优先公开捕获入口，旧私有路径保留为冻结历史对照。公开 API 的内部版本变化通常无需移植私有槽位；这里仍要求可观察的 Python 公开 callable、支持文档化 LSE、当前 causal/dropout0/无额外 mask 语义，不能承诺所有未来破坏性接口变更都自动兼容。遇到不支持的接口明确失败，不暗中退回私有调用。

本工作只解决端点元数据接口，不是默认单端点 backward 的双端点有限扩展。显式 N×N 归因矩阵和长输入问题仍在。原评估 B4 已有1.19—1.52x实测提速；真正多样本归因仍未完成。

下一步保持 P1 和这条公开路径，处理多个样本各自的固定响应范围与结果，再检验真正 B2 样本的吞吐/显存。对于当前纯因果 Qwen，可研究在完整响应之后右侧补 EOS、仅对各自原响应置种子的方案：未来位置不影响原前缀是其理论依据，实际浮点归因和额外计算仍须核验。不能将 EOS 填充计入响应分数，也不能用复制同一个样本替代真实异长样本测试。
