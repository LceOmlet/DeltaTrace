1. **按收益调整优化优先级。** 当前继续核查 FA 融合的剩余收益。若同一实际工作负载的剖析、完整归因计时和小预算配对验证表明剩余 FA 收益有限，就转向其他主要耗时，不无限停留在 FA 微优化。应从实际模型前向、层重放、投影、MLP、输出头、数据搬运和调度中按测得成本选择；复用已有官方或厂商算子与编译器。单个候选变慢不证明全部 FA 空间耗尽；静态乘法次数、内核数或寄存器字段也不替代完整时间。进入新验证前记录预期收益、预算和停止条件，继续支持真实 mini-batch。

2. **支持 Qwen3.5-9B。** 先在远端共享目录查找已有权重，核对 config、tokenizer、权重分片和实际模型类，记录来源、版本及可追溯标识。复用权重，不默认重新下载或替换现有环境。模型支持应覆盖真实模型前向、固定轨迹目标、端点捕获、明确的带符号归因、真实批处理和完整成本记录；加载成功本身不等于归因支持完成。原 Qwen3-8B 对照与证据保留。

3. **支持实际 FLA 后端，禁止影子实现。** 按新模型真实结构区分标准注意力和 FLA 所负责的算子，复用官方/厂商模型实现及可追溯 FLA 加速路径。核验实际分派、输入输出、精度、状态与缓存、mask/padding、批处理和数值影响；不能仅凭配置名称或 import 成功宣称已运行 FLA。不能把普通注意力的 PV 有限规则未经推导直接套到不同状态更新，也不能另写影子注意力、状态递推、模型或 backward 冒充真实执行。必要的有限归因扩展须明确公式和近似，并与真实端点核对。FA 的原有真实性约束继续适用。

4. **沿用原评测，明确模型扩展范围。** 使用 FlashTrace 官方数据和处理好的固定轨迹以及原 needle、RISE/MAS 定义；候选与 FT 比较必须在同一实际模型、同一轨迹和同一可归因范围进行。新模型结果明确标为模型扩展，不冒充原论文表格复现，不直接继承 Qwen3-8B 的指标。现有被历史使用的样本不称为独立保留集；未经授权不自行生成替代基准。
