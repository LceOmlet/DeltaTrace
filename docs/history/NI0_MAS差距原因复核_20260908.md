# NI0 MAS 差距复核与样本范围

2026-09-08。用户要求分清当前 DT 的 MAS 退步原因，以及样本不足是否掩盖了优势。当前 DT 和完整官方 FT 均保持固定。本文修正上一轮对负密度罚项的因果解释，不改原始指标或历史数值。

## 已有单例能说明什么

NI0 上，冻结 DT 的 needle 为37.5%、RISE为0.177252、MAS为0.346576；FT2为15%、0.187763、0.293977。RISE和MAS越低越好。针对此例，DT的证据恢复和删除排序更好，但静态贡献幅度与累计删除效应对不齐。

设 G_k 为第k步真实模型评分，u_k=(G_k−G_20)/|G_0−G_20|为未经截断的归一化响应，ρ_k为原MAS根据DT分数计算的剩余贡献比例。原指标还将u截断至[0,1]并取前缀最小值，得到r，再计算|r−ρ|等后续步骤。

| NI0 冻结DT的观测 | 分数给出的分配 | 实际模型删除响应 |
| --- | ---: | ---: |
| 第一组删除16个token | 占净贡献43.77% | 下降18.92% |
| 累计删除80/310个eligible token | 剩余比例约0（−0.00094） | 仍剩30.03% |
| 后段最低剩余分配比例 | −13.72% | 全部21个原始响应均未低于全EOS端点 |

这里的归一化只是原曲线的离线分析，不向模型回填校准值，也不作为另一套指标。

## 收回一个过强解释

此前把“负密度越界面积占对齐罚项45.2%”解释成MAS的范围约定导致DT退步。45.2%这个几何分解数值仍然成立，但不足以证明因果：需要检查真实模型响应是否本来也应为负，只是被指标截断了。

已保存曲线给出的结果相反：NI0的DT原始响应没有负值。完全去掉原响应截断和单调化，仅离线比较|u−ρ|时，对齐误差AUC从0.172289略增至0.174691。原指标这一步实际减小了DT的误差。因此，不能将本例MAS退步主要归咎于它不接受负数，也不能认为裁负即可得到更好的方法。

按照DT排序，后段8个删除组的静态分配为负。实际累计路径上，删除其中1组后评分上升，1组后下降，6组评分相同。默认原生BF16评分较粗，相同评分不能证明效应为零；这些是整组、给定此前删除条件的效应，不能用来判定每个token的符号错误。

## 当前最有依据的方法解释

DT当前分配的是“所有eligible位置同时由EOS基线恢复到原输入”的有限总变化。局部交互分配规则决定正负贡献如何归属，并使总有限差近似闭合。这不保证任意剩余token集合的分数和，等于该集合单独恢复后的模型效应。

MAS还要求静态分配幅度能对应逐步删除所经过的中间条件。特征之间存在门控、替代证据和交互时，原端点上的分配可能把交互收益记给先删除的组；实际删除这组时，其余内容仍能维持一部分响应。上面的43.77%与18.92%差异符合这种失配，但仅凭曲线还不能定位是哪一层或哪个算子造成的，也不能排除尚未发现的实现误差。

因此目前需要区分：needle衡量找到证据，RISE偏重删除排序，MAS另外检查幅度与响应形状。更好的排序不自动带来更好的MAS。FT在该例的幅度对齐更好，也不等于其非负分数已经证明负向贡献不存在。

## 样本不足如何判断

当前同输入的新Qwen3.5比较只有NI0，不能估计总体平均差异或差异方差，更不能估计需要多少样本才可能测出优势。20步删除共享同一输入和累计路径，不是20个独立样本。增加样本可能揭示DT平均更好、平均更差或任务间分化；没有依据预先认定其中一种。

冻结的小扩展选NI1、NI2与已有位置核验的MorehopQA第1条，全部使用作者处理好的原轨迹，保留FT0–3和当前DT，不生成替代数据、不调方法。另重算NI0仅检查新的共用执行驱动是否保持当前规则，不计为新增样本。按数据集分别报告逐例差异，检查重复prompt；不把这些历史用过的样本称为独立确认，不为了显著性继续扩跑。

预算上限：一次实际模型加载、4次DT归因（含NI0驱动控制）、3次完整原FT、15条原20步曲线/315次真实评分前向、900秒远端执行。输出头行选择优化在此检查中关闭；所有有限规则保持原样。样本级仍为B1，DT的两个端点组成B2，不宣称多样本mini-batch已完成。
