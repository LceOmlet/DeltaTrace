## 为什么两种单调外推都不成立

统一使用预测−实际记号。对任一层边界，实际条件差为 δh_i，归因系数为 m_i，定义 e_i=m_i·δh_i−m_(i+1)·δh_(i+1)。顶部和输入映射余量单独保留，则完整误差为各 e_i 的望远镜和。

只改变 FA19 core 时，顶部及层 20 以上系数不变，但层 19 的 Q/K 输入投影、归一化和下方 0–18 层系数都会变化。因此完整误差改变量是该 core 改变量、其下游到输入的各项改变量和数值映射余量之和。原 local +0.128101 不是这个和。

理想固定端点线性有限规则下，若 core 输入的新旧系数差为 δm，原输入到 core 的有限正向映射为 T，则完整变化是 δm·Tδh_0；局部测的是 δm·δh_core。两者相差 δm·(Tδh_0−δh_core)，正是下方条件传播不准确对候选改动的影响。生产 BF16 seed/cast 还需明确额外数值项；不能单独传播 δm 后假称等价于分别传播新旧完整系数。

## 当前可复用边界与最小下一检验

1. 当前第 0 层 FLA 端点平均只改变归因反传、不改变真实前向。在**相同原生端点和顶部 seed**条件下，它不会改变第 19 层收到的上游系数，因此不会自动使旧 MH1 的局部 softmax 测量失效；它会改变下方传播 T，故完整输入影响可能改变。实际当前 MH0 是另一条样本，且已知跨进程原生漂移，不能直接套用旧 MH1 的候选系数。
2. 优先使用正在捕获的当前 MH0 layer19 内部真实账本，先确认 +10.60/+11.90 的整 decoder 误差究竟有多少来自 softmax/FA core、输入 RMS 或其他边界。现有 34 边界和原生产 m_i 已足够在 CPU 上核对符号、抵消和误差总账；只有 old m_i 不足以推导任意新 m_i。旧 private 文件只保存 6/19 内部及若干边界，未保存所有下方有限算子的完整线性映射。
3. 如果当前同源内部证据仍指向 softmax，需要的是一次**可闭合到输入的有限传播修法判别**，而非又要求局部 early/mid 同降：复用当前实际 B2 操作数、FA19 上游 seed 和真实 LSE，计算一个有理由的候选一次，再从更新的层 19 输入系数沿原 18→0 有限规则传播到输入。使用同一真实捕获的 early/mid/全 EOS 删除集和原评分，直接比较新旧完整 Σ_A attribution−实际删除效应，并把 Δe19 与 ΣΔe0:18 分开。无需新整网前向、FT、生成、排序或原指标曲线；这只是固定条件误差判别，不能冒称新 MAS。
4. 若下方仅有各层 h_i 端点而无内部捕获，默认原生重放仍不可省：单下方传播需要 19 次原 decoder 重放、19 次有限 decoder（4 个 FA/LSE，15 个 FLA 层，当前第 0 层额外交换向使 finite FLA 共 16 次），再加 layer19 候选及其输入侧传播；模型若不常驻还需一次原权重加载。完整预算应按真正可复用字段冻结，不能用旧系数向量冒充新规则，也不为省 GPU 另写状态/注意力前向。

上述第 3–4 项是明确的候选判别边界，不是本次运行授权；是否执行应由当前 MH0 内部分解决定。未执行任何新测试，未修改源码、FT、生产文档或目标状态。
