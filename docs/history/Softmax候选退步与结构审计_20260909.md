# Softmax 候选的原指标退步与结构审计

保留 P1 内容分支、统一改8层路由传播的 supported-secant 候选未通过两例整网测试。两例原 RISE、MAS 均变差；两套真实删除背景上的条件幅度误差也都变大。NI1 needle 从37/38升到38/38，这个正结果保留，但不足以抵消解释幅度退步。停止该候选扩跑和推广，默认配置未改。Goal 仍未完成。

这轮新增一次整网任务和一次保存数据的 CPU 数学审计；没有新 FT、生成、模型后端修改或新 FA 编译。前一轮 PV19 的八例正负结果仍有效，本轮不重复跑已足以否决的候选全八例。

## 候选为什么值得测试，实际测到了什么

前轮 MH0 真实算子拆分已发现，除了 PV 参考内容错配，softmax 对部分删除方向还有约+7.03/+7.79的路由预测误差。PV19 改善幅度却损害部分排序，所以本次保留原 P1 内容分支，只改变 softmax 有限传播。

候选以原输入雅可比为起点，把有限差校正限制到两端概率变化方向。它复用此前已编译、可追溯的 vendor FA 分块库和默认 BF16 算法边界；原模型 FA/FLA、QK 中点、P1 内容分支及第0层既有修法不变。执行的是上轮冻结的完整21文件载荷，不用后来新增的 PV API 重建旧协议。此前“prepared only”文件是历史准备快照；本报告及执行目录记录它现在已经运行，不能再说该整网候选从未测过。

作者缓存的 MH0、NI1 使用相同原输入、原答案加 EOS、原跨度/gold 映射和原 RISE/MAS 实现。两种方法的原生目标、seed 与相同删除输入的原评分一致；没有把历史 FT 分数冒充本次配对测量。这里 C 为当前默认，S 为 supported 候选。RISE/MAS 越低越好。

## 结构问题成立，但还不是这次失败的根因证明

对理想归一化 softmax 端点，记

\[
d=p_1-p_0,\quad s=z_1-z_0,\quad D=d^Ts>0,\quad
J=\operatorname{diag}(p_1)-p_1p_1^T.
\]

候选对任意上游向量 g 的拉回为

\[
Mg=Jg+d\frac{g^Td-g^TJs}{D},\qquad
M=J+\frac{d(d-Js)^T}{D}.
\]

它满足 \(M^Ts=d\)，因此端点有限差守恒；也保持常数方向不变。但 M 一般不对称，其对称部分未必半正定。真实 softmax 雅可比以及它们的非负加权平均均为对称半正定，故“保持有限差”不能证明这个校正保留了真实 softmax 响应的全部结构。三类别代数反例被保存在协议中；它不是自造质量基准。

为了避免只凭反例猜本次根因，另做了32个真实保存行的 CPU 审计：此前已定位的 MH0 query443、547，每个16头全部纳入，不按结果筛头。用原生保存的 BF16 Q/K/V 和 BF16-rounded上游做 FP64 数学计算，仅保存行向量及2×2矩阵，未物化全序列平方矩阵，也未执行模型、FA、归因或评分。

在 query547/head13，确有负二次响应方向：规范化到原雅可比二次量为1时，supported 为−0.107704。这证明该结构问题会在实际保存操作数上发生。**但真实 g 在这32行的二次响应均未变负**，该头实际值仍为+0.004157；不能据此宣布它就是两例 MAS 退步的原因。此处是理想 FP64 softmax 的结构审计，不能冒充默认 FA 的实际输出重放。

同时考察了保持对称半正定的有限差形式：

\[
H=J-\frac{(Js)(Js)^T}{s^TJs}+\frac{dd^T}{s^Td}.
\]

只要两个分母为正，Cauchy–Schwarz 保证第一、二项之差半正定；第三项半正定；直接代入得 \(Hs=d\)。这是一个定义清楚的结构修正，**没有实现新 GPU 内核，也没有整网有效性结论**。

| 保存行的条件误差，16头绝对误差之和 | 原 logmean | supported | 对称形式 H |
|---|---:|---:|---:|
| query443，early | 1.2492 | 1.3934 | 1.2969 |
| query443，middle | 1.2889 | 1.2235 | 1.1067 |
| query547，early | 1.1145 | 1.0418 | 0.7902 |
| query547，middle | 1.1463 | 1.2574 | 1.2771 |

H 对原 logmean 两好两差。净误差改善的部分还包括头间抵消，逐头正负量已保存。结构正确不等于解释效果必然改善，本轮证据不足以仅凭半正定性继续开发新内核。

## 成本与下一步

整网试验实际用了4次 DT、100次有限 FLA/200个原生伴随阶段、32次有限 FA和32次公共 LSE、128次原层重放、84次原 B1 评分，墙钟77.789724秒；CPU几何任务2.766680秒。无 FT、生成和新 FA 编译。两例各方法只有一次观测且首次形状包含预热效应，MH0 C8.0957/S1.1031秒、NI1 S5.7518/C1.3773秒不能当作速度对比。各例 C/S 峰值 allocated 相同：MH0 21,117,508,608 bytes，NI1 20,495,206,912 bytes。此次单样本两端点不构成真实 batch 验收，也没有给失败候选追加热成本测试。

保留默认 C 和已归档的 PV19 取舍，不推广 S。下一步回到当前强方法剩余的最大可观察差距：上一轮 MH2 的 MAS 对历史 FT3 仍差约0.13，明显大于 MH0 的 PV19 残差；先用当前 C 在 MH2 同一真实删除集合上的层边界账本确定最大实际错配，再决定是 PV、FLA 控制内容、归一化还是其他边界。计划上限为一次归因和4个原评分点，沿用已有真实边界诊断，不修改 FT、不新建基准；具体载荷须先按实际记录冻结。该诊断尚未执行。

不继续从一个失败 softmax 变体跳到另一个仅数学性质更漂亮的变体；没有主导机制证据时，不能承诺“按此修法必然有效”。后续新方法仍需原 needle、RISE、MAS 的固定覆盖与实际成本，Goal 保持 active。
