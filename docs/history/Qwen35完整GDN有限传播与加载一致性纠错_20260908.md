# Qwen3.5 完整 GDN 有限传播与加载一致性纠错

已实现并在真实首层上执行完整 GDN 有限传播，覆盖异长 NI0/MH1 的605/368 token。当前证据只支持这个局部实现；完整 decoder、D256/BF16 标准注意力、原答案目标传播、原评测质量及完整归因成本仍未完成。研究 Goal 保持进行中。

## 核心实现

[运行时](../../research/runtime/qwen35_gdn_finite.py)消费实际默认模型的 EOS/输入端点，不替换模型 forward。其 FLA 部分复用原生伴随、已有有限递推扩展和官方编译，三次收缩复用开关保持关闭。新增边界使用已有 RMS 有限规则、厂商 BF16 GEMM、Torch 张量算子及公开 causal-conv 原语，没有另写注意力、卷积或模型反向。

实际 `FusedRMSNormGated` 来自 `fla.modules.fused_norm_gate`，先做 RMSNorm 再乘 SiLU(z)。它不是另一个 `layernorm_gated` 模块。输出交互规则固定为 Δ(n·s)=s1·Δn+n0·Δs：内容使用输入门控，门控保留基线内容贡献。RMS/L2 用原有对称有限规则；beta/log-decay 用实际端点割线，端点相同处采用解析导数。Q/K 由16头展开到32头后的系数按真实分组求和。

卷积采用一次公开 `causal_conv1d_fn(activation=None)` 配对前激活调用，再用该线性原语的原生 autograd 回传。模型融合 SiLU 的真实输出继续充当端点。原生 backward 还计算了丢弃的权重梯度，这些成本没有从计时中扣除。没有创建全局 T×T 矩阵；当前只支持无缓存、无 packed sequence 的预填充，整网接入须按层释放临时状态。Q/K/V、写入门和衰减分支的正负系数都保留，没有裁去负项。

## 完整系数与有限差

实际系数形状为 `[2,605,4096]`，是 GDN 输入系数，不是最终输入 token 的答案归因。上游固定为原输入 GDN 输出，padding 置零；因此这里的目标是局部能量配对。原官方文本、回答、EOS位置和 gold 映射没有改变，没有生成新答案。

| 真实端点有限效应 | NI0 | MorehopQA1 |
| --- | ---: | ---: |
| 直接输出配对 | 1355.674324585 | 953.600099616 |
| 完整输入系数分配 | 1350.002405361 | 944.623268273 |
| 残差 | -5.671919223 | -8.976831343 |
| 相对该样本效应 | -0.4184% | -0.9414% |

两样本总效应向量残差 L2 为0.6406%。不能只看总量：内部 FLA 的32头残差 L2 分别为1.8544% / 1.6197%，完整逐头数值随[分析结果](../../evidence/qwen35_gdn_integration_summary_20260908.json)保存。此处长度和上游都不同于此前129-token局部检查，不能把差别单独归因为长度。所有非线性、投影和上游 BF16 转换的效应残差均记录；没有新设或放宽精度门槛。

在4,340个位置，BF16保存的卷积前激活相等，但融合 SiLU 输出仍不同。其遗漏效应分别约−0.12934 / +0.01832；卷积 SiLU 段残差 L2 约0.00177%。这个信息揭示了辅助前激活保存的舍入边界，不能把混合端点视作新的模型前向。

等端点极限检查使用同一原生重放自身的端点和 cotangent。完整输入系数相对原生梯度 L2 差0.3162%，余弦0.999995022，最大绝对差0.1263504，原生梯度范数344.010110。三个版本的 padding 系数最大绝对值均为0。此检查检验完整链条的梯度极限，不能证明原指标优势或条件删除符号正确。

## 两次观测错误与一次不匹配恢复

1. v1误把官方 `force_accelerate_hooks` 外层函数当作 GDN 正文，读取不存在的 `hidden_states` 后中断。装饰器未设置 `__wrapped__`；修正只通过闭包里的 `forward_func` 找到被动观察代码对象，没有安装或调用替代 forward。该次完整模型加载和失败 root 尝试仍计入预算。
2. v2已完成真实 B4 root、两次完整 GDN 有限调用和一次原生 GDN forward/backward，随后错误要求主线程 `sys.setprofile` 必须看到卷积 backward。后续原生 autograd 节点 hook 确认该反向在另一工作线程返回输入梯度；主线程计数不能作为未执行的断言。v2后续完整向量保存被此断言跳过，原状态继续保留为 failed。
3. 第一次保存端点恢复直接采用 checkpoint 的 FP32 `norm.weight` 和 `A_log`。真实模型通过 `from_pretrained(dtype=bfloat16)` 初始化和物化，这两个参数应为 BF16。这是目标参数不一致，不能称为一般 FA 舍入，也不能因误差小就接受。[不匹配恢复记录](../../evidence/qwen35_gdn_unmatched_recovery_summary_20260908.json)已明确排除出目标模型结论，其花费仍保留。

最终恢复使用原始模型类的 `get_init_context` 创建纯 meta 元数据，核验 `_get_dtype_plan` 为空，再复用官方 `_materialize_copy` 按实际初始化参数 dtype 读取九个 GDN 权重。全部九个参数为 BF16，checkpoint 与实际加载后的 dtype/内容哈希分别保存；没有重新加载完整模型权重或执行整网前向。

纠正后，原生重放输入、投影、卷积、原始/归一化 Q/K、V、beta、log-decay 与 root 捕获相同；WY/状态和输出仍有记录中的小差异。最终 GDN 输出相对 root 差约0.01296%，最大绝对差0.03125，未要求逐位一致。按原始 root 端点重新求得的贡献总量与 v2 相对差1.56e-11，来源一致性与有限传播复现分别核对。

## 成本和资源账本

v2唯一热调用12.171 ms，初次调用10.972秒，后者含编译与诊断留存。模型驻留时起始 allocated 为19,267,276,800 B，局部有限调用峰值20,003,675,136 B，增加约736.40 MB；这不是整网归因显存，也不是与同批次原生反向的完整比较。新非线性边界尚未用编译器集中融合，当前没有稳定吞吐或 FA 速度主张。

原生 GDN 诊断包含局部前向、反向、冷编译和被动 CPU 捕获；恢复调用使用不同的驻留状态。它们不能与有限-only热调用拼成提速比。v2在导出编译器计数前中止，因此累计内部调优次数不完整；恢复的缓存命中计数不能替代整个任务的成本。

四个实际进程的累计账本：完整模型加载2次，root尝试2次、完成1次；单独 GDN 权重加载2次，其中一次 dtype 不匹配已排除；纯 meta 模型构造1次；完整 GDN 有限调用6次；普通原生 GDN forward/backward3次；辅助配对线性卷积 forward/backward各6次。较最初筛查额外发生一次失败root、三次有限调用、两次原生局部forward/backward，均来自上述接线和加载纠错，不是未披露的重复择优。另有一次只导入源码的探测超时。新生成、质量查询、整网归因均为0。

原生 root 的34个层/最终归一化检查点和首层端点保留在远端，大小约674 MB / 370 MB并记录哈希；完整输入系数与原生梯度已下载、CRC和文件哈希校验，原始激活不公开。源码、协议、结果、分析、失败及排除理由进入仓库。本阶段不再追加运行。

## 下一决策

继续接入剩余 decoder、MLP、残差、最终目标种子，以及8个标准注意力层。现有有限 FA 源码仍固定 FP16/D128（`Flash_fwd_kernel_traits<128,...,half_t>`），不能直接用于 Qwen3.5 的 BF16/D256；还需正确处理异长 padding、Q/K 的1+weight归一化、64维部分旋转和输出 sigmoid 门控。优先沿用同一可追溯 FA 框架及官方算子，不引入显式全局注意力矩阵或替代模型。

整网接通后才在作者固定轨迹和原 RISE/MAS、needle 上作小预算比较。没有新增质量胜出、条件删除方向可靠或整网成本可接受的结论。
