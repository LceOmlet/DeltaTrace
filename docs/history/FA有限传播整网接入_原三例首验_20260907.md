# FA 有限传播整网接入：原三例首验

已将可追溯 FA 框架有限算子接入原 content-P1 整网传播，清除了该运行路径的全局概率、分数、logmean/乘子及仅供审计的 N×N 矩阵。实际 Qwen/default FA、公开端点捕获、原 GQA/旋转/归一化/MLP 有限规则保持原用途。归因扩展仍独立命名，不能称为模型原生 backward。

## 完整归因成本

每个原样本、每种方法一次预热加三次交错实测；NI0另有两次完整形状/内存profile。下表为完整方法，包含输入准备、B2根捕获、36次B2层重放、36次额外公开原FA调用、所有转换及运行检查。库初始化和冷编译独立记录；表格不把profile计入正常延迟。

三个新路径峰值均低于同进程真实普通输入反向参照，差额约2.41—5.13GB。参照实际采用B1及原生 `logits_to_keep` 输出头；归因采用B2完整端点捕获，均为同一G32数学目标，但批维和输出头布局产生浮点分数差，逐例已记录，不能假称逐位相同。该参照用于显存，不用来替代质量评价。

局部算子87.8%的存储减少没有直接变成整网87.8%：完整峰值还包含权重、捕获缓存、输出头和其他有限传播。当前长度范围601—1241，不足以通过实测宣称任意长输入的整体内存规律。

## 原指标与符号

所有归因先冻结，再通过未更改的 FlashTrace EOS删除评估器重新计算6条21点原曲线。原缓存、完整输入、响应、可归因位置、gold、原评价后端、检查点和源文件均校验。没有复用候选曲线；FT0—3各对照引用已独立核验的历史原16条结果，明确不是这次新跑的FT。

完整归因向量相对误差为0.0244%、0.0634%、0.0349%。NI0/MH0无符号变化，NI2两个近零位置反号，对应原绝对贡献总量占比8.46e−7。全序列负值保持，原正值投影只用于原FT评测入口。各方法重复向量稳定，显式对照三例均逐位复现原P1。新路径最大相对未分配量0.1967%（同例显式0.1134%），保留而不回填。按用户认可的FA混合精度继续开发；这些差异本身不是退回FP32的理由，也不等于已验证单token删除因果符号。

## 运行真实性与平方级存储

同一NI0完整profile分别捕获108次真实默认FA前向；新路径额外有36个有限算子作用域、108次明确命名的FA框架有限内核。旧路径记录到1800个带N×N输入形状的操作，新路径0个；同时检查了新路径源码没有显式attention矩阵运算，15个有限入口缓冲均为 `[B,H,N,D]` 或 `[B,H,N]`。这构成当前实际运行与源码边界的证据，不把shape记录当作任意未来实现/长度的完整分配器证明。

Q/K内核输出已经乘scale，复用的GQA/RoPE布局传单位scale，避免重复缩放；GQA归并前转回FP32。真实RoPE/QKV、模型输出、原层重放与公开辅助FA输出逐项核验；没有影子注意力或静默dense回退。

归因源于固定MetaX FA2.5.3框架；安装的默认FA2.6.3没有覆盖。上游原文件、编译产物hash和独立局部公式核验沿用已保存证据。本轮预算：155次根前向，其中26次归因根、3次普通反向参照根、126次原评估；3次原生模型输入VJP、26次有限传播、936次层重放、936次额外原FA调用、468次有限算子（1404个扩展内核）。物理调用与双端点轨迹分别记账。
