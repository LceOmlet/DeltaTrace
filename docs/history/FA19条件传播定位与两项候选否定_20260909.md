**这说明两个已测删除点的路由净过估主要落在 softmax 条件响应项，不能说明 QK 对逐来源排序的影响很小。** Q/K 收缩分别按操作数位置记账，T/R0 按输出 query 位置记账；前两者相减仅有总收缩的机制解释，逐位置差不能冒充来源误差，也不能由净值抵消排除 QK。后两者 T−R0 的 query 坐标一致，可以定位：92.41%/93.33% 的绝对残差在固定响应 query，前 20 个 query 占 46.61%/50.75%。这些是读取位置，不是 needle 所指的原输入证据位置；没有逐 head 的原生 R0，不能宣称定位到某个 head。

固定双端点的 logmean softmax 规则满足相应端点弦的有限差关系，但该约束不保证它对实际部分删除的另一个方向仍预测正确。q513 的 step3 预测为 +0.795116、实际原生路由响应为 +0.218070；step10 为 +0.896017、+0.265038。现有证据定位到了实际条件方向错配，没有证明一个统一放大系数、特定 key 或单项权重就是根因，不能据此调最终分数。

## 成本、实现边界与可恢复性

四任务实际总墙钟时间由源结果求和，约 106.34 秒：公共 FA 对照 12.61548 秒、原生 VJP 10.93701 秒、整网对称候选 72.41196 秒、已有诊断 10.37284 秒。包含加载/复制/存档，不能称为方法生产耗时。CPU 审计另记于各审计产物。新增完整模型加载仅发生在原指标任务；其余复用已保存的实际状态。FT、生成和新 FA 编译次数均为零。
