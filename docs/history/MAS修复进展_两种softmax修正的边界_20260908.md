# 概率差方向的有限修正：构造依据与否证条件

这是在统一Euclidean候选被完整指标否定之后的单一候选定义，不是对NI回退已经给出的因果解释。

已测事实：NI同删除集合的中段过估25.500→32.177，正负量同时增加、净和近似不变；正质量更集中，不能说已经证明罕见键扩散。第19层softmax条件传播是此前实测的局部主误差，但这一层的收益不能直接推广到全网。

## 数学定义

有效key行的两个精确softmax概率为p0、p1，s=z1−z0，上游与V0的收缩为固定g。

a=J(p1)g，b=gᵀΔp，D=sᵀΔp，m=a+κΔp，κ=(b−aᵀs)/D。

设w为p0/p1逐元素对数平均。由Δp=w(s−ΔLSE)且1ᵀΔp=0，m是满足1ᵀm=0、mᵀs=b的所有向量中，最小化Σ(m−a)²/w的唯一解（D>0）。若有效support上s为常数，则Δp=0、b−aᵀs=0，保留a。

它不是在新旧分数之间拟合一个权重；κ由算子两个端点唯一确定，不读取gold、删除曲线或MAS。一般不等于原logmean有限规则。完整端点方向上，所有守恒线性规则都给同一结果，仍不能解决任意非线性子集响应。

令p(t)=softmax(z0+ts)，F(t)=E_p(t)g，则：

b−aᵀs=−∫₀¹tF''(t)dt，F''(t)=E[(g−Eg)(s−Es)²]，D=∫₀¹Var_p(t)(s)dt。

因此|κ|≤osc(g)，|m_j−a_j|≤osc(g)|Δp_j|，修正L1范数≤2osc(g)。两端均趋零的key修正也趋零；这里只是局部修正界，不约束全网正负归因或保证MAS。它保留共同masked support，不承诺只保留原输入单侧support。

## 当前明确的浮点计算选择

复用原模型公共FA提供的LSE、BF16矩阵乘法及FP32行计算。令r_i=exp(lp_i)、Z_i=Σr_i、p̂_i=r_i/Z_i。a与b、Δp使用行归一的p̂。

分母采用非负的原始对数概率表达式：

D_raw=Σ exp(max(lp0,lp1)) [−expm1(−|lp1−lp0|)] |lp1−lp0|。

κ=(b−aᵀs)/D_raw，m=a+κ(p̂1−p̂0)。它沿用原内核已有expm1路径，避免用两个接近的行矩直接相减得到分母，不加epsilon、阈值截断或额外score pass。原raw P1的dv分支保持。

理想LSE下Z0=Z1=1，D_raw为Jeffreys divergence，恢复上述解。一般正行质量下，实数中D_raw=Z1 KL(p̂1||p̂0)+Z0 KL(p̂0||p̂1)+(Z1−Z0)log(Z1/Z0)≥min(Z0,Z1)D_norm，其中D_norm=sᵀ(p̂1−p̂0)。所以质量修正后的理论界为|κ|≤osc(g)/min(Z0,Z1)。FP32指数/归约另有舍入，不能直接继承精确界。

实际的端点余量为(b−aᵀs)(D_norm/D_raw−1)，再加FP32与BF16输出舍入。必须记录实际行和、端点余量、理想界及质量修正界的越界量；不能把它声称为浮点精确守恒。D_raw=0取κ=0，记录不相容余量，不伪造补偿。
