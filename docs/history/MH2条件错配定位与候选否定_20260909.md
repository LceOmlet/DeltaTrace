# MH2 实际错配定位与一个被否定的修法

本轮把剩余 MAS 差距较大的 MH2 从整网边界定位到具体算子，并在等待原生层重放时准备了后续审计和最小测试。发现两个不同来源：FA19 仍由注意力核心主导；GDN1 则以遗忘参数外推和 K 归一化为主。针对遗忘分支设计的一项有端点约束的整体传播候选，在 CPU 局部测试中加重中段误差，已停止推广。当前 DT、FT、模型默认 FA/FLA 和生产核均未修改；Goal 尚未完成。

这里的 step3/10/20 是作者原20步删除评分曲线中的早段、中段与全 eligible EOS 位置；MH2 原处理输入480 token、原目标230 token，总长710。沿用此前当前 C 的真实删除集合，不能将这些开发诊断称为新增基准、独立确认或论文表格复现。RISE/MAS 越低越好。

## 实际新证据

先对当前 C 做一次完整归因及四个原评分点，保存34个实际边界及系数。随后只重放 FA19、GDN1，并用保存的真实上游做两次有限层传播。旧捕获未保留 kwargs，因此另有一次原模型 B2 前向取得真正的 RoPE、位置、mask 和缓存参数；没有手写替代参数或原生前向。两个端点行 B2 只代表一条样本。

以下统一为“预测−实际”，正值表示过估删除造成的有符号变化，单位是当前目标的收缩值，**不是 MAS**。

| 实际项 | step3 | step10 |
|---|---:|---:|
| 整网预测过估 | 24.804710 | 43.025350 |
| FA19 整层 | 10.115841 | 11.764230 |
| FA19 注意力核心（含 seed cast） | 11.596631 | 14.365729 |
| FA19 输入 RMSNorm | −2.935025 | −3.039803 |

FA19 的重放与原边界转移项均为0；GDN1 的转移净值约 +0.000004/−0.000043。默认数值边界被保留，没有逐位一致准入或精度修补。由这些量级可知，主要错配不能归因于重放漂移；负向 RMSNorm/MLP 项确实补偿了其他正误差，不能删掉后宣称修好。

## GDN1 的具体机制与不能随意修改的部分

实际代码使用 g(a)=−exp(A_log)·softplus(a+dt_bias)，再由衰减系数 alpha=exp(g) 进入记忆递推。固定两个非重合标量端点后，满足有限差关系的标量斜率只能是 (g1−g0)/(a1−a0)。部分替换得到的 a_A 经常在该区间之外，原割线不能保证准确预测这种外推。

实际 MH2 step10 中，10,116 个 token/head 坐标落在 a0/a1 区间外。这些位置贡献 raw_g 映射净过估 +9.749883，区间内位置有所抵消，合计 +6.102643。极端端点比例也包含端点距离很小的坐标，因此不把其极值当作质量指标。

进一步用保存的 native raw_g 做 CPU64 代数分解，raw_g→exp 项仅抵消 −0.850911；a→alpha 复合项仍为 +5.251732，剩余记忆递推项为 +1.801180。二者合计 +7.052911，与原 FLA 加参数映射相同。因此，这次确有参数到衰减的条件错配，不能全推给更新门使用 EOS 内容。这里的 alpha 是数学衰减坐标，**不是新捕获的原生 chunk 中间量，更不是影子反事实前向**。

Q/K 的 +4.111489 中，K 为 +3.965451，Q 只有 +0.146038。保存的部分删除 raw K 偏离两个端点连线，归一化是第二个明确方向；几何统计本身尚未给出有效修法。

证据：[标量复合与 Q/K 审计](../../evidence/dt_MH2_GDN1_scalar_composition_summary_20260909.json)。这项仅CPU计算，0模型、0GPU、0评分。

## 新测试否定了什么

单改标量割线无法同时保留端点关系，因此测试将输入投影 a=W_a x 与衰减函数合为一个向量块 F(x)，用

M = J1 + (Delta F − J1 Delta x) Delta x^T / (Delta x^T Delta x)。

该式在数学上是满足端点约束、与原输入 Jacobian 距离最小的秩一修正；它可能保留原输入附近的响应并改变离开端点连线方向的传播。测试只读取原检查点三项权重，使用实际捕获输入和固定上游，在 CPU64 做局部收缩；没有实现或替换原生模型，也未接入生产路径。

| a→alpha 块，预测−实际 | 当前 | 候选 |
|---|---:|---:|
| step3 净误差 | −1.278550 | 1.088523 |
| step10 净误差 | 5.250039 | 11.082754 |
| step10 token 净误差的绝对和 | 13.710761 | 15.160272 |

原生投影与 CPU64 线性收缩差另列（step10 为 −0.001693），不能把它归入方法收益。候选端点关系虽接近精确，中段净过估和绝对误差却同时增加。**据此停止这个候选，不扩大整网/多样本测试，不调连续权重寻找局部好看结果。** 这只否定该候选修复当前错配的理由，不能推出所有整体传播方法都失败。

证据：[候选与否定决定](../../evidence/dt_MH2_decay_block_scout_summary_20260909.json)。

## 覆盖与成本

四项实际任务耗时合计130.276305秒：边界57.312967秒、两层内部60.073124秒、CPU复合6.702011秒、CPU候选6.188204秒。包括加载、捕获、CPU整理和私有保存，**不是生产归因速度**。新增完整归因1次、原评分4次；两层诊断另计原 B2 kwargs 前向1次、原生所选层重放10次、有限层传播2次、公共 FA LSE1次。两项CPU研究无模型、FA/FLA或评分调用。没有新 FT 或生成；有限层诊断仅1次FA扩展和1次FLA扩展，所有实际调用明细在协议和结果中。

大容量实际边界/内部张量保留远端并记录哈希（约1.582GB、2.626GB），不将权重或私有 PT 推入 Git。公开 NPZ 数值保持原始字节。NumPy审计验证公开向量、标量/分组关系、来源和终止回执；并未在本机独立重算私有大张量的每一次内积。

本轮没有新原20步完整曲线，也没有新的 needle/RISE/MAS 成绩，不能据此声称 DT 胜过 FT 或质量未退步。此前两轮固定 NI0–3/MH0–3 八例覆盖仍保留；PV19 的 needle 合计105→103/154、六例 RISE 退步的事实不被本轮诊断覆盖或撤销。MH2 没有可用原 gold，不能为它编造 needle；needle 要继续在有原 gold 的 NI 例上验证。

## 下一步的明确顺序

1. FA19 是 MH2 最大项，且 MH0 也有同类核心问题。复用这次真实 Q/K/V/O 和上游，按已有11次公共 FA 算子对照拆出内容参照、路由预测和数值差；先核对原生调用参数来源，不能凭 MH0 的拆分值代替 MH2。该项尚未执行，不能把核心总项直接称为 softmax 或 PV 的单独根因。
2. GDN 支线保留“标量区间外外推＋K 归一化”为已定位错配，但停止上述 J1 秩一修正。只有明确说明如何改变这些方向的响应、保留符号并控制额外代价，才冻结下一最小候选；不自动扫描端点权重或靠守恒筛方法。
3. 任何值得接入的候选都先跑完整传播和原指标的小配对测试，再按预先固定的 NI0–3/MH0–3 覆盖逐例 needle/RISE/MAS、失败与退步。真实 mini-batch、异长 mask 和成本另行验收；只做局部数学的新候选没有“通过多样本”的资格。明显失败可提前停止并完整保留，节省资源不等于省略已推广版本的回归。
