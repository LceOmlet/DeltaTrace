# Qwen3.5 官方映射与真实双端点有限系数

2026-09-08。已从“只有推导和普通 backward”推进到真实 EOS/原输入端点上的混合有限系数。当前是局部 CPU 数学参考，整网归因、GPU 有限系数和原评测优势仍未完成。

## 结果与含义

| 官方原缓存答案 token 范围 | [205,242] | [118,138] |

残差相对真实局部效应的绝对值计算；同时保存各分支和残差相对分支绝对值之和，防止抵消掩盖误差。这两个标量采用 Z=原输入 FLA 输出、固定局部目标 J=<O,Z>，不是整网答案目标、RISE/MAS 或 token 删除效应。不得从这些数字推出质量胜出或符号具有条件因果含义。

**总和存在数值误差抵消。** 分别核算32个头后，残差向量相对真实效应向量的 L2 约0.40%/0.37%，最大单头绝对残差0.9293/0.8847。保存每个头的真实效应和系数和，不用很小的总体残差宣称高精度；不同环节对残差的来源贡献尚未分解。

五类系数 q/k/v/beta/alpha（以及由 alpha 转换的 g）均已计算。分块公式与按既定有限递推逐项计算的局部公式相对 L2 差最大 2.51e-7；V 完全相同。两种 CPU 算法共用真实原生边界、写入值及伴随量，所以这项比较只检查分块代数重写，不是独立原生模型正确性证明。有限差残差另外对照实际 FLA 输出。

## 官方数据映射

复用哈希核验后的作者 `attach_spans_from_answer`、`ruler_gold_prompt_token_indices` 和 stop-token 过滤函数，原函数 AST 未改动。先清空旧 token spans，使用原 Qwen3-8B tokenizer 重新计算，确认与缓存完全相同，再使用 Qwen3.5 tokenizer 重算。作者函数会保留已有 spans，不清空就可能“调用了映射函数却仍得到旧索引”。

答案字符范围、原 prompt/target、needle 字符范围未改，`attr_mask_indices` 保持句子索引；新 token gold 由作者字符重叠规则给出。输入 ID 哈希与上一轮真实模型输入一致，只有映射元数据更新。两条固定官方缓存均为历史开发样本，不称独立确认集；没有生成新文本。该模型扩展不称论文原表复现。

## 实际执行与复用边界

一次原模型 B4 前向，顺序为 NI EOS、NI 原输入、MH EOS、MH 原输入。实际长度为 [605,605,368,368]，右侧 padding 到605。EOS 仅替换现有 P1 规则允许的用户 token；模板、标点/空白过滤结果和固定生成轨迹按已有约定保留。

使用真实 Transformers Qwen3.5-9B、默认 BF16、8 次默认 FA varlen、24 次 FLA chunk 和24次原生 causal-conv；没有调用模型 torch 注意力回退，没有改写模型 forward。模型/FLA 的2853个源码文件再次与固定轮子核对，只有既有三处显式兼容修改，无新增后端修改，执行前后相同。

被动捕获首个 FLA 层前129 token、三个64-token块的起始状态及原生 WY 中间量。两个原输入前缀组成 B2，分别调用一次官方 `chunk_bwd_dv_local` 和 `chunk_gated_delta_rule_bwd_dhu`；真实 GPU profile 中存在两类内核。没有为此执行完整普通 backward 或额外局部 forward。

有限系数保留既定 content_P1 递推分配。复用原输入端点的状态伴随传播，使用 EOS 端点的状态和写入计算 q/k/beta/decay 混合项；V 分支用 beta1*A1ᵀ*dU_WY。不能直接把原生 dU_WY 当逐 token lambda_u，也不能把原生全部普通梯度当有限系数。

推导及[参考实现](../../research/runtime/finite_fla_chunk_reference.py)只需块边界 K×V 状态和64×64交互块；衰减混合项通过稳定的加权前缀累计计算，不需要全局 T×T 矩阵或全序列逐 token K×V 状态。当前 CPU 对照的逐项 oracle 仅临时保存一个头、一个块的状态，不接入模型或生产路径。完整公式见[有限传播契约](../qwen35_finite_extension_contract.md)。

## 调用、成本和局限

本轮共处理两条官方文本，加载模型一次，完成一次真实 B4 前向和两次原生反向状态算子调用；零生成、零质量评测、零整网归因。文本映射6.03秒；模型加载9.23秒。带被动 CPU 捕获的前向25.60秒，峰值20,108,746,240字节；带 profile 的局部反向状态阶段4.61秒，峰值342,114,816字节。上述包括诊断/原生编译调优成本，不是稳态延迟，不能与 FT 旧计时比较。局部阶段释放模型后测量，更不能将其显存冒充整网归因峰值。

CPU64 分块系数参考两次约0.76/0.77秒，逐项局部 oracle 约4.69/5.70秒；第二次加入逐头残差记录，仅为本机诊断成本，不构成 GPU 加速主张。CPU 分析首次遇到“未调用的 FA_dense 在计数字典中没有键”的读取错误，改为按零读取后完成；没有重跑 GPU。没有新增或放宽数值通过门槛。

两条前缀都跨越两个块边界，但不包含 padding 区域；真实模型异长批处理已执行，有限传播 padding 尚未验证。q/k 系数目前作用于原生归一化结果，还需接 L2、卷积、门控和整网其他算子的有限 pullback。已有8B的D128/FP16全注意力扩展也不能直接用于新模型D256/BF16。

## 连续决策

混合系数的块内代数获得实际端点支持，接下来实现 GPU 版本并接入有限 FLA 传播；优先复用原生两阶段伴随，融合局部混合收缩与加权扫描，保持可追溯来源。不要重新铺开普通梯度诊断、精度扫描或质量全扫。先以这些已保存真实端点验证 GPU 系数和实际成本，再接非线性边界与整网固定答案目标。RISE/MAS、needle、条件删除方向及完整成本均未获得新结论，研究目标继续进行。

证据：`qwen35_paired_finite_summary_20260908.json`、两个任务的冻结协议和原始结果；真实激活 NPZ 与完整 profile 在远端保存，激活 NPZ 和压缩包已下载并校验。公共仓库仅发布派生结果、哈希与可追溯代码，机器路径脱敏后哈希单独记录。
