# 第19层共同错配：保留内容不在固定参照之间，低节点联合FA积分未通过

当前 C、生产运行时、FT和模型默认FA/FLA均未改。本轮完成三个小预算实验：同进程MH3内部定位；三个实际样本上的一/两节点原生FA联合路径候选；六次原生FA内容参照对照。结果改变了下一项修法的依据，但没有新方法通过完整归因质量验收，Goal继续进行。

## 同进程重现，先区分总层项与核心

## 符号的条件必须明确，原输入内容并不天然是正确参照

令C为原输入，A为实际部分替换后的输入，0为既定EOS基线；u为同一固定上游。定义三个输出查询坐标上的原生路由对照：

- R0 = <u,(PC−PA)V0>，固定EOS内容。
- RA = <u,(PC−PA)VA>，固定实际保留内容。
- RC = <u,(PC−PA)VC>，固定原输入内容。

这些写法表示理想算子关系，表内值来自默认BF16公共FA输出差。RA是采用“内容变化按PC分配”时的路由项；RC是反向顺序分解的路由项。它们属于不同条件，不能称某一个是唯一、不依赖背景的内在路由符号。

在三个样本的每个早/中点，新增一次公共FA( QA,KA,VC )，合计六次，即可比较：

因此根因需进一步限定：实际部分删除产生的VA，不能由“它应该更靠近VC”这一假设替代。六点RA均低于R0和RC。理想实数注意力对V线性，所以对任何统一的0≤λ≤1，参照(1−λ)V0+λVC的路由对照落在R0与RC之间，无法复现这些RA。任意BF16混合参照没有逐个执行或给出统一舍入误差界；上述凸组合结论是理想算子下的结论，不冒充对所有数值实现的穷举证明。

更直接的交互量为 RC−RA = <u,(PC−PA)(VC−VA)>。它在六点约32.47至41.02，足以改变路由项的符号。问题不只是一个EOS基线值选错了，而是**归因所使用的内容背景，没有保留部分删除时路由与内容共同变化的条件**。这也说明不能从“V0参照存在错配”直接推导“P0或V1参照一定修好”。此前P0八例质量取舍仍按实际结果保留，不重判。

## 测了一个更完整的算子思路，但廉价近似被否定

对整个注意力函数F(Q,K,V)，令X(t)=X0+t(X1−X0)，以同一u计算积分 <u,J_F(X(t))>。该路径每个节点同时改变Q/K/V，可保留节点内路由与内容的共同变化，区别于逐算子各自使用有限平均。每次均执行默认flash_attn_func及其FlashAttnFuncBackward，没有手写注意力或反向。

预先冻结两种近似：中点一节点t=1/2；两节点Gauss，t=1/2±sqrt(3)/6，权重各1/2。它们是近似，未补端点残差、拟合删除mask、裁负或修改最终分数。三个实际样本共9次FA前向和9次原生反向，另3次输入端点原生重放；重放差均为0。

## 下一项按机制和成本选择

停止本轮两种联合路径候选，以及统一固定V0/VC混合参照的权重扫描。FA19仍是未修复大项；有实际保留状态交互依据的方案才能重新进入测试。不能靠补端点守恒、局部净误差归零或更高精度宣称解决。

同时推进已有明确证据且成本较小的GDN1联合控制问题：MH2中段a→raw_g映射仍过预测约6.10264，K归一化约3.96545；单个不等端点的标量secant已被唯一确定，继续换标量斜率没有依据。下一项优先复用保存的GDN1实际状态和同一mo，检验**完整FLA端点顺序平均后，再经过原q/k归一化、beta和raw_g映射的联合输入预测**。它改变的是门控/遗忘所乘的记忆与伴随系数，不改原生模型或一个孤立标量函数。先同时比较所有分支的真实部分变化与抵消，局部值得推进才做整层、整网原指标；不能由第0层曾改善就假定第1层也有效。

现有端点平均包装器和finite_fla_by_layer接口可复用；若在第1层额外接入，FLA后端调用数由当前25变26，增加1次后端/2次原生伴随。4%仅为FLA调用数变化，不是已测耗时或显存涨幅。这个明确的小成本假设优先于无界加积分步数。该GDN1联合测试尚未执行，不把它写成修复。

任何值得接入的新方法仍必须完成固定NI0–3/MH0–3原needle/RISE/MAS并保留退步，再独立验收真实mini-batch及实际成本。本轮未更改生产方法，因此不重复已完成的八例曲线；此前K候选的104/154needle不变、MH三例MAS退步等结果仍有效，不冒称本轮新测。
