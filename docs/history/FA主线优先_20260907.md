# FA 主线优先

用户最新要求覆盖此前优化排序：**FA 尚未完成的工作优先，暂停 MLP 缓存和输出头优化。** 显存按相同 FA 条件下的速度、吞吐、长度/batch 容量共同判断，不恢复固定额外字节上限。

当前真实模型使用默认 FA；双端点有限注意力已经复用可追溯厂商 FA 框架，并完成原开发整网、真实 B2/B4、部分原长输入核验。它没有全局 N×N 归因矩阵、dense 回退或假称原生 backward。这里的“已接入”不等于 FA 配套开销已经全部处理完。

|事项|实际状态与顺序|
|---|---|
|GQA 输入|**本轮已接入并核验 B1/B4。** 旧有限路径将 8 个 K/V 头复制为 32 个头，再转换为连续布局。沿用已固定 FA 源码 `bidh / h_h_k_ratio` 的头映射，让有限内核读取紧凑 K/V；保留原输出及 FP32 GQA 求和，不改变有限数学。|
|端点平均和布局|Q/K 端点平均、输入 contiguous/half 转换、输出转换仍有内核外操作。GQA 完成后，先检查哪些可随 FA 的载入/写回完成，复用框架和默认精度；不能把这个工作计入 MLP 优化。|
|三遍有限传播|目前为 row center/tau、query、key/value 三遍。仍重复遍历 attention tiles；进一步合并须证明归一化依赖及舍入/抵消行为可接受。kernel 个数不能单独代表效率或完成度。|
|公开 LSE 获取|仍有每层额外一次真实公开 FA 调用。核对官方接口能否直接供给所需 LSE；不为省调用读取未经保证的私有槽位或复制一套 attention。|
|批处理|真实 B2/B4 已在旧有限 FA 验证；每个新 FA 改动必须区分单样本局部、整网与真实批处理状态。不能自动继承“新路径已验证 B4”。|

当前 GQA 改动保存在独立候选文件，原已验证 FA 路径保留。先编译一次，用已有原 NI0 第 35 层真实张量进行至多 6 次新旧局部算子调用，检查全部 dq/dk/dv/tau/center。不是新造 benchmark，不生成回答、不跑新删除曲线、不扫描全表。局部成功后才进入少量整网与实际 batch 检查；局部耗时不能作为整网加速结论。

此前公开 SAC 的 MLP 原型及两例结果已经保留，但其研究顺序后移；不会继续扫描缓存层数。原生 `logits_to_keep` 同样后移。最新结论以 FA 当前工作记录为准，历史报告的“下一步”保留为历史说明。


## 本轮 FA 实际产出

紧凑 GQA 版本已编译并接入单样本、真实 B4 整网路径；两份源码、旧版本及复现协议分别保留。局部 6 次算子比较的全部输出相同。随后 8 次真实归因完成，所有本次新旧完整带符号向量和端点分数相同，0 个符号翻转；不是只核对最终分数和或少量 token。

真实 B4 profile 捕获 108 次默认模型 FA kernel 和 108 个有限 FA kernel。有限输入确为 32 个 query 头、8 个共享 KV 头，批维为 4；真实模型双端点批维为 8。原生模型/FA 源码及方法未替换，原核心有限计算保持。没有 dense 回退或全局 N×N 缓冲。

局部 NI0 层 35 的接口张量总量从 54,465,024 降到 39,694,848 字节；这是该算子的张量契约之和，不是整网峰值。NI2 与 B4 的整网峰值分别保持 18,759,975,936 / 21,699,025,920 字节。不能把减少局部复制说成整网峰值下降。

B4 单次稳态配对为 1.5072→1.4864 秒，约 1.4% 耗时下降，尚无稳定性结论。NI2 旧路径本次为 1.8419 秒、候选为 0.9536 秒；旧路径相对于此前同形状约 0.99 秒有明显波动，不能把这个比值归因于 GQA 优化。没有新的 FT 成本比较，也没有新的 RISE/MAS 结论。

本轮 FA 预算实际为一次编译约 43 秒、6 次既有真实张量局部算子调用、8 次整网归因；后者作业约 90 秒，包含校验、模型加载、编译预热和已有预算内的 B4 profile。0 次生成、0 次原生 VJP、0 条质量曲线。首次整网启动因 shell 参数过长在 Python 启动前失败，未运行模型；后改为复用远端已有且哈希一致的依赖后成功启动一次，没有重复模型作业。两项 FA 作业均已结束。

下一步仍为 FA：先处理端点平均、布局/转换和 GQA 输出归并的内核外开销，同时评估三遍传播与额外公开 FA 元数据调用中的可避免重复。默认精度和真实官方后端保持；三遍减少是否可行需要证明，不能仅为降低 kernel 数而改变分配规则。MLP 与输出头研究继续暂停。新路径目前覆盖 NI2 的 B1 与原四例 B4，不自动继承更长输入或任意设备/FA 版本支持。

证据：`fa_compact_gqa_operator_summary_20260907.json`、`fa_compact_gqa_integration_summary_20260907.json`、`fa_compact_gqa_integration_numeric_20260907.json`。单样本入口 `qwen_signed_secant_paired_vendor_fa_gqa.py`，多样本入口 `qwen_signed_secant_batched_vendor_fa_gqa_public.py`，显式运行时 `VendorFAFiniteP1CompactGQA`。这些是研究候选入口，默认模型 FA 并未被替换。
