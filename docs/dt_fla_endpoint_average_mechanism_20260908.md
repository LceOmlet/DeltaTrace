# 当前 FLA 条件错配与唯一候选的范围

当前方法为第 0 层 norm-gate 对称、FLA 仍按输入控制/EOS 内容传播。NI1 原 MAS 中段固定删除集合的层误差 +23.11348，其中 FLA +21.64625；早段 FLA −1.27764 正在补偿其他项。后续修复不能从局部数字直接外推。

## 被检验的错配

以输入端点 1、EOS 端点 0 和实际部分删除状态 A 表示，在固定输入端点控制及实际输出伴随下，当前有限规则在各个乘积处的局部预测误差是：

- 读取：`(q1−qA)^T (H0−HA)`；
- 预读：`(k1−kA)^T (C0−CA)`；
- 写入内容：`(k1−kA) (u0−uA)^T`；
- 写入门：`(beta1−betaA) (c0−cA)`；
- 遗忘：`(alpha1−alphaA) (Hprev0−HprevA)`。

每项必须再与相应的当前伴随收缩并求和。原始 raw-g 到 alpha 的指数割线在部分状态上的误差另列，不能全部归到参考记忆。块计算与模型默认精度残差、B2 输入到 B1 clean 的迁移也另列。某一分支分数本身并不是以上误差。

用真实 native 端点及同一输入端点伴随，现有块系数代数计算 `M01`、`MA1`，可直接核算 `(M01−MA1)·delta_inputs` 与剩余配对残差。不需要构造新的模型反事实、运行复制的状态递推或修改 FLA。A 只用于诊断已有真实评分轨迹，生产候选不得读取测试删除状态。

## 单一候选

仅在第 0 层取完整两种端点分配的平均：

`Mavg(E0,E1;Z) = (M(E0,E1;Z) + M(E1,E0;Z))/2`。

同一个现有有限 FLA 后端执行两次。全部 11 个原生端点字段按配对行交换，时间顺序、chunk 顺序、Z、scale 不变。交换后的系数仍是原坐标乘子，因此平均时不加负号。alpha 和 raw-g 是两种坐标，整网只传播 raw-g 一次。

两种分配都满足同一个完整端点差恒等式，所以平均保留该恒等式并消除端点交换下的反对称部分。它不等同于每个局部乘积使用平均因子，也不等同于输入词集合的精确 Shapley 值。它没有对任意部分删除集合误差变小的定理。

候选的机制依据是已测的单向参考记忆错配及旧规则下中段端点平均的实际幅度改善；当前 norm-gate 已改变上游，因此旧结果仅支持选择候选，不能作为本次效果证据。若当前早段的补偿被破坏，必须在完整输入与原指标中保留该失败。

## 预算与验收

生产每个样本只多一次第 0 层有限 FLA、两个原生伴随阶段以及线性大小的端点复制/系数平均；无新模型前向、卷积、GEMM 之外的复制模型、全局序列平方矩阵。实际计算、复制和显存峰值全部纳入归因计时；复杂度未升阶不等于常数开销可忽略。

仅比较当前 control 和一个候选，先用原 NI1/MH1 数据及原函数的完整 21 点曲线。RISE、MAS 在此原实现中均为越低越好。保留 needle、同 control 删除集合的有符号预测减实际误差、正负质量、端点漂移与成本。测试没有修改 FT。两个已使用样本的结果是开发证据，不能称独立确认。

如果原指标或实际条件误差不支持候选，不默认推广、不扫描连续权重或所有层。固定加性归因不可能对包含任意交互的所有删除集合都精确：例如二元乘积 `x1*x2` 在 `(1,1)` 相对 `(0,0)` 的总贡献为 1，而单删任一个输入的效应均为 1，两者不能由同一组加性分数同时精确表达。这个限制不能当作忽略当前可修复大误差的理由，也不能将 Goal 偷换成只验证总守恒。
