## 优先级与验收

1. **先审查剩余 FA 收益，再转向其他主要耗时。** 用同一工作负载的算子剖析和完整归因配对计时判断剩余收益，记录预期收益、调用预算和停止条件。证据支持收益有限时，按实际成本处理层重放、投影/MLP、输出头、搬运或调度；不必穷尽所有 FA 微优化，也不能由一个失败候选推断全部 FA 空间耗尽。局部耗时、内核数及跨实验百分比不能冒充整网收益。

2. **保留默认模型 FA，有限传播扩展复用可追溯框架。** 优先使用已有官方/厂商算子、公开接口和编译器；必要扩展须说明上游版本、修改边界、数学规则和真实调用证据。禁止另写影子注意力、模型或 backward 冒充原生实现。双端点混合乘积仅用于归因恒等式，不冒充真实反事实前向。生产归因路径避免物化全局序列长度平方阶矩阵。

3. **完成 Qwen3.5-9B 与真实 FLA 的归因支持。** 复用远端共享权重，核验官方来源、模型类和 tokenizer。标准注意力走模型默认 FA，线性注意力走实际 FLA；端点、门控、状态递推和有限传播规则须符合新模型结构，不能直接照搬旧模型 PV 规则。验收依次覆盖真实模型执行、固定轨迹及 gold/token 映射、有限传播接入、真实异长批处理、原指标和完整成本。导入/前向成功不等于整网归因支持完成。

4. **效率、显存和批处理共同验收。** 保留 FA 常用默认精度，不追求逐位一致；检查数据流、数值影响、符号涉及的贡献、排序和原指标。效率不能严重退化，不能用不断增长的查询/积分次数换取质量。显存以相同模型、设备、FA 后端、精度、长度和实际 batch 的原生执行为参照，不设“一次反向 + 72.5 MB”等固定上限；同时报告速度、吞吐、峰值及可支持的长度/batch。支持真正的 mini-batch，不能把串行循环称为批处理。首次编译、诊断 hook 和稳态成本分开记录。

5. **只沿用官方评测，先做有决策价值的小预算验证。** 使用作者处理好的固定轨迹或严格官方生成流程，沿用原 needle、RISE/MAS 和 gold；不自行生成替代 benchmark。主对照明确为同一实际Qwen3.5权重上的FT混合架构变体；当前共享模型标识Qwen3.5-9B，不混用Qwen3-8B。候选与 FT 在同一实际模型、轨迹和可归因范围下比较，并核对 FT 是否计算了无关输出。Qwen3.5 结果属于模型扩展，不能冒称论文原表复现。已被历史实验使用的样本不能重新称为独立确认集。达到可比较状态后优先原指标和方法效果；不继续修作者框架，不以约2×10⁻⁶等微小舍入或非逐位一致延迟比较。先冻结预算与停止条件，部分结果足以改变决策就停止扩跑；不为置信区间跨零强行调参或追加样本。

6. **持续提交推送与可恢复交付。** 在 LceOmlet/DeltaTrace 保存公式、源码、来源/产物哈希、冻结协议、正负结果和下一决策；阶段完成后提交、推送、核对远端提交并验证 Git bundle。开发草稿标注未执行或未验证，不能只保存在远端临时目录，也不能混入已验证成果。

**本次追加要求的执行顺序：** FA 剩余收益的证据足以支持转向时，停止低收益微调并处理其他主要耗时；Qwen3.5-9B 必须完成默认 FA 与真实 FLA 的整网有限传播和异长批处理，不能仅以权重加载或局部算子通过交付；每个完成阶段提交、推送并验证可恢复备份。具体实验仍先冻结调用预算和停止条件，不因 Goal 进行中而自动重复已关闭实验。
