## 优先级与验收

测试运行期间并行分析已有逐例曲线、实际传播残差与最明显错配，准备有区分力的下一项最小测试；不把等待指标当作研究进展。GPU 任务按冻结预算调度，已有实际状态与系数优先复用，避免为内部定位反复计算整网归因。

**本轮覆盖要求（执行前冻结）：** 作者缓存中的 NI0–3/MH0–3 共八例构成预先指定的开发比较集合，不能观察改善后挑选报告样本，也不能把已用样本称为独立留出集。旧 DT 固定为第 0 层 symmetric norm-gate 与原有限 FLA；新 DT 只增加已冻结的第 0 层完整 FLA 端点平均；原 FT 保持完整公共实现，评分的输出/跳数在协议中预先指定，不能根据结果选优或省掉原 trace 的内部工作。同一实际权重、原输入/目标、eligible 范围、原 gold/跨度映射和评分器须逐项核对；FT 与 DT 原有内部目标不同须披露，不能改 seed 假称相同。

- 逐例报告原 needle、RISE、MAS、原始曲线及候选减对照差值，再报告各数据集与全固定集合的均值、成对退步数量和幅度。RISE/MAS 越低越好；无 author gold 的 needle 记为不可用，不编造标签或记作零，均值分母和有效例数预先约定。
- 保存全部成功、退步、异常和未完成例，不从改善样本决定报告范围。因来源/输入/数值检查或资源停止时，明确哪部分尚未覆盖，不能删除失败例后冒充八例通过。
- 真实 mini-batch 单独验证样本数、各自目标 offset/EOS 范围、真实 mask、输出拆分及符号/原指标；两个端点行 B2 仍只代表一条样本，两条真实样本通常需要四个端点行。串行逐例循环、FLA 内部 tile padding 或接受偶数端点的 API 都不构成 batch 验收。真实多样本、异长 mask 与相应成本证据缺一项，就保留该范围未完成。
- 分阶段控制预算：先用 CPU 核对固定记录、来源和已有可复用证据，再冻结必要归因/原 scorer 调用与停止条件；真实 batch 从最小有区分力的样本数开始另列预算。模型加载、编译、warmup、measured、诊断和失败全部记账；成本同时报告延迟、每样本摊销、吞吐、常驻基线及峰值，不将两次热调用的近似持平宣称为加速。只复用已核验输入/目标/来源及实际删除输入身份的结果，不为非逐位一致重复已有测量，不自动扩样、加候选或调层权重。

**质量定位首要门槛：根因分析与最明显错配结合。** 先成对记录实际目标/操作数/删除集合产生的变化和当前归因预测，定位最明显且可复现的差值；核查端点、系数坐标、目标行与缓存是否接错，再区分实现错误与方法的条件传播失配。每个修法必须指向一个具体错配，给出计算机制、预计有符号变化、抵消风险和成本理由。不以抽象的“更稳定”替代证据，不因此展开无关的框架修补或全量测试。

**历史控制内容错配定位（不能替代当前覆盖）：** 更新门局部残差(c0−cA)(beta1−betaA)成立；NI1中段目标投影为−0.7572，不能解释同点FLA的+36.1625总过估。原生写入与CPU局部数学读出差另列，不将它们称为完全一致。修复norm-gate后FLA投影误差降为+6.1277；这是上游系数改变，不能称为beta规则已被修好。读取/遗忘等剩余分支应按新的最大实际错配决定是否细拆，不机械展开所有分支。

1. **先完成当前固定质量覆盖，再按证据处理工程收益。** 后续用同一工作负载的算子剖析和完整归因配对计时判断剩余收益，记录预期收益、调用预算和停止条件。证据支持收益有限时，按实际成本处理层重放、投影/MLP、输出头、搬运或调度；不必穷尽所有 FA 微优化，也不能由一个失败候选推断全部 FA 空间耗尽。局部耗时、内核数及跨实验百分比不能冒充整网收益。

2. **保留默认模型 FA，有限传播扩展复用可追溯框架。** 优先使用已有官方/厂商算子、公开接口和编译器；必要扩展须说明上游版本、修改边界、数学规则和真实调用证据。禁止另写影子注意力、模型或 backward 冒充原生实现。双端点混合乘积仅用于归因恒等式，不冒充真实反事实前向。生产归因路径避免物化全局序列长度平方阶矩阵。

3. **完成 Qwen3.5-9B 与真实 FLA 的归因支持。** 复用远端共享权重，核验官方来源、模型类和 tokenizer。标准注意力走模型默认 FA，线性注意力走实际 FLA；端点、门控、状态递推和有限传播规则须符合新模型结构，不能直接照搬旧模型 PV 规则。验收依次覆盖真实模型执行、固定轨迹及 gold/token 映射、有限传播接入、真实异长批处理、原指标和完整成本。导入/前向成功不等于整网归因支持完成。

4. **效率、显存和批处理共同验收。** 保留 FA 常用默认精度，不追求逐位一致；检查数据流、数值影响、符号涉及的贡献、排序和原指标。效率不能严重退化，不能用不断增长的查询/积分次数换取质量。显存以相同模型、设备、FA 后端、精度、长度和实际 batch 的原生执行为参照，不设“一次反向 + 72.5 MB”等固定上限；同时报告速度、吞吐、峰值及可支持的长度/batch。支持真正的 mini-batch，不能把串行循环称为批处理。首次编译、诊断 hook 和稳态成本分开记录。

5. **只沿用官方评测，先做有决策价值的小预算验证。** 使用作者处理好的固定轨迹或严格官方生成流程，沿用原 needle、RISE/MAS 和 gold；不自行生成替代 benchmark。主对照明确为同一实际Qwen3.5权重上的FT混合架构变体；当前共享模型标识Qwen3.5-9B，不混用Qwen3-8B。候选与 FT 在同一实际模型、轨迹和可归因范围下比较，并核对 FT 是否计算了无关输出。Qwen3.5 结果属于模型扩展，不能冒称论文原表复现。已被历史实验使用的样本不能重新称为独立确认集。达到可比较状态后优先原指标和方法效果；不继续修作者框架，不以约2×10⁻⁶等微小舍入或非逐位一致延迟比较。先冻结预算与停止条件，部分结果足以改变决策就停止扩跑；不为置信区间跨零强行调参或追加样本。

6. **持续提交推送与可恢复交付。** 在 LceOmlet/DeltaTrace 保存公式、源码、来源/产物哈希、冻结协议、正负结果和下一决策；阶段完成后提交、推送、核对远端提交并验证 Git bundle。开发草稿标注未执行或未验证，不能只保存在远端临时目录，也不能混入已验证成果。

**工程阶段仍保留的执行原则：** 当前固定多样本质量比较优先；进入工程阶段后，FA 剩余收益的证据足以支持转向时，停止低收益微调并处理其他主要耗时；Qwen3.5-9B 必须完成默认 FA 与真实 FLA 的整网有限传播和异长批处理，不能仅以权重加载或局部算子通过交付；每个完成阶段提交、推送并验证可恢复备份。具体实验仍先冻结调用预算和停止条件，不因 Goal 进行中而自动重复已关闭实验。
