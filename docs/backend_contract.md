# 后端契约与批处理

当前优先级：保留 P1 质量收益，效率与显存必须实测；双端点算法不应随 FA 私有内核、参数结构或编译 ABI 的变化反复移植。公开接口不变时应无需修改算法；接口破坏性变化须显式失败，禁止静默替代后端。

现有真实模型一直使用已安装的默认厂商 FA。当前捕获实现仍观察 `_flash_attn_forward` 并读取私有返回槽位；这是已经确认的版本耦合，不能称为通用兼容方案。下一个候选边界是公开 `flash_attn_func` 的实际输入/输出，以及公开 `return_attn_probs=True` 所返回的 LSE。只使用文档定义的 LSE，不使用文档明确不保证正确缩放的 S_dmask。必要的额外默认 FA 调用必须计费并比较实际端点输出；严重变慢不能因可维护性而接受。

这只解决端点信息的接口边界，不代表整个有限传播已进入 FA 内核。P1 的价值分支为 `P1.T @ M_out`，路由分支仍依赖两个端点概率的 logarithmic mean；默认单端点 backward 没有直接提供该有限算子。不能把普通梯度更名为双端点有限传播，也不能把旧版 FA 源码补丁当作零适配方案。能否在稳定公开算子层以可接受成本表达完整方法，尚需验证。

MetaX 官方2.5.3源码与编译诊断保留为来源证据，不作为默认运行时依赖。本项目不安装它、不覆盖当前2.6.3、不修改模型标准前后向。独立有限传播算子必须明确命名、声明自己的数学含义；不能把自己的注意力前向伪装成模型实际端点。

批处理分两层：

1. 原评估器 `compute_logprob_response_given_prompt` 已公开接受 `[B,N]` 与 `[B,M]`。优先按相同提示/响应长度分组，直接调用这个未修改方法，一次评估多个实际删除状态；不换评分公式、gold、生成轨迹或删除顺序。先比较 B=1/2/4 的真实曲线差异、吞吐量和显存，再选批量。
2. 当前归因 B=2 是一个样本的两个端点。多样本归因需要明确 `sample × endpoint` 索引、各样本目标与 mask，以及独立的归因结果。尚未实现，不把第一层批量评估或单样本双端点称为此能力。

所有批量报告同时统计物理调用数和样本/端点轨迹数；批量调用不是一个样本的成本。失败、OOM 和重试也计入，不自动降低批量后隐藏失败。

批量调度代码已保存于 [`original_ft_batched_evaluation.py`](../research/runtime/original_ft_batched_evaluation.py)。首个冻结检验使用 NI0、NI2、MH0 上的 P1 与最佳 RISE FT 的六条原曲线；每个 B=1/2/4 一次预热、两次实测，实际预算453次根前向、777条评估轨迹、0次归因/反向。现已独立核验：B4提速1.19—1.52x，最大RISE/MAS差约0.000287/0.000456，三例均在冻结容差内；限实际长度与样本范围。[完整结果](history/默认FA兼容边界与原评估批处理_20260907.md)。
