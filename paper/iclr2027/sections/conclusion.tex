\section{Conclusion}
DT assigns signed token contributions to the change in a complete response's log-probability between reference and original inputs. Its reverse pass uses coefficients relating input and output differences in place of local derivatives. The attention and Gated DeltaNet examples illustrate how the two executions define backward calculations within this procedure. The resulting token scores sum to the response-score difference. Tiled attention and chunked memory make the auxiliary storage linear in sequence length at fixed model dimensions and chunk size. The experiments measure evidence recovery, deletion faithfulness, and attribution cost on attention and hybrid models.
