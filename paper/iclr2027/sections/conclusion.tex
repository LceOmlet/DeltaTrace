\section{Conclusion}
DT assigns signed token contributions to the change in a complete response's log-probability between reference and original inputs. Its reverse pass composes finite changes through the model, following both the evidence carried by values and the attention or memory operations governing its use. The resulting token scores sum to the response-score difference. Tiled attention and chunked memory make the auxiliary storage linear in sequence length at fixed model dimensions and chunk size. The experiments measure evidence recovery, deletion faithfulness, and attribution cost on attention and hybrid models. The same reference-based construction motivates the policy-learning extension in Appendix~\ref{app:credit}.
