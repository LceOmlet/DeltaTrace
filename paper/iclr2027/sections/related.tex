\section{Related Work}

\paragraph{Reference-based attribution.}
Integrated Gradients integrates input sensitivities between a baseline and the input; DeepLIFT propagates activation differences into source contributions \citep{sundararajan2017axiomatic,shrikumar2017deeplift}. Conservative Propagation and AttnLRP develop relevance rules for transformers \citep{ali2022conservative,achtibat2024attnlrp}. DT uses a reference difference for the log-probability of a complete response and supplies finite rules for attention selection and gated memory. The local rules determine how input tokens share that score difference.

\paragraph{Tracing source information.}
ALTI aggregates token interactions across layers, and DecompX propagates decomposed representations to the prediction head \citep{ferrando2022alti,modarressi2023decompx}. Information Flow Routes traces influential computations, while FlashTrace aggregates response spans and recursively follows their source importance \citep{ferrando2024information,pan2026flashtrace}. DT combines the response positions in one scalar target and follows both the transported values and the controls selecting them.

\paragraph{Recurrent models.}
MambaLRP conserves relevance through selective state-space computation, and LaTIM decomposes token interactions in Mamba models \citep{jafari2024mambalrp,pitorro2025latim}. DT follows the retained state, write correction, and query read of Gated Delta Networks \citep{yang2024gated}. Its memory and attention paths use the same content and control split, with computation organized through FlashAttention tiles and FLA chunks \citep{dao2022flashattention,yang2024fla}.
