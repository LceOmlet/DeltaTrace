\section{Introduction}
\label{sec:introduction}

Input attribution assigns scores to the words in a prompt to explain a model's response. A reasoning response depends on both the information available and the computations that select and combine it \citep{ferrando2024information}. Figure~\ref{fig:overview}(d) shows a passage containing a playwright, William Shakespeare, and a composer, William Walton. The names supply candidate answers, and the phrase ``the author of the play'' specifies which role to use. Attribution should account for how both the candidate names and the requested role affect the response. It should also distinguish words that support the response from words that oppose it.

We ask how replacing selected prompt tokens would change the model's score for a chosen response span. The reference replaces these source tokens with a common reference token at the same positions. Both executions score the same target span using the fixed response prefix. The target can be an answer span or the complete reasoning and answer. We assign each source token a signed share of the resulting log-probability difference, so the contributions add across words or passages.

Attribution must specify both the score being explained and how it is assigned to input sources. Integrated Gradients and DeepLIFT assign prediction differences relative to a reference \citep{sundararajan2017axiomatic,shrikumar2017deeplift}. Relevance propagation and representation decomposition trace information through attention and recurrent states \citep{ali2022conservative,achtibat2024attnlrp,jafari2024mambalrp,modarressi2023decompx,pitorro2025latim}. FlashTrace follows source importance through multi-token responses \citep{pan2026flashtrace}. For the fixed-response question above, the target is a finite log-probability difference. Computing token contributions requires relating the response-score difference to activation differences throughout the model.

Replacing a source token changes intermediate activations throughout the model. Several inputs to the same operation can change together, so assigning the response-score difference requires accounting for their combined effect. The backward calculations below illustrate this problem with two examples. An attention product receives changing value vectors and attention weights. Gated DeltaNet receives changing values, keys, queries, and gates that affect its memory updates and reads \citep{yang2024gated}.

\dt{} modifies backpropagation so that input-token contributions explain the measured change in a fixed response's log-probability. Local derivatives describe small changes around one execution. We replace them with coefficients relating each operation's actual input and output changes between the original and reference executions. A single reverse pass combines these relations across the model, giving token contributions that add to the response-score difference. Scoring the reasoning and answer together combines a source word's effects across response positions into one signed contribution. Positive and negative scores then identify supporting and opposing evidence for the response as a whole. Figure~\ref{fig:overview}(a) shows the complete method, while (b) and (c) illustrate its backward calculations for two operations.

\paragraph{Contributions.}
\begin{itemize}
\item \textbf{Signed evidence for the reasoning and answer together.} DT combines a source token's effects across response positions into one contribution to the full response's score difference. The signed scores identify support and opposition and can be summed to explain sentences or passages (Section~\ref{sec:reverse}).
\item \textbf{One procedure for attention and linear attention.} We derive backward calculations for attention products, normalization, and Gated DeltaNet as examples of the operations handled by \dt{}. These calculations account for simultaneous changes in their inputs, allowing the same attribution procedure to follow attention and recurrent memory (Sections~\ref{sec:attention}--\ref{sec:memory}).
\item \textbf{Auxiliary storage linear in sequence length.} FlashAttention-style tiles \citep{dao2022flashattention} and Flash Linear Attention (FLA) chunks \citep{yang2024fla} bound the workspace used for intermediate products. At fixed model dimensions and chunk size, longer inputs and responses require only linear growth in auxiliary storage (Section~\ref{sec:computation}).
\end{itemize}

On Qwen3-8B retrieval and reasoning tasks, \dt{} achieves the lowest deletion-faithfulness scores on most tasks and the highest evidence recovery across the six needle-in-a-haystack tasks (Section~\ref{sec:evaluation}). On Qwen3.5-9B, \dt{} lowers RISE on 10 of 13 tasks and MAS on 12 relative to FlashTrace.
