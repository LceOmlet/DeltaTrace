\section{Introduction}
\label{sec:introduction}
\input{figures/intro_teaser}

Input attribution assigns scores to the words in a prompt to explain a model's response. A reasoning response depends on both the information available and the computations that select and combine it \citep{ferrando2024information}. Figure~\ref{fig:overview} shows a passage containing a playwright, William Shakespeare, and a composer, William Walton. The names supply candidate answers; the phrase ``the author of the play'' specifies which role to use. An explanation should follow both the supplied content and the control that directs its use. It should also distinguish words that support the response from words that oppose it.

We study this task by comparing the same response under two inputs. The original input contains the context and question. A reference replaces the source tokens being explained with end-of-sequence (EOS) tokens at the same positions. Both executions score the same complete reasoning and answer, token by token. The resulting difference in log-probability is the quantity to explain. We assign each source token a signed share of that difference, so the scores have a common meaning and add across words or passages.

Reference-based methods already assign prediction differences to inputs through integrated gradients or propagated activation differences \citep{sundararajan2017axiomatic,shrikumar2017deeplift}. Relevance propagation and representation decomposition trace how information moves through attention and recurrent states \citep{ali2022conservative,achtibat2024attnlrp,jafari2024mambalrp,modarressi2023decompx,pitorro2025latim}. FlashTrace follows source importance through multi-token responses \citep{pan2026flashtrace}. Our goal is to combine a signed score for a complete response with explicit attribution through the operations that select, store, and retrieve its evidence.

The difficulty is that content and control change together. Changing a token can alter both its value vector and the attention weights that select it. Those weights compete because their sum is one. In gated memory, a new value changes a state assembled from earlier tokens, while keys, queries, and gates determine what is written, retained, and read \citep{yang2024gated}. Tracing only the transported content leaves these selection and memory decisions outside the explanation. Tracing both requires local rules that account for their joint changes and can be composed across the whole response.

We introduce \dt{}, which turns two forward executions into signed input contributions through one reverse pass. The forward runs supply the original and reference activations. Analytic rules use these pairs to replace each local Jacobian with a finite change map. The reverse pass applies the transposed maps to coefficients, starting with $1$ at the response score. At the input, each coefficient vector is dotted with its embedding difference to obtain a token's contribution. Thus the forward runs provide the changes, while the reverse pass supplies their multipliers. Attention rules follow content and selection; memory rules follow retention, writing, and reading. The resulting token contributions sum to the response-score difference.

The computation follows the same structure as accelerated attention. FlashAttention-style tiles process small blocks of token interactions \citep{dao2022flashattention}; Flash Linear Attention (FLA) processes memory in consecutive chunks \citep{yang2024fla}. Accumulating coefficients within these blocks gives auxiliary storage linear in sequence length at fixed model dimensions and chunk size.

On Qwen3-8B retrieval and reasoning tasks, \dt{} achieves the lowest deletion-faithfulness scores on most tasks and the highest evidence recovery across the six needle-in-a-haystack tasks (Section~\ref{sec:evaluation}). Qwen3.5-9B measurements evaluate the same rules in a model with attention and gated memory. Appendix~\ref{app:credit} develops a policy-learning extension: averaging action-level return differences over a policy reference recovers the advantage, the return above that policy's expected return \citep{sutton1999policy,foerster2018counterfactual}.
