# DeltaTrace：摘要与引言的论证安排

中心论点：**输入既提供信息，也决定信息如何被选择和保留；DeltaTrace 沿实际计算传播有限变化，将这些作用统一分配为对完整回答的有符号信用。**

## 面向审稿人的贡献归纳

最有说服力的组织，是让定义、机制和计算形成同一条论证链。明确干预对象和回答目标，使信用的因果含义具体；有限链式法则使正负信用具有守恒的数值意义；内容与控制的解析传播说明这些信用怎样产生；FA／FLA 实现说明这种解释怎样在实际架构中执行。实验和真实热力图为这条主线提供可检查的证据。

论文保留三项集中贡献：

1. **有限干预定义下的有符号信用。** 原输入与参考输入共享固定回答，以回答 log-probability 的有限变化为分配对象。守恒保证各来源解释同一个总效应，正负号区分支持与反向作用，词段得分由 token 分数相加。
2. **统一的内容与控制机制。** Attention 同时传播内容变化与选择变化；解析 softmax 处理来源间的竞争。GDN 将同一原则延伸到状态、键、查询以及保留和写入门。
3. **支持加速注意力计算的实现。** FlashAttention 风格的 tile 归约与 Flash Linear Attention 原生 chunk 状态伴随、矩阵乘法和 scan 承接相同有限规则；固定维度和 chunk 大小时辅助存储随序列长度线性增长。

开发实验在贡献段之后集中呈现：两个模型各 8 个检索和 8 个多跳案例，形成 32 个配对模型／案例观测。检索召回与 MAS 对应证据恢复和删除评价；真实正负热力图对应解释内容。

强化学习作为这一信用定义带来的研究视角放在引言结尾。精确平均的动作反事实回报差与优势函数的关系，给未来研究一个明确目标；附录给出参考动作分布、轨迹平均条件和学习信号等式。具体推进方向是借助计算或环境结构估计奖励信用，以及研究估计方差和无关时间延长下的稳定性。

## 摘要的句子安排

摘要在引言和贡献定位完成后撰写，依次完成八件事：

1. 直接提出解释对象：输入提供的证据与控制证据使用的决策。
2. 引入 DeltaTrace 和有限输入干预。
3. 定义完整固定回答的 log-probability 差。
4. 给出解析局部规则、一次反向组合及有符号守恒的优势。
5. 用 Attention 与 GDN 的具体动作说明内容／控制机制。
6. 明确 FlashAttention／Flash Linear Attention 支持与辅助存储界。
7. 给出配对开发实验的样本范围和检索召回增量。
8. 由反事实信用接到优势信号，提出 RL 研究方向。
