\begin{abstract}
Explaining a reasoning model's answer involves tracing how input evidence contributes to its prediction. These contributions carry both magnitude and direction: different sources can support or oppose the same response. We present \dt{}, a method that propagates signed contributions from a response to its input sources. The method decomposes changes in model computations into content and routing contributions, follows them through attention and gated memory, and preserves their sum through a finite chain rule. An analytic treatment of attention normalization connects changes in routing probabilities to changes in attention scores. A corresponding memory recurrence tracks how evidence is retained, read, and updated. The resulting propagation admits tiled attention contractions and chunked memory computation, with sequence-linear auxiliary storage at fixed model dimensions. \dt{} provides a common attribution framework for attention and hybrid reasoning models. Its evaluation protocol combines source recovery and the original FlashTrace faithfulness metrics with complete attribution cost measurements.
\end{abstract}
