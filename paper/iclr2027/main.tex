\begin{abstract}
Explaining a reasoning response requires tracing input evidence and the controls governing its use. We introduce \dt{}, which assigns signed input-token credit to a finite intervention between reference and original inputs. Analytic operator rules compose in one reverse traversal, allocating the change in the same complete response's log-probability. Supporting and opposing source contributions sum to this change. The rules follow content and control together: attention propagates transported values and selection changes; gated delta memory propagates stored content with the keys, queries, and gates governing retention, writing, and reading. Analytic normalization preserves competition among attention sources. FlashAttention-style tiling and Flash Linear Attention chunked computation give sequence-linear auxiliary storage at fixed model dimensions and chunk size. On Qwen3-8B retrieval and reasoning benchmarks, \dt{} achieves the lowest RISE and MAS on most tasks and the highest NIAH recovery, exceeding FlashTrace by 3.96--19.60 percentage points. Separate Qwen3.5-9B development measurements demonstrate the hybrid-model implementation and a 35.3\% throughput increase from real batching and GPU checkpoints. The counterfactual formulation also motivates finite credit propagation for policy learning, where exactly averaged action-level return contrasts recover the advantage signal.
\end{abstract}
