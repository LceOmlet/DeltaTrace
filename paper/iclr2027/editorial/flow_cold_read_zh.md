# 图 1 与方法计算流程的独立冷读

## 阅读边界与次序

仅以固定快照 `paper/iclr2027/tmp/pdfs/flow-reader/figure1.png` 和同目录 `manuscript.pdf` 为证据。未读实现、旧稿或既有评审。先看图 1，冻结以下理解，再单次通读 PDF 方法节。

## 仅看图 1 时的第一遍理解（读正文前记录）

1. **两次前向。** 输入是等长的 EOS 参考输入 x₀、原始词序列 x₁，以及固定响应 y。两个分支都经过注意力或 GDN、MLP 和残差，得到标量 F(x₀; y)、F(x₁; y)，差值应为 ΔF = F(x₁; y) − F(x₀; y)。图没有单独定义 F 的具体分数含义。
2. **形成局部变化规则。** 从两次运行得到的局部激活差 Δa、Δh，构造满足 Δh = D_f Δa 的局部线性规则。这里的 D_f 看起来是两点间的有限差规则，而不是单次前向的普通雅可比；图尚未明确这一点，也没说明规则是保存为矩阵还是按算子计算。
3. **一次反向传系数。** 令输出系数 m_F = 1，逐个局部算子应用 m_a = D_fᵀ m_h，得到输入位置 i 的嵌入系数 m_i。紫色箭头和编号让我理解为：反向的对象是解释 ΔF 的系数，不是在两个前向分支上各自求梯度。
4. **输入端计分。** 输入是 m_i 和原始/参考输入嵌入差 Δe_i，输出 A_i = ⟨m_i, Δe_i⟩。全部输入源的分数之和是 ΔF，示例中只展示其中几个词段。
5. **注意力的局部例子。** 两次前向给出 P₀、P₁、V₀、V₁。以 ΔY = P₁ΔV + ΔP V₀ 分成内容变化和选择变化。反向的输入是输出系数 M_Y，输出是 M_V = P₁ᵀM_Y 与 M_P = M_YV₀ᵀ。图未展开 M_P 怎样继续穿过 softmax 和 QKᵀ；我把它理解为局部例子，不会据此断言整个注意力只做这两步。
6. **GDN 的局部例子。** 前向示意是先用 α 保留旧状态，再加 k uᵀ 得新状态，再以 q 读取 o_t。右侧明确标出 Retention: T = αS，因此 ΔT = α₁ΔS + S₀Δα 及对应 M_S、m_α 应只讲保留这一步。图没有说明 u 的来源，也没有给出写入和读出的反向步骤。

读图后待正文解答的疑问：F 是什么分数；m 是否只是普通梯度；D_f 如何来自两次前向并在真实网络中执行；注意力选择分支如何走到底；GDN 写入/读出及时间反向如何与保留例子接起来；示例中“全部输入源”具体包括什么。

## 通读后能够复述的实际计算流程

1. 固定模型参数、原始 prompt、需要解释的 source positions 和响应 y；按选定 source positions 构造参考 prompt。输入变化仅在这些位置的嵌入上非零。
2. 对原始和参考输入分别做真实前向，均用相同响应前缀评分，得到 F₁、F₀ 与成对激活所确定的变化。输出目标是 ΔF = F₁ − F₀。
3. 从标量输出系数 1 开始向输入反向遍历。每个局部操作的输入是成对激活和传入的输出系数，输出是该操作各输入的系数。D_f 表示所采用的有限变化规则；运行时需要的是它的转置作用，而不是先显式构造一张全网矩阵。
4. 在注意力的 PV 操作，M_Y 分出 M_V 和 M_P；V 路径继续向输入表示走，P 路径经有限 softmax、query–key 操作继续走。局部 ΔY 恒等式说明两种变化怎样分配，其右端各项不是算法需要另行向前运行的两条网络。
5. 在记忆层，前向顺序是保留旧状态、根据保留状态计算写入校正、更新状态、读出。反向按相反顺序，把系数交给状态、query、key、value 与两个 gate；时间上的状态路径继续传向先前位置或 chunk，多条返回路径按通用规则累加。
6. 其余线性层、残差、非线性和归一化继续同一次反向遍历。高效实现逐层重算局部激活，在注意力 tile 或记忆 chunk 内计算并累加系数。
7. 在输入嵌入端形成 A_i = ⟨m_i, Δe_i⟩。固定 token 因 Δe_i = 0 得零分；所有 source 的有符号分数相加得到 ΔF，也可以再按词段求和。

## 结论与最小修补建议

**就“图 1 加方法节通读一遍能否理解计算过程”而言，本轮通过，没有发现需要修正的实质流程问题。** 前向计算什么、反向传什么、局部恒等式怎样导出反向更新、局部例子怎样接入完整网络，这四件事都已交代清楚。没有读完正文仍然无法排除的误导，因此不建议为此增加正文推导、伪代码或算子细节。

仅有两处可选的图内提示，作用是让单独看图的读者更快确定符号含义；它们不属于正文必须修改的问题：

- **图 1(a)，第 3 步。** 将 `propagate m` 改为 `propagate coefficients m`。一个名词即可确认反向传递的对象。正文行 180–186 已解释充分，不需要再加段落。
- **图 1(b)/(c)，共用符号提示。** 在合适的小字位置补 `0: reference; 1: original`。图 (c) 左边用 t−1/t 表示递归时间，右边又用 S₀、α₁ 表示两次运行，独立看图时这两类下标存在混读的可能。该提示与正文行 149–150 完全一致，无须改公式，也不需要展开 GDN 的完整反向式。

以上第二点是一个预防性的标注建议，并非本次读者在通读后仍然混淆；第一遍图读中，我已根据相邻注意力例子把 0/1 理解为成对运行。图 (c) 没有展示 u 的内部依赖，但正文在给出逆序传播前先完整定义了它，故不将这一简化列为待修问题。
