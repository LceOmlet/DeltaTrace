## Focus checks

- **CLP:** The current expansion, Context Length Probing, is correct. The original method varies the available left-context length; its differential score measures the change in KL divergence to the maximum-context output distribution when context is extended. It is a black-box probability-distribution method. See Sections 3.1–3.3 of the [original ACL paper](https://aclanthology.org/2023.acl-short.92.pdf). Independent title/author lookup was necessary because FlashTrace's reference points to `2023.acl-long.310`; the actual paper is [ACL 2023 short.92](https://aclanthology.org/2023.acl-short.92/), pp. 1067–1079. This is a source-side link error, absent from the present bibliography.
- **RISE deletion:** The manuscript correctly describes an area under a score curve after removing highly ranked inputs; lower is better. This is the deletion metric associated with RISE. The original paper separately introduces a randomized-mask attribution algorithm; the manuscript does not confuse the two. See the [primary paper, Sections 1 and 4](https://arxiv.org/pdf/1806.07421).
- **MAS:** Magnitude Aligned Scoring is the correct name. Sections 4.1–4.2 compare model response and attribution density and add an alignment penalty for deletion. For deletion, density is remaining attribution mass; equivalently, removed mass aligns with the score drop. The manuscript's concise description is supported. [Original IJCAI paper](https://www.ijcai.org/proceedings/2024/0059.pdf). FlashTrace Eq. 34 prints cumulative removed mass against remaining score, unlike the original deletion-density definition; the manuscript does not reproduce that equation.
- **PyTorch VJP footnote:** The existing [PyTorch 2.14 documentation URL](https://docs.pytorch.org/docs/2.14/generated/torch.func.vjp.html) resolves and describes the returned function's action on cotangents. This supports the conventional reverse derivative product, written `J_f(a)^T g_h` with column-vector gradients. The current text introduces ordinary backpropagation first, then compares its structure with finite propagation. It does not assert that DeltaTrace calls `torch.func.vjp`; preserve that conceptual comparison.
- **Qwen3.5 architecture sentence:** The Gated Delta Networks citation grounds the memory rule. The model-specific interleaving is independently confirmed by the Qwen team's [Qwen3.5-9B model card](https://huggingface.co/Qwen/Qwen3.5-9B), whose model description lists Gated DeltaNet and gated-attention layers. No extra model detail is needed in the prose.

## Discrepancy requiring reconciliation

`sections/evaluation.tex` describes the external timing curves as published six/eight-GPU measurements. FlashTrace Appendix C states five A800 GPUs and 400 GB in both [v1](https://arxiv.org/html/2602.01914v1) and [v4](https://arxiv.org/html/2602.01914v4). This is a provenance mismatch between that sentence and the cited paper, not evidence that the plotted numbers are wrong. Reconcile the phrase with the actual timing source before changing a hardware count.

The explicitly cited [Table 1 release](https://github.com/wbopan/flashtrace/releases/tag/table1-data-v1) confirms the prepared-cache provenance, Qwen3-8B attribution model, and 48 HotpotQA examples; it explicitly corrects several paper-text details. The manuscript's release-based sample framing should be retained. This audit does not substitute paper-text experimental settings for the released protocol.
