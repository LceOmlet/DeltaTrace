# Abstract

We introduce DeltaTrace, which assigns signed scores to input words to explain a complete reasoning response. It compares the response's log-probability under the original prompt and a reference that replaces source words with end-of-sequence tokens. Analytic rules convert the observed activation changes into coefficients for one reverse pass, analogous to gradient backpropagation. The token scores sum to the response-score difference. The rules follow content and control together: attention traces values and their selection; gated delta memory traces stored content and the keys, queries, and gates controlling retention, writing, and reading. Analytic normalization accounts for competition among attention sources. FlashAttention-style tiling and Flash Linear Attention chunks give sequence-linear auxiliary storage at fixed model dimensions and chunk size. On Qwen3-8B retrieval and reasoning tasks, DeltaTrace achieves the lowest deletion-faithfulness scores (RISE and MAS) on most tasks and the highest needle-in-a-haystack Recall, exceeding FlashTrace by 3.96–19.60 percentage points. Qwen3.5-9B development measurements evaluate the hybrid-model implementation; batching with GPU checkpoints increases throughput by 35.3%. The same reference-based formulation motivates policy learning, where exactly averaged action-level return differences recover the advantage signal.

# Introduction

Input attribution assigns scores to the words in a prompt to explain a model's response. A reasoning response depends on both the information available and the computations that select and combine it ([1](https://aclanthology.org/2024.emnlp-main.965/)). Figure 1 shows a passage containing a playwright, William Shakespeare, and a composer, William Walton. The names supply candidate answers; the phrase “the author of the play” specifies which role to use. An explanation should follow both the supplied content and the control that directs its use. It should also distinguish words that support the response from words that oppose it.

We study this task by comparing the same response under two inputs. The original input contains the context and question. A reference replaces the source tokens being explained with end-of-sequence (EOS) tokens at the same positions. Both executions score the same complete reasoning and answer, token by token. The resulting difference in log-probability is the quantity to explain. We assign each source token a signed share of that difference, so the scores have a common meaning and add across words or passages.

Reference-based methods already assign prediction differences to inputs through integrated gradients or propagated activation differences ([2](https://proceedings.mlr.press/v70/sundararajan17a.html), [3](https://proceedings.mlr.press/v70/shrikumar17a.html)). Relevance propagation and representation decomposition trace how information moves through attention and recurrent states ([4](https://proceedings.mlr.press/v162/ali22a.html), [5](https://proceedings.mlr.press/v235/achtibat24a.html), [6](https://papers.neurips.cc/paper_files/paper/2024/hash/d6d0e41e0b1ed38c76d13c9e417a8f1f-Abstract-Conference.html), [7](https://aclanthology.org/2023.acl-long.149/), [8](https://aclanthology.org/2025.acl-long.1194/)). FlashTrace follows source importance through multi-token responses ([9](https://arxiv.org/abs/2602.01914)). Our goal is to combine a signed score for a complete response with explicit attribution through the operations that select, store, and retrieve its evidence.

The difficulty is that content and control change together. Changing a token can alter both its value vector and the attention weights that select it. Those weights compete because their sum is one. In gated memory, a new value changes a state assembled from earlier tokens, while keys, queries, and gates determine what is written, retained, and read ([10](https://arxiv.org/abs/2412.06464)). Tracing only the transported content leaves these selection and memory decisions outside the explanation. Tracing both requires local rules that account for their joint changes and can be composed across the whole response.

We introduce DeltaTrace, which turns two forward executions into signed input contributions through one reverse pass. The forward runs supply the original and reference activations. Analytic rules use these pairs to replace each local Jacobian with a finite change map. The reverse pass applies the transposed maps to coefficients, starting with 1 at the response score. At the input, each coefficient vector is dotted with its embedding difference to obtain a token's contribution. Thus the forward runs provide the changes, while the reverse pass supplies their multipliers. Attention rules follow content and selection; memory rules follow retention, writing, and reading. The resulting token contributions sum to the response-score difference.

The computation follows the same structure as accelerated attention. FlashAttention-style tiles process small blocks of token interactions ([11](https://arxiv.org/abs/2205.14135)); Flash Linear Attention (FLA) processes memory in consecutive chunks ([12](https://github.com/fla-org/flash-linear-attention)). Accumulating coefficients within these blocks gives auxiliary storage linear in sequence length at fixed model dimensions and chunk size.

On Qwen3-8B retrieval and reasoning tasks, DeltaTrace achieves the lowest deletion-faithfulness scores on most tasks and the highest evidence recovery across the six needle-in-a-haystack tasks (Section 4). Qwen3.5-9B measurements evaluate the same rules in a model with attention and gated memory. Appendix F develops a policy-learning extension: averaging action-level return differences over a policy reference recovers the advantage, the return above that policy's expected return ([13](https://proceedings.neurips.cc/paper/1999/hash/464d828b85b0bed98e80ade0a5c43b0f-Abstract.html), [14](https://ojs.aaai.org/index.php/AAAI/article/view/11794)).
